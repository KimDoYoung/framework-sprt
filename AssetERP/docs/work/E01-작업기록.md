## 의존 (사용자 결정 대기)
- **기한 설정 `Sch03_Lookup_Ics`**: 법규 그리드 [기한] 아이콘과 분류 수정 창 수시알림 [설정]이 부른다. 다른 도메인(sch)의 큰 조회창(UI 354줄·이벤트 40·버튼 9·그리드 1)이라 새 ID(예: sch 변환)로 해야 한다. 지금은 "아직 변환 전입니다" 알림. 변환되면 `Ics01_Grid_IcsType.deadlineList()`·`Ics01_Edit_ClassTree` [설정]에서 연다(연 뒤 `refresh`·`sch.Sch03_Deadline.selectDeadlineName`).

## 제안 (사용자 승인 전 반영 안 함)
- **원본 저장이 안 불러온 열을 NULL로 덮는다**: `UpdateDataModel.getUpdateSql`은 모델에서 읽은 값으로 모든 열을 쓴다. 분류 수정·이동은 트리 행 모델(`selectByCompanyId`는 id·회사·분류명·상위·순번·코드·구분·사용·상세내용만 가져옴)을 보내므로 `ics01_related_law`·`ics01_submit_to`·`ics01_public_type`·`ics01_advis_yn`이 NULL/false로 바뀐다(분류(IC) 행은 보통 비어 있어 실제 피해는 작을 수 있음). TOBE는 화면이 고치는 열만 쓰므로 이 문제가 없다.
- 법규 이동(`Ics01_Move_Grid`)·분류 이동이 **자기 자신·하위로** 옮기는 것을 막지 않는다(원본). TOBE는 서버가 거절한다(보호 추가).
- 법규 서식파일 [삭제] 아이콘은 **확인 창 없이** 연결을 지운다(원본 그대로, `Sys11_RelateFile.delete`). 확인 창을 넣을지 확인 필요.
- `Ics01_Edit_ClassTree` 수정 창의 **조회순서** 칸은 저장 때 분류코드로 덮인다(`update()`가 `setSeq(getClassTreeCode())`). 칸을 읽기 전용으로 할지 확인 필요.
- 법규 이동 창·분류 이동 창이 **자기 자신까지 포함한 전체 트리**를 보여 준다(원본). 이동할 수 없는 노드를 비활성으로 보이게 할 수 있다.
