# B12-4 작업기록 — UX보강 일괄 적용 (org·sms)

## 범위
`Org00`~`Org02`, `Sms02`~`Sms04` 11파일 중 조회·저장이 있는 파일.

## 적용
| 화면(파일) | 적용 |
|:---|:---|
| `Sms03_Page_UserListAdmin` (1367 오른쪽) | SearchBar — 고객사·검색·사용고객만 보기 3개(UX-01·04). **초기화는 넣으면 줄바꿈이 늘어 뺌.** 원본처럼 부모 선택 전에는 조회 비활성 → `SearchBar`에 `disabled` prop 추가(조회·초기화 함께 끔, 공통 부품). 기타고객사 추가는 `extra`. 페이징 이동 중에도 `loading={loading}` |
| `Sms02_Lookup_History` (발신기록) | SearchBar — 조회기간·검색 2개. **초기화는 줄바꿈이 늘어 뺌** |
| `Sms04_Lookup_History` (전송기록) | SearchBar — 조건 1개라 초기화 없음. 원본에 Enter 이벤트가 없어 `SearchBar.Input` 대신 `Input allowClear`(UX-04만) |
| `Org00_Lookup_SelectSingle` (조직찾기) | SearchBar(`flexWrap: nowrap`로 원본 한 줄 유지) — 기준일·조직명 2개지만 폭 450이 이미 가득 차 초기화 없음 |
| `Org01_Tab_OrgCode`·`Sms02_Tab_TotalCount`·`Sms03_Tab_SendAdmin` | 조건이 날짜·체크박스 하나뿐이거나 없음 — 변경 없음 (조회 버튼은 이미 UX-01 로딩) |
| `Org01_Edit_OrgCode`·`Org01_Move_OrgCode`·`Org02_Edit_Info`·`Org02_Lookup_OrgInfo`·`Sms03_Edit_GroupSend` | 편집 폼 저장이라 UX-03 대상 아님, 조회 조건 없음 — 변경 없음 |
