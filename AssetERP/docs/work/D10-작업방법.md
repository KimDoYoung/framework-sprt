- 위: 툴바 3줄(① 기준일 `DatePicker` + 조회 + 가져오기류 + 알람실행 ② 시작일·종료일 + 펀드원장… + test ③ 연도 `Input`(100) + 소실파일 + 타사무 Get) → `SingleGrid`(행번호, **체크박스 한 행 선택**, 23열). 아래: 버튼 줄(테두리) = 시작취소 … 승인시작 · 기간조건 제외 · 인사정보 가져오기 · 적용.
