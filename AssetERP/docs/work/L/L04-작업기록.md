**제안(승인 대기)**
- **기준년월 형식 안내**: 원본은 `yyyy.MM`으로 읽지 못하면 예외가 나 아무 일도 없다. TOBE는 "기준년월을 yyyy.MM 형식으로 입력하세요"를 띄운다(작업방법 "공통 절차와 다른 점"). 원본 그대로가 필요하면 알려 달라.
- **페이징 뒤 편집 칸**: 저장하면 1쪽부터 다시 읽는다(원본 `retrieve()`와 같다). 2쪽 이상에서 저장하면 1쪽으로 돌아가 고르던 행이 안 보인다 — 원본 그대로 두었다.
- **UX-02**: 툴바에 조건 3개 + 버튼 3개라 초기화를 넣지 않았다. 일괄 화면시험에서 한 줄이면 `onReset={sp.reset}`만 켜면 된다.
- **L11 간이판**: `Biz01_Tab_CardContentsSimple`이 같은 API를 쓰면 `card-contents`를 그대로 재사용할 수 있다(L11 분석 때 확인).
