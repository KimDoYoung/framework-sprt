**제안(승인 대기)**
- **yunhee**: `mapper-run`·`compare`가 `-p yearText=2024`처럼 숫자로 보이는 문자열을 정수로 바인딩해 `to_char(...) = 2024` 같은 비교가 타입 오류/0행이 된다(따옴표를 붙여도 문자열에 따옴표가 들어간다). 문자열 파라미터를 지정하는 방법(`-p yearText:str=2024` 등)이 있으면 좋겠다.
- **엑셀 xlsx**: 원본이 .xls(HSSF)라 그대로 했다. 다른 TOBE 엑셀은 .xlsx — 통일하려면 형식만 바꾸면 된다.
- **기준년도 입력 검사**: 원본은 4자리 숫자 검사가 없다(빈 값이면 0행). 그대로 두었다.
