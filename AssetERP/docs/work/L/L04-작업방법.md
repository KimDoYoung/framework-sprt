## 공통 절차와 다른 점
- **E4 생략**: 검색 입력칸이 화면에 붙어 있지 않다(원본 그대로).
- **기준년월 형식 오류**: 원본은 `yyyy.MM`으로 읽지 못하면 예외가 나서 아무 일도 일어나지 않는다. TOBE는 "기준년월을 yyyy.MM 형식으로 입력하세요"를 띄운다(원칙 5의 제안 — 승인 전 최소 처치).
- 페이징 뒤 선택 규칙(`num`)·`retrieve()`가 항상 1페이지로 가는 것은 원본 `GridPagingLoader`의 콜백을 읽은 추정이다(`setActivePage(1)`).
