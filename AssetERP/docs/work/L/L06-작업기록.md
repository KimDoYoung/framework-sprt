**제안(승인 대기)**
- **종료일 BETWEEN**: `apr01_reg_date`는 timestamp인데 종료일을 날짜로 넘겨 종료일 당일(0시 이후) 문서가 조회에서 빠진다(예: 종료일 오늘이면 오늘 올린 문서가 안 보인다). 원본 SQL 그대로 두었다. 고치려면 `< 종료일 + 1일`. 같은 모양이 `selectByRequestEmpId`에도 있다.
- **콤보 지우기**: 신청서 구분 콤보는 지우기(X)가 있다. 지운 뒤 [승인신청]은 "신청서 구분을 선택해주세요"가 나오지만 문서분류 칸의 placeholder·앞서 고른 분류는 남는다. 원본(`ComboBoxField`)이 지우기가 있는지 확인이 필요하다.
