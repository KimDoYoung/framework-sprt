## 공통 절차와 다른 점
- **기준년월 형식 오류**: 원본은 `yyyy.MM`으로 읽지 못하면 예외가 나서 아무 일도 일어나지 않는다. TOBE는 L04와 같이 "기준년월을 yyyy.MM 형식으로 입력하세요"를 띄운다(원칙 5의 제안 — 승인 전 최소 처치).
- 페이징 뒤 선택 규칙(`num`)·`retrieve()`가 항상 1페이지로 가는 것은 L04와 같은 추정(`setActivePage(1)`).
- 원본 `retrieve()`에 `retrieveButton.setEnabled(true)`가 있다 — 조회 버튼을 끄는 코드는 없어 TOBE는 생략.
