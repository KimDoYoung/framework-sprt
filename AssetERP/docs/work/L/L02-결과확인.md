## 남은 문제
- 7·7-1(브라우저)은 도메인 일괄 시험 대기. 사원 내역이 있는 계정이 필요한데 kfstest 관리자는 0건이다.
- **사원 계정 로그인 시도가 계정을 잠갔다**: `yunhee api -u 121`을 한 번 시도했는데 이미 4/5였던 사원 29035(=121)가 5/5로 잠겼다(`ACCOUNT_LOCKED`). 이어서 `-u 202306221546363`(비밀번호가 맞지 않아 1/5)도 시도했다. 08 K06이 이미 `--as` 금지를 적었는데 지키지 못했다. 잠금 해제는 관리자 화면(비밀번호 재설정 `SysPassword`의 잠금해제)에서 한다 — 데이터를 바꾸는 일이라 하지 않았다.
- 카드 내역이 있는 사원으로 [일괄저장]·편집 [저장]·직원 [등록]/[삭제]·증빙자료 창 실제 클릭은 브라우저 일괄 시험에서(DB 시험은 서비스까지만).
- 원본의 `getSelectedItem()`(여러 행 체크 시 현재 행)을 "마지막으로 새로 체크한 행"으로 옮겼다 — GXT 기준과 같은지는 화면 시험에서 확인.
