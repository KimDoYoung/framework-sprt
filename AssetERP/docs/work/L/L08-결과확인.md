## 남은 문제
- 7·7-1(브라우저)은 도메인 일괄 시험 대기. 특히 **[출력/다운로드]**(RdViewer iframe, mrd `Biz01_Rd_ProvideList`/`Biz01_Rd_ReceiveList`)는 RD 서버 시뮬레이터가 켜져 있어야 확인된다 — 이번에는 `provide-list/rd-print`를 부르지 않았고 주소 발급도 보지 않았다(→ 2026-10-23 시뮬레이터로 호출 계약 확인, 아래 절. 브라우저 iframe은 일괄).
- 제공/수령 콤보에서 구분 `2`(이익수령)의 화면 동작(열 숨김·조회)은 코드 대조와 DB 테스트(출력 자료)까지만 봤다. kfstest 이익수령 자료는 2건뿐이라 목록이 거의 비어 보일 수 있다.
- 조회 속도(6.5초, 1028행)는 원본 SQL 그대로다 — 작업기록 제안.
- UX-02 초기화를 뺐다(위 11).
