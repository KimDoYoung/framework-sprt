## 남은 문제
- 7·7-1(브라우저)은 도메인 일괄 시험 대기. 사원 계정을 쓰지 않아 **행을 눌러 편집 칸이 채워지는 흐름**과 **저장 뒤 목록 갱신**은 코드 대조와 API·DB 테스트까지만 봤다(일괄 시험에서 사원 계정이 없으면 빈 목록이다).
- 첫 행을 체크해도 편집 칸이 켜지지 않는 것은 AS-IS의 `select`가 `RowClick`을 부르지 않는 동작을 옮긴 것이다. 일괄 시험에서 원본 화면과 비교한다(**미확인**).
