## 의존 (사용자 결정 대기)
- **ICAM Get·타사무 Get 실제 구현**: 외부 ICAM DB 접속(`DatabaseFactoryICAM`)과 `BatchMain.icamFund`(L1126~)·`extrFund`(L1282~)가 필요하다. 지금은 버튼이 "ICAM 연동(외부 ICAM DB)이 아직 없어 펀드정보를 가져오지 않았습니다"만 보인다. D08 `Icam10_Tab_FeeAdmin`·D09 `Icam50_Tab_DbSource`도 같은 ICAM 연동을 쓸 가능성이 크다.

## 제안 (사용자 승인 전 반영 안 함)
- `selectRecentFund`의 서브쿼리 `WHERE a.icam03_icam_company_cd = icam03_icam_company_cd`는 안쪽 열이 `a`의 것이라 항상 참 → 회사와 무관하게 펀드코드별 전체 최대 기준일을 쓴다(다른 회사가 같은 펀드코드로 더 늦은 기준일을 가지면 이 회사 행이 빠짐). 회사 조건이 의도였다면 `a.icam03_icam_company_cd = icam03_fund.icam03_icam_company_cd`.
- 원본 `Icam03_Tab_Fund`는 ICAM Get·타사무 Get 결과(성공·실패)를 화면에 알리지 않는다(숨은 폼 제출). TOBE는 거절 사유를 오류 메시지로 보인다.
- ICAM Get·타사무 Get 버튼 type은 `button-types`에 없어 `download`로 골랐다 — 별도 type이 필요하면 지정.
- 관리자 회사가 아니면 자기 회사 펀드만(서버 보강, 05 §6 회사 조건).
- 이전 D01 그리드 필드를 모델 이름(`ifCode`)으로 지었는데 05 §6의 DB 파생 이름(`ifCd`)이 규칙이다 — `yunhee compare`가 D01에서 `missing: ifCd`로 알린 이유. D01 이름 정리는 사용자 승인 뒤.
