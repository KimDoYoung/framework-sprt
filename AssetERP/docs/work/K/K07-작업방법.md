## 공통 절차와 다른 점
- `sys99_print`에 쌓지 않는다(위 SQL 이식). 결과 값은 같다.
- 중분류 콤보는 열 때 전체 중분류를 읽어 둔다(K06과 같게). 원본은 대분류를 고르기 전에는 중분류 목록을 읽지 않는 것으로 보이나 목록을 미리 읽어도 화면 동작은 바뀌지 않는다 — 원본 확인 못 함.
- 조회년도·콤보는 AS-IS가 `yyyy-01-01`을 기준일로 쓴다(월 말일이 아님) — 그대로.
- 상세 조회창 폭 1250(AS-IS 1600) — 03 원칙 21.
