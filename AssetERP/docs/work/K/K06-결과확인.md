## 남은 문제
- 항목 7·7-1(브라우저 시험)은 `대기(일괄)`. 확인자 계정이 필요한 시험(행이 있는 조회·확인)은 일괄 때 사용자와 정한다.
- **HTTP API 호출은 못 했다**: 기본 호출이 `TOKEN_EXPIRED` 401이고 `--as 121`은 로그인 실패(**4/5회**). 이 계정은 K05 때 3/5였고 이번에 한 번 더 시도해 4/5가 됐다 — 한 번 더 틀리면 잠긴다. 사용자가 로그인하면 풀린다.
- **상신 조회창의 뒷부분(2단계)**: 문서분류 선택(`Dcr01_Lookup_Class`)·RD PDF 첨부·`Apr01_Edit_ApprDoc.insertLinkApproval`·`updateApprId`·[미리보기] RD·[문서보기] 결재 창. 전자결재·RD 단계에서 K03·J01·J08과 함께 연결한다.
