## 범위 (분석에서 정함)

- **1단계만**(F·G·I·J와 같은 방식): 본 화면 + 아래 탭. [결재요청] 아이콘이 여는 `Apr01_Edit_ApprDoc`과 그 앞의 서버 `fnd.Fnd20_Plan.insertAppr`(결재 문서·결재선 행을 만든다)는 편집창과 함께 다음 단계 — 편집창 없이 문서만 만들면 열어 볼 수 없는 문서가 생기므로 서버 쪽도 미룬다. **편집창이 붙기 전에는 `완료` 불가(03 원칙 12).**
- P03(`Fnd20_Tab_Plan`)의 짝 화면(일반 사원용)이다. 위 그리드는 같은 서비스 `fnd.Fnd01_FundCode.selectByPlan`(열만 9개), 아래 탭은 `selectByFundIdEmp`이다. **`fnd20_plan.selectByFundIdEmp`의 SQL은 `selectByFundId`(P03)와 같고**(`analysis sql`로 대조, 파라미터 `fundId`만) 서비스가 `orgId`를 넘기지만 SQL이 안 쓴다 → 새 API 없이 P03의 `GET fnd/plans?fundId`·`GET fnd/fund-codes/plan-funds`를 그대로 쓴다.
- 색인의 아래 탭 "도달 불가" 둘은 **진짜 도달 불가**다: 생성자에서 `addUpdateButton`·`addDeleteButton`이 주석 처리돼(L61-62) 툴바에 제목 라벨 "펀드별 일정목록"뿐이다 → 업무내용 편집(E1 `BeforeStartEdit`)을 저장할 길이 없고 `deleteRow()`(E2)는 호출처가 없다. 둘 다 `// [E1 생략]`·`// [E2 생략]`, 업무내용 열은 읽기 전용. (P03의 "도달 불가는 오판"과 다른 경우다.)
