## 범위 (분석에서 정함)

- P05(`Fnd01_Tab_FundCode`)와 같은 펀드 목록(일반 펀드) + **최종 규약 3열**(최종규약일자·최종개정회차·규약보기). 규약은 `fnd25_terms.fnd25_fund_id`로 펀드와 이어진다. **이 DB에 그 열이 없어 2026-10-26 사용자가 DBeaver에서 직접 추가했다**(`fnd25_fund_id numeric` + 인덱스 `fnd25_terms_idx02`, 03 변경 이력 참고). 값은 24행 모두 NULL이라 지금 화면의 규약 3열은 빈 칸이고, 규약 팝업은 열리지 않는다(`termsId`가 null이면 아이콘이 아무 일도 안 한다 — 원본은 빈 창).
- 열 때 조회하지 않는다. 조회 뒤 첫 행 선택 → 아래 폼.
- `[엑셀다운로드]`: RD(`Fnd01_Rd_FundSearch`) — 서버가 같은 조회 결과를 `sys99_print`에 담고(`insertRdFundSearch`) 그룹 ID로 `rdDownload`.
- `Com01_Lookup_RelateFile`(다른 도메인)은 `view(termsDetailId)` 모드만 쓴다 — 삭제 열 숨김, 올리기 숨김, 첨부파일명 720. 같은 AS-IS 패턴인 `pages/bbs/Bbs02_Lookup_File`(openUser)을 `parentId=termsDetailId`로 재사용(이벤트 E1~E6은 view 모드에서 도달 불가).
- 색인의 "Fnd25_Lookup_Content 닫기 도달 불가"는 오판 — 생성자 L83에서 `getButtonBar().add(closeButton)`.
