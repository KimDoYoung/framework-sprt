## 남은 문제
- PDF 실제 표시는 미확인(서버에 PDF 원본 파일이 없음 — A33과 같음). 시험은 txt로 했다.
- 한 번에 여러 파일을 고르는 경우(`onChangeFiles` 다중)는 한 파일만 시험했다 — 반복 호출이라 코드로만 확인.
- 비관리자 일반 사용자 계정은 미확인.
- `Sys09_Lookup_Code`의 다른 코드구분(SpecialLeaveCode·DocFormClassCode·WeekBizType) 사용이력 검사는 다른 도메인 변환 뒤(작업기록 의존).
