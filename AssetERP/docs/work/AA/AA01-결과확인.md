## 규칙별 확인 (`AprNoticePlanDbTest`)
- 결재중: 다음 결재자 한 명에게만(두번째 대기자에게는 안 감), 앱알림·메일·SMS 각 1건, SMS는 하이픈 없는 번호.
- 결재완료: 마지막 결재자 제외, 결재한 사람(상신자)에게; 반려(40)도 앱알림 문구는 "결재완료"(원본 그대로)·메일/SMS는 "반려".
- 참조자에게 결재완료 알림, 승인취소는 취소 전 대기자에게 code 50, 수신설정을 끈 사람에게는 보내지 않음.

## 남은 문제
- **`real` 모드 없음** — 실제 서비스로는 아무것도 가지 않는다. 비밀값을 줄 방법이 정해지면 제안 ①.

- 시뮬레이터는 호출 계약만 본다 — 실제 도착·지연·스팸 분류는 볼 수 없다.
