## 공통 절차와 다른 점
- PDF 생성은 전자결재(apr) 도메인의 iText 인장 PDF(`Apr10_StampPDF7` 1,440줄 + 인장 파일·로고·회사별 설정)라 02의 "다른 도메인 컴포넌트" 규칙대로 범위 밖(의존). 서버는 만들지 않고 알린다.
- 서버 권한 검사는 넣지 않았다(원본에 없음; kfstest 관리자가 이 데이터를 본다 — sys admin 검사를 넣었다가 403이라 뺐다).
