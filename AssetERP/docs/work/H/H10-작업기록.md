## 제안 (사용자 승인 전 반영 안 함)
1. **삭제의 사용중 검사를 서버로**: AS-IS는 화면이 `checkRelateIcs`를 먼저 부르고 서버 `delete`는 검사하지 않는다. API를 직접 부르면 법규에 연결된 관리그룹도 지워져 `ics05_relate_manager`가 없는 그룹을 가리킨다. `DELETE ics/managers`가 안에서 `countRelate`를 다시 확인하면 안전하다.
2. **관리그룹 삭제 때 공유(`ics04_share`)도 함께 지우기**: AS-IS는 그룹만 지워 고아 공유 행이 남는다.
3. **미지정 그룹 삭제 방지를 서버에서도**: 화면에서만 막는다(`defaultYn`).
4. 관리그룹명 중복·빈 이름 검사 없음(AS-IS 그대로 빈 이름도 저장됨).
