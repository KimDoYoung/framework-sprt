## 남은 문제
- 7·7-1(브라우저 시험)은 `대기(일괄)` — 도메인(ics·icr) 일괄 시험 때 `H04-화면시험.json`으로 실행.
- 툴바가 길다(년 62 + 월 70 + 대분류 150 + 중분류 250 + 체크 2 + 구분 콤보 2 + 검색 250 + 조회): 원본은 두 줄 고정, TOBE는 `SearchBar`가 줄바꿈한다. 어색하면 사용자 판단(작업기록 제안).
- 사용자가 말한 test 계정 kfstest/121/1111(사원)로는 로그인하지 않았다 — 조회 API 확인은 `yunhee api -c kfstest`(kfstest 고객사 관리자)로 했고, 사원 계정 메뉴 노출·권한은 일괄 화면 시험에서 확인.
