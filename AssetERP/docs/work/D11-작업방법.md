## 화면 구성
- 위: `SearchBar` = 사무수탁사명(`SearchBar.Input` 400, 빈칸 글자 "전체") + 조회 + 저장(n) + ICAM가져오기 + 사용여부(`Checkbox`, 켬). 아래: `CellEditGrid`(행번호, 체크박스 단일, 수탁사코드 80 편집·수탁사명 250 편집·사용여부 70 체크 표시만·비고 300 편집). 여백 20, 최대 폭 1000.
- 원본에 행 추가·삭제·초기화 버튼이 없다. 새 행은 ICAM가져오기로만 생긴다.
- 버튼 type: 조회 `search`, 저장 `save`, ICAM가져오기 `download`.
- `consignmentId`는 15자리라 `number`로 안전(05 §6의 18자리 문자열 규칙 대상 아님).
