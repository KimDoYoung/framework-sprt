## 화면 구성
- 본 화면: BorderLayout center(최대 1000) + east(폭 500) 좌우 분할. 왼쪽 = 툴바(`조회` 버튼 + "사용고객만 보기" 체크, 기본 체크) + 단일 선택 `CellEditGrid`(행번호·체크박스 단일): 회사 250 / 서브도메인 80 / 누적사용건수 200(정수) / 발신기록 80(View 아이콘). 오른쪽 = `Sms02_TabPage_Detail`
- `Sms02_TabPage_Detail`: 위 연도 그리드(사용연도 100 가운데 / 사용건수 100 / 사용금액 100) 30%, 아래 월 그리드(사용월 100 가운데 / 사용건수 / 사용금액) 70%. 둘 다 `SingleGrid`
- `Sms02_Lookup_History`: 모달 700×500 "발신기록 (최근 300건)", 툴바 `조회기간 [시작일 100] ~ [종료일 100] 검색 [내용 200] 조회`, `SingleGrid`: 전송일 170(가운데) / 내용 470(textArea), 하단 `닫기`
