## 의존 (사용자 결정 대기)
- **PDF 생성 실제 구현**: 전자결재 변환 때 `Apr10_StampPDF7`과 함께 `PdfMaker` 구현을 만든다. 지금 버튼은 오류 안내만 한다.
- 이 PC에 playwright-core가 없어 scratchpad에 설치(`npm i playwright-core@1.49.1`)해 `NODE_PATH`로 썼다.

## 제안 (사용자 승인 전 반영 안 함)
- 원본 `update()`는 선택 행이 없으면 `getSelectedItem()`이 null이라 NPE → `grid.mask("PDF 생성중")`이 풀리지 않는다. TOBE는 선택이 없으면 아무것도 안 한다(안내 문구는 원본에 없어 넣지 않음).
- 원본은 서버 오류를 알리지 않고 항상 다시 조회한다(`PDFCreate`는 결과 없이 예외를 삼킴). TOBE는 거절 사유를 오류 메시지로 보여 준다.
- UX보강 제안 없음.
