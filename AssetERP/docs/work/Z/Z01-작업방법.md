- `GET /api/v1/bbs/company-rules/public?ruleType&searchText` — `bbs.Bbs15_CompanyRule.selectBySearchText`. companyId = 로그인 회사, stdDate = 서버 오늘. 새 API 1개.
- 첨부 건수·목록: 기존 `fileApi.searchByParentId`, `Bbs02_Lookup_File`(사용자용) 재사용.

## SQL 이식
`bbs15_company_rule.selectBySearchText` → `BbsCompanyRuleMapper.xml#selectBySearchText`. 공개된 최신 개정회차만, 종료일 안 지난 것만, 정렬 규정코드. AS-IS의 `taskId` 분기(Tdm10 연결법규 조회창용)는 옮기지 않음. 열은 기존 `companyRuleColumns` 재사용.
