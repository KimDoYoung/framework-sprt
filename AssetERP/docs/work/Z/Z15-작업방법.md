## 공통 절차와 다른 점
- 어느 조회를 쓸지는 AS-IS가 클라이언트에서 로그인 이름으로 골랐다. TOBE는 같은 기준(로그인 이름 = "정서현")을 서버가 정한다(요청 값을 믿지 않음). 저장·삭제·엑셀은 원본처럼 서버 이름 검사 없음(이상한점 #193).
- 엑셀: 원본은 `HttpServletResponse` 메시지(성공 문구)를 화면에서 안 쓴다 — 건수만 돌려주고 화면은 다시 조회만 한다. 오류는 한 행이라도 나면 전체 롤백(원본은 commit 전에 중단).
- 템플릿 버튼은 원본에 없다.
