## 공통 절차와 다른 점
- **sys admin 검사 제거**: C06이 `SmsGroupSendService`에 둔 `requireSysAdmin`은 원본 서버에 없는 검사다(메뉴 권한이 막음). 이 화면은 일반 사원 메뉴라 뺐다. 모든 문장은 로그인 회사 범위. C06 화면(#1367)은 관리자 메뉴라 영향 없음.
- 대상 이름: C06은 `고객사 + " " + 사원명`, 사내 사원은 고객사가 없어 사원명만(`targetName` 분기 추가).
- `separateAddTitle=false`: AS-IS 호출이 `isSeparateAddTitle`을 안 줘서 겸직 행도 재직으로 센다(A04와 같음). 이걸 빼면 API 48행 ≠ SQL 51행.
- 원본이 확인하는 SMS 허용 설정(`getSMSFlag`)과 `sms04` 기록은 C06과 같이 옮기지 않는다(발송 자체를 안 함).
