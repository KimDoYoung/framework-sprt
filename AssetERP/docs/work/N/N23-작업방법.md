## 화면 구성
- 본 화면: 위 = 툴바(점검년월 `QuickMoveField`·직책 `LookupInput`·[조회]·[제출][제출취소]) + 안내 줄("※ 의견등록상태를 더블클릭하여…" · "※ 점검마감일 : …") + `SingleGrid`(**묶음 헤더** "이행점검결과"{적정·미흡·해당없음}과 "의견등록상태", 직책 200·검토부서 200·점검항목 80 …) / 아래 = 두 그리드.
- 팝업: 승인(반려) 의견 630, 보고의견 630, 이행점검 승인상세 1300, 미흡내역 조치결과 승인 1310, 승인이력 1300.

## 공통 절차와 다른 점
- **서버가 승인 대상 행을 다시 읽는다.** AS-IS는 모델(`firstApprEmpYn`·`finalApprEmpYn`·`apprStatusCode`·`checkStatusCode`)을 화면이 보냈다. TOBE는 승인 행 ID만 받아 서버가 `selectByApprEmpId`와 같은 SQL로 다시 읽고(로그인 사용자의 승인 행이 아니면 거부), 상태 판단에 그 값을 쓴다. 정상 화면 흐름에서는 같은 값이다.
