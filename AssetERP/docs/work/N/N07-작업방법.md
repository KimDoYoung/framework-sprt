## 공통 절차와 다른 점
- 직책 연결창은 `useGridCrud`를 쓰되 저장·삭제는 화면이 직접 부른다(삭제를 미뤘다 저장 때 보내는 AS-IS 흐름 — Org10 `RoleStamp`와 같은 방식). 저장 버튼 건수는 `changes.modified + deleteList`.
- AS-IS `stdDate`(직책 연결창의 기준일)는 조회 SQL에서 쓰이지 않고 `Tdm20_Lookup_SelectMulti`도 `open(callback)`이라 기준일이 오늘이다 — 그대로.
