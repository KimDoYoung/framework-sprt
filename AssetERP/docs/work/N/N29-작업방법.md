## 공통 절차와 다른 점
- **저장 판정(`IsNewData`)**: AS-IS `UpdateDataModel`은 키가 DB에 없으면 INSERT, 있으면 UPDATE다. 그래서 기본 행(DB에 없음)을 고쳐 저장하면 INSERT가 된다. TOBE 서비스도 같게 한다: ID가 null·≤0(새 행·기본 행)이면 새 ID로 INSERT, 양수인데 DB에 없으면(다른 사용자가 지운 행) 같은 ID로 INSERT, 있으면 UPDATE(다른 회사면 403).
- **중복 검사**: AS-IS는 새 행의 ID가 null이라 `!= null`이 거짓이 되어 걸리지 않는다. 그대로 두고(기본 행·기존 행은 ID가 있어 걸림) 제안에 남긴다.
- 그리드는 `useGridCrud`(다중 체크 기본)에 `rowSelection`을 단일 체크로 넘겨 쓴다. [삭제]의 "삭제할 내역을 선택하세요"는 훅 기본 문구("삭제할 행을 선택하세요.")와 달라 화면에서 먼저 검사한다.
