## 제안 (사용자 승인 전 미반영)
- **삭제 판정 03 보강의 확인**: 위 결정이 공통 서버 코드 변경이다. 다른 첨부 화면 중 연결 행이 있는 파일(법규 서식 등)이 이제 삭제가 막히는데 AS-IS와 같은 동작이다. 문제가 되면 `SysRelateFileService`의 03 분기만 되돌리면 된다.
- 업로드 창의 [업로드]·[닫기]는 `analysis screen`이 "도달 불가"라고 표시하지만 `getButtonBar().add(…)`로 창 아래 단추에 붙어 실제로 보인다 — N22와 같은 감지 한계(yunhee 수정 제안 후보).
- AS-IS 삭제 확인 문구 "해당 파일을 삭제하시곘습니까?"의 오타("하시곘")는 원문 그대로 둔다.
- 감사 로그 `AuditLogService 감사 로그 DB 기록 실패`(FILE_UPLOAD·WS_CONNECT)가 서버 로그에 남는다 — 이 ID와 무관한 기존 현상으로 보이나 원인은 확인하지 않았다.
