## 메모
- 로그인 사용자 부서(`LoginUser.getOrgCodeId()`)는 서버가 `dashboard my-org`로 구한다(N17 `manl-jobs?checkYn`과 같은 방식). 회사관리자(userId < 0)는 부서가 없어 회사 전체가 나온다 — kfstest 27건.
- E13의 기존 `selectByText`는 `COLLATE "ko-KR-x-icu"`를 쓰고 있다(03 원칙 19 이전). 새 문장은 `ko_KR.utf8`로 썼고 기존 문장은 건드리지 않았다(사용자 일괄 수정 목록 대상).
- 합계 행은 `getSumGrid("", 2, 4, 7)` — 원본 `GridBuilder`에서 `setChecked`가 선택 열을 0번으로 넣으므로 직책(2) 라벨 칸, 4~7 = 책무~점검항목 4열.
