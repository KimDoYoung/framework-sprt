## 공통 절차와 다른 점
- 중복 기간 검사는 원본처럼 클라이언트에서 한다(화면 값 + `not-in`으로 받은 나머지). 시작일이 비고 종료일만 있는 행은 원본은 NPE라 비교에서 빈 문자열로 본다

- 잠금(P)은 PDF 생성기가 연결되기 전에는 첫 행에서 "파일 생성실패"로 멈춘다 — 위 범위 참조
