- 바깥 `BorderLayoutContainer` 여백 20, 테두리 박스: 위 툴바 높이 50(구분 콤보 200 · 검색 300 "파일명/비고" · [조회][저장][파일업로드]) + 아래 `CellEditGrid`(체크박스 단일).

## 공통 절차와 다른 점
- AS-IS는 `FileUpload` 서블릿이 폼 항목마다 행을 만든다(B10 결함) — 파일 하나만 받는다(B10 결정과 같다).
