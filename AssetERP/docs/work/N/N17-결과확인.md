## 남은 문제
- 항목 7·7-1 브라우저 시험은 일괄 실행에서. 처음 열릴 때의 자동 조회(내 부서가 확정된 작성중 작업이 1건이면 바로, 여러 건이면 선택 창), 책무관리자일 때만 부서 칸이 켜지는 것, 위 목록 선택 → 아래 목록 갱신, 불러오기 창 두 개의 위/아래 그리드 연동, 작성완료 뒤 [등록][삭제][불러오기] 비활성은 브라우저에서만 볼 수 있어 아직 못 봤다.
- 사원 계정(부서가 있는 사용자)으로 `manl-jobs?checkYn=true`가 부서 필터를 거는 것은 회사관리자 API 시험으로는 못 본다(`mapper-run`으로 AS-IS와 같은 SQL임만 확인).
- 검색칸에서 Enter를 눌러도 [조회]와 같이 처리돼 매뉴얼작업이 없으면 "매뉴얼작업을 선택하세요"가 뜬다(AS-IS는 Enter에서 조용히 무시). `SearchBar` 공통 동작이라 그대로 둠.
