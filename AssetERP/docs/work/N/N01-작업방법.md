## 화면 구성
- 바깥: `padding: 20`(원본 `Margins(20)`) + 테두리 `Tabs`(총괄·임원별·부서별).
- 각 탭 공통 뼈대(`vlc`): ① 툴바(50) — 빈칸 · "점검년월" 라벨 · `QuickMoveField` · (임원별 "임원" + `LookupInput` 150 / 부서별 "부서" + `LookupInput` 250) · 라디오 `최종승인`(기본)·`점검완료` · `<Button type="reset">새로고침</Button>`(button-types의 reset) · 마감 문구(`label01`: 마감되면 `* 당월 이행점검은 마감되었습니다`, 아니면 빨강 `* 마감일 : yyyy-MM-dd`). ② 모니터 3개(140): `진행율`(20%)·`적정비율`(20%)·`점검결과 : 대상 / 적정 / 미흡 / 해당없음`(60%), 큰 글자 50px, 값 없으면 `-`. ③ 그리드 영역.
- 총괄: ③ = 가로 2분할(300 높이) `임원별 진행현황`(grid01)·`부서별 진행현황`(grid02), 아래 `미흡 조치현황`(grid03, 나머지 높이).
- 임원별: ③ = 2분할(250) `직책별 진행현황`(grid01)·`부서별 진행현황`(grid02), 아래 2분할 `미흡 조치현황`(grid03)·`미점검 현황`(grid04).
- 부서별: ③ = 2분할(350) 왼쪽 `미점검`(grid01), 오른쪽 위 `반려`(grid02)·아래 `당월발생 미흡`(grid03), 아래 `미흡 조치현황`(grid04).
- 그리드는 모두 `SingleGrid`(체크 없음, 편집 없음, 행번호 있음). 진행현황 그리드(총괄 grid01·02, 임원별 grid01·02)는 맨 아래 합계 행 `계`(`getSumGrid("계", …)` → `sumRow`)와 묶음 헤더 `점검`(대상~해당없음 5열). 컬럼은 `analysis grid` 표 그대로(총괄 grid03 650폭 등). 합계 열: 총괄 grid01 `getSumGrid("계", 2, 4, 8)`, grid02 `("계", 1, 3, 7)`; 임원별 grid01·02 `("계", 1, 3, 7)` (라벨 열, 합계 시작 열, 합계 끝 열).
- 부서별 grid02 컬럼 `반려의견`은 `ImageCell`인데 클릭 핸들러가 비어 있다(AS-IS 그대로 아무 일도 안 함). 부서별 grid03은 `점검자` 열이 **두 번** 들어 있다(원문 그대로 둔다).
- 임원선택 조회창 `Tdm01_Lookup_SelectSingle`: 제목 `임원선택` 600×600, 검색 칸(`임원명/직위/조직명`, 200폭, Enter=조회) + [조회], 단일 선택 그리드(임원명 100 가운데·직위 150·조직명 250), [확인][닫기], 더블클릭=확인. 선택 없이 확인하면 `선택된 담당임원이 없습니다`. 열릴 때 조회.
