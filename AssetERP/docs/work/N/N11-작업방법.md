## 공통 절차와 다른 점
- 하단 탭 그리드는 AS-IS에 체크 열이 없고 선택 행을 삭제하지만, TOBE `CellEditGrid`는 삭제용 체크박스가 있다(공통 부품 동작).
- 인사정보 창 검색은 AS-IS가 아무 키나 누를 때마다 조회하지만(`KeyPress` 핸들러에 Enter 검사가 없다) `SearchBar` 규칙대로 Enter/[조회]로 한다.
- 상신·상신문서보기·책무기술서 RD는 위 "1단계 범위"대로 안내만.
- 책무배분 등록은 AS-IS의 서비스 호출 둘(tdm30 → tdm34)을 한 트랜잭션으로 묶었다(결과 같음).
- 직책배정 삭제 뒤 AS-IS처럼 탭을 다시 읽지 않는다(선택이 사라지면 탭은 옛 내용이 남는다).
