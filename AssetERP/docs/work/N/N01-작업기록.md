## 제안 (03 원칙 5 — 승인 전 반영 안 함)
- `selectDashboardInsuff`에 `orgId`를 넘기지 않는 점(부서별 탭의 미흡 조치현황이 부서와 무관)은 AS-IS 서버 코드의 누락으로 보인다. 원본 쪽에서 고칠지 사용자 판단.
- 점검결과 모니터가 데이터 없음(`checkCntInfo` null)일 때 AS-IS는 글자 "null"을 찍는다(문자열 연결). TOBE도 그대로 "null"이다 — "-"로 바꾸는 편이 낫다.
