## 공통 절차와 다른 점
- 저장 뒤 목록을 다시 조회한다(AS-IS `GridUpdate`는 바뀐 행만 갱신) — 계산 열(작성현황·완료여부)을 새 행에서도 맞추려고
- 아직 저장하지 않은 새 행(ID ≤ 0)은 작성내역이 있을 수 없으므로 `has-duties`를 부르지 않고 PASS로 본다(AS-IS는 `GridInsertRow`가 서버 시퀀스를 받아 조회 결과가 빈 목록)
- 생성 두 버튼은 AS-IS가 화면의 모델을 서버에 보냈지만 TOBE는 id만 보내고 서버가 저장된 행을 읽는다(저장 전 변경이 있으면 화면이 막으므로 같은 값)
- 매뉴얼 작성·복제는 서버도 관리자(`SysMenuSearchService.isManager`)만 허용(AS-IS는 버튼만 숨김 — 보안 보강)
- 조회창 [전체]는 원본이 `callback.execute(null)` 뒤 `hide()`(Tdm20 L162-167, Org00 L148-153) — 직책 [전체]는 직책만, 부서 [전체]는 부서를 비운다(L200-201·L260-261). 두 조회창에 `onAll` prop을 더해 처리(처음에는 yunhee 이벤트 줄 `→ hide()`만 보고 닫기로 오인했다가 N16 분석 중 원본 확인해 고침)
- 날짜 편집 열 폭 원본 90 → 120(UX-08)
