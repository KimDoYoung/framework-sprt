## 남은 문제
- 미확인: 고객사·일반 사용자 계정의 실제 화면(`me` 응답 대체로 모양만, 일반 사용자 SQL은 DB 테스트), 기초데이터생성 화면 실행(DB 테스트로 대체 — 화면에서 하면 고객사에 시험 행이 남아 지워야 함), 북마크 창의 저장·전체삭제 실행(admin 사용자에게는 조회 가능한 북마크가 없음 — DB 테스트로 대체), 화면 찾기에서 북마크한 행이 별로 바뀌는 것(응답을 대체해 별 클릭 → POST까지만), 회사관리자(`userId<0`) 판정이 원본 `getIsManager()`와 같은지.
- 제안 승인 대기: 작업기록의 제안 ①~⑤(특히 ④ UX보강 제안: 행 끌기를 [→]/[←] 버튼으로도).
- 사고: 화면 스크립트의 앞선 두 실행이 120초 제한·끌기 루프 오류로 28000에 시험 화면 행과 거래코드 지정 2건을 남기고 끝났다(내 행만 API로 삭제, DB 0건 확인). 기존 화면 등록·북마크 23건은 건드리지 않음.
