## 공통 절차와 다른 점
- 원본은 서버 검사가 없어 조회순번·항목 NOT NULL 위반이 DB 오류로 나온다 → 서버도 화면과 같은 문구로 막는다(05 §6). 저장·삭제는 관리자 회사(`isSysAdmin`)만, UPDATE·DELETE에 회사 조건을 건다(보안 보강, D11~D13과 같음).
- 저장(n)은 삭제 대기 건수를 더해 센다: 원본 `update()`는 변경 0건이어도 `deleteList`를 보내므로 삭제만 해도 [저장]이 눌려야 한다.
