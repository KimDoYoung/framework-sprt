## 공통 절차와 다른 점
- 회사 조건은 서버가 정한다: 원본은 클라이언트의 `companyId`를 그대로 썼지만 TOBE는 로그인 회사가 아닌 값이면 관리자 회사만 허용한다(05 §6 "세션 값"·"관리 화면 권한").
- 체크 칸 값은 DB 형태('true'/'false' 문자열) 그대로 — `gb.boolean(…, { editable: true })`.
- 오른쪽 그리드는 `rowSelection singleRow`(원본에 `setChecked`가 없음). 삭제는 선택한 한 행.
