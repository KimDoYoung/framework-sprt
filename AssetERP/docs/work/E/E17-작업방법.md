## 공통 절차와 다른 점
- `Dcr30_Link.update`와 `updateDcrAuth`는 원본에서 클라이언트가 두 번 부르지만 TOBE는 PUT 하나로 묶는다(같은 순서, 같은 트랜잭션).
- 복사(copy-link·copy-form)는 원본이 화면 행 전체를 서버에 보내지만 TOBE는 `linkIds`만 받고 서버가 로그인(관리자) 회사의 행을 읽는다(클라이언트 값을 믿지 않음).
- 새 도메인 `biz.com`(Com10_FormMapping)을 만든다.
- `Dcr30_Move_DcrClass`는 act·apr·ast·biz·car·emp·flt·ics·pay가 쓴다 → 공통 컴포넌트(`components/lookup/`)로 만든다(IM-02).
