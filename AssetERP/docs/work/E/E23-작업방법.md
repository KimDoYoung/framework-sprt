## 공통 절차와 다른 점
- 원본은 서버 검사가 없고 열이 모두 NULL 허용이라 **필수 검사를 넣지 않는다**(03 원칙 4).
- 저장·삭제는 관리자 회사(`isSysAdmin`)만, UPDATE·DELETE에 회사 조건을 건다(보안 보강, E21·E22와 같음). 조회는 누구나 회사 0 행을 본다(원본 그대로).
- 야간 시작/종료의 빈칸 글자 "00:00"(`setEmptyText`)은 그리드 셀 편집기에 빈칸 글자 옵션이 없어 옮기지 않았다(제안 아님, 동작 차이 없음).
- `analysis grid`의 묶음 헤더 이름이 `newHeaderGroupMap…`로 나오는 것은 색인의 한계(실제 제목은 "야간근로"·"가산 배수"). `compare`의 `missing: new`도 같은 이유.
