## 다음 단계 — RD 대체 또는 RD 연결 때 (사용자 지시: 문서에 기록)
지금 서버는 `RoleDescPdfMaker.make(roleDescId, companyId)` 인터페이스 + `DisabledRoleDescPdfMaker`(항상 거절)만 있다. 구현할 때:
1. **원본 순서 복원**: ① `Tdm31_RoleDesc.fileCheck` — 그 책무기술서의 `sys10_file`(parent_id) 있으면 `deleteByParentId` ② `Sys99_Print.CreateTdmRoleDesc`(L122-149) — `sys99_print.deleteByPJobTp`·`tdmCreateData`로 인쇄 데이터를 만들고 `groupId/파일명`을 돌려줌 (windowClassName=`Tdm31_Tab_RoleDesc`, pJobTp=`MK_DESC`, allcStdDate=`yyyyMMdd`, pId=roleDescId) ③ RD 리포트 `Tdm31_Rd_DescRpt`로 PDF 파일 생성(옵션 `/rpdflinebreak [1] /rwordbreakopt [1] /rsaveopt [2049]`, 파일은 `Sys10_File.getServerPath(companyId)` 폴더, 서버 경로가 `c:`로 시작하거나 없으면 실패) ④ `Sys10_File.checkFileStatus`로 파일 존재 확인 ⑤ `Sys10_File.fileReName`(파일명 "책무기술서 ({직책} {임원명})", 형식 pdf, adminYn=true) ⑥ `Sys10_File.copyFile`(apprId, parentId=roleDescId, tableName=`apr01_appr`)로 결재 문서에 연결. 지금 TOBE 서비스는 생성기가 거절하면 아무것도 지우지 않는다(AS-IS는 ①을 먼저 해 실패하면 파일만 사라짐 — 구현하면 ①을 PDF 생성 성공 뒤로 옮기는 것도 검토, 제안)
2. **보기(`viewRd`)**: 첨부가 없거나 결재 전 상태일 때 RD 뷰어(`CommonViewer.html`, mrd `Tdm31_Rd_DescRpt`)를 연다. 지금은 안내만("RD 뷰어 연동이 없어 책무기술서를 열 수 없습니다."). RD 대체가 PDF 생성이면 같은 PDF를 바로 보여주는 방식으로 바꾼다
3. 같은 RD 의존이 있는 형제 화면: E12 `Tdm32_Tab_RoleDigmAdmin`(책무체계도 재생성)·E13 `Tdm42_Tab_ManlManagerAdmin`(책무매뉴얼 재생성) — 같은 방식일 가능성이 커서 인터페이스를 공통으로 올릴지 E12 때 판단
4. 실제 생성 연동이 서면 `DisabledRoleDescPdfMaker`를 지우고, 결과확인 항목 4의 "재생성 실제 실행"을 `통과`로 바꾼다
