## 공통 절차와 다른 점
- **`useGridCrud` 저장 순서**: AS-IS는 서버 점검(updateCheck) → 클라이언트 검사 → 저장이라, 서버 점검 후 `crud.saveRows()`(검사+저장)를 부른다.
- 행 삭제를 모았다 저장 때 지우는 창(Dcr06·Dcr20·Dcr21)은 `useGridCrud.removeRows` + 화면의 `deleteList`(Sys17_Grid_CorpAccount 방식).
- 연결 창(양식·법규·내규)을 닫아도 오른쪽 그리드의 건수는 다시 읽지 않는다(AS-IS 그대로).
