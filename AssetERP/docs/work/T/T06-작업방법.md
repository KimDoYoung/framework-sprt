## 공통 절차와 다른 점
- 근태정책 저장 때 원본이 부르는 `notWorkPolicyIdList`(그리드에 없는 회사 정책을 합쳐 중복 검사)는 호출하지 않는다: 그리드가 회사의 정책을 모두 조회하므로 합칠 행이 없다. 검사 결과(적용시작일 중복 / 사용 한 항목)는 같다.
- 원본 `deleteRow()`(`att.Att02_Commute.delete`)는 이 화면에서 부르는 버튼이 없어 옮기지 않았다.
- 저장 성공 메시지는 `useGridCrud` 기본("n건 저장되었습니다.")이고 원본은 "정상적으로 등록완료되었습니다"다(InsertBatch는 원본 문구).
