## SQL 이식
| SQL ID | 테이블 | 그대로 / 수정(사유) |
|:---|:---|:---|

| `selectByDate` | 〃 | 그대로. 날짜는 `CAST(#{date} AS timestamp)`로 `f_trunc`에 준다. 컬럼 수를 record와 맞추려 `NULL AS time` |

## 화면 구성
- 위(300): 제목 줄 50("공용차량 예약현황 (기준일자 : yyyy년 MM월 dd일)" + 새로고침) + `SingleGrid` 9열(예약 시작일 100·종료일 100·시간 120·차량정보 160·행선지 240·예약자 100·참석자 240·상세보기 60·삭제 60, 체크 단일).
- 아래: 왼쪽 300 달력(antd `Calendar fullscreen=false`) + [예약하기], 오른쪽 라디오 + `SingleGrid` 7열.
- 팝업 880×610 EditModal: 차량·사용자 / 일시(날짜 2 + 시 콤보 `HourCode` + 분 콤보 `MinuteCode`) / 행선지 / 목적 / 참석자 / 메모(85) / 시간막대 300.

## 공통 절차와 다른 점
- `Car03_TimelineChart`는 Google Charts Timeline이다. 이 프로젝트에 차트 라이브러리가 없어 새 의존성을 넣지 않고 같은 모양(행 이름 = 차량명, 막대 글 = 행선지, 행 이름별 색, 배경 #F7F8FC)을 CSS로 그렸다(작업기록 제안).
- AS-IS의 `getSeq`(채번)는 새 예약 저장 때 서버가 한다.
- 매니저 판정(`LoginUser.getIsManager`)은 다른 화면과 같이 `user.userId < 0`.
