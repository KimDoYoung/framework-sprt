- T08·T09는 같은 DTO(`AttCommuteStatusRes`)·서비스·컨트롤러·매퍼를 쓴다(원본도 `Att02_Commute` 한 서버 클래스). 한 쪽에 없는 열은 null이다. record 생성자 자동 매핑은 열이 모두 있어야 하므로 `getCommuteStatus`에만 `NULL AS check_in_time_str, NULL AS check_out_time_str`를 더했다.
- 출력 별칭의 `att02_` 접두사를 뗐다(하위 쿼리의 `att02_status_cd` 별칭은 바깥이 참조하므로 그대로).
