## 공통 절차와 다른 점
- 서버 호출 순서 하나: AS-IS 등록은 `getSeq` 뒤 서버를 부르지만 새 예약 ID는 서버가 채번한다.
- 삭제 시 일지는 AS-IS가 화면의 일지 ID(없는 일지는 임시 번호)로 지우던 것을 예약 ID로 지운다 — 같은 결과이며 임시 번호가 실제 ID와 부딪힐 위험이 없다.
