## 남은 문제
- `Emp93_Lookup_SmsNoticeTarget`(알림수신인 설정, 옵션 "B03")은 다음 단계 — Flt10_Tab_PreApprove("B01")에서도 같은 이유로 미룬 창이다.
- SMS 실제 발송은 `SmsSender` 구현이 없어 못 한다(거절 문구 확인까지). 원본 `sendMessage`는 SMS 사용 여부 플래그(`SMSok`)와 `sms02_history` INSERT도 하지만 `SmsSender`가 거절하므로 만들지 않았다(`trace-crud`의 `sms02_history C`·`sys01_company R` 빠짐).
- 편집기 `HtmlEditor`는 표·글꼴 색이 없다(11 §3). 원본 내용에 표가 있으면 고칠 때 사라질 수 있어, 고치지 않은 내용은 저장 때 다시 보내지 않게 했다.
- 브라우저 동작은 일괄 시험에서.
