## 공통 절차와 다른 점
- 삭제 확인 순서: AS-IS는 확인창 [예] → 예약 조회 → 삭제. TOBE는 확인창 [예] → DELETE 한 번(서버가 예약 확인). 사용자가 보는 순서·문구는 같다.
- `car02_user`에는 회사 컬럼이 없어 서버가 차량정보의 회사로 막는다(보안 보강, 동작 불변).
- 저장 전 새 행(infoId ≤ 0)은 [삭제] 때 서버를 부르지 않고 목록에서만 뺀다(AS-IS도 예약 0건 → 클라이언트 삭제).
- 삭제할 행을 안 골랐을 때 AS-IS는 NPE 위험이 있다. TOBE는 "삭제할 대상을 선택해주세요."로 알린다(제안 아님, 방어).
