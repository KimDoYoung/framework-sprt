## 화면 구성
- 레이아웃: 바깥 여백 20. 왼쪽(455, 분할선) 테두리 박스: 툴바 [법규분류 라벨][찾기 입력 150][찾기] + 트리 그리드(흰 배경, 행번호 없음). 오른쪽 테두리 박스: 툴바 + 문서 그리드.
- 트리 그리드(`SingleGrid` + `useTreeGrid`): 분류명 345(트리 열) · 분류코드 100
- 문서 그리드 `Ics01_Grid_ApprList`(SingleGrid, 체크박스 단일, 행번호 표시): 등록일 100 · 시행일 100 · 등록자 100 · 상신제목 700 · 상세보기 70(아이콘)
- 버튼 type: `search`(찾기·검색), `register`(신규문서 작성)

## 공통 절차와 다른 점
- 안내 문구 2개(편집창 "다음 단계에서 연결됩니다")는 1단계에만 있는 임시 문구다(F01·F02와 같음).
- 행 key: 원본 `keyId`(`relateFundId`)가 발령 이력 조인으로 겹칠 수 있어 그리드에서는 순번을 붙인 `rowKey`를 쓴다(AG Grid는 key 중복을 허용하지 않음). 화면에 보이는 행은 같다.
- `search()`의 `getParent`/`setExpanded`는 이미 `expandAll()`로 모두 펼쳐져 있어 따로 하지 않는다.
