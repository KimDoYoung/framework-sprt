## 공통 절차와 다른 점
- 최근 사용한 문서분류를 콤보에 채울 때 AS-IS는 `f_class_tree_nm_allpath` 결과를 `" > "`로 쪼개 콤보 **이름**으로 찾는다. 이 DB 함수는 `/`로 이어 줘서(`상품전략/상품개발/상품개발위원회`) 그대로면 쪼개지지 않는다 → 서버가 대분류·중분류 ID를 같이 주고 화면은 ID로 채운다(이름이 같은 분류를 잘못 찾는 일도 없음). 조회창 "문서분류" 열은 함수 결과 그대로 보인다.
- 그리드의 HTML 열(문서명·상태)은 AS-IS가 값을 그대로 붙이지만(`appendHtmlConstant`) 문서명은 사용자가 입력한 글이라 TOBE는 굵게·기울임·밑줄·줄바꿈·색 태그만 살리고 나머지는 글자로 보인다(`gb.textHtml`, 11 §1).
- 신규 문서작성 안내 문구 3개(편집창·북마크·상세보기 "다음 단계에서 연결됩니다")는 1단계에만 있는 임시 문구다.
