- 트리 조회 API 이름은 `item-doc`(이 화면 전용 열만 돌려줌: 분류 id·부모·이름(+표준코드)·구분·깊이).

## 제안 (사용자 승인 전 반영 안 함)
- **원본 SQL의 `UPPER(apr01_title||class_tree_nm_allpath||apr01_note) LIKE …`는 비고(`apr01_note`)가 NULL이면 전체가 NULL이라 그 문서가 조회되지 않는다.** kfstest(28000)는 문서 938건 중 비고가 있는 것이 45건뿐 — 종목에 연결된 완료 문서(예: ast 44110의 61730)도 비고가 NULL이라 이 화면에 안 나온다. 원본 그대로 두었다. `COALESCE(apr01_note,'')`로 고치면 보이게 된다. 검증은 이 COALESCE를 양쪽 SQL에 넣어 비교했다(1=1).
- 문서 그리드 같은 `apprId`가 여러 행일 수 있음(첨부파일 조인) — F06과 같다.
- 메뉴가 `(X)`·사용 `false`다 — 실제로 쓰이는 화면인지 확인 필요.
