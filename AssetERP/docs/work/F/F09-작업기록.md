## 결정
- 기록 창(`Apr40_Lookup_DownloadHistory`)은 apr 도메인이지만 이번 ID에서 함께 했다 — 본 화면의 [기록보기]가 여는 하위 클래스이고 01d 머리말(하위 클래스는 같은 ID에서)에 맞다. `biz.apr`에 `AprDownloadHistory*`를 신설.
- zip은 파일 공통(`sys/files/appr-zip`)에 두었다 — AS-IS `FileDownload` 서블릿 `fileType=apprList` 대응.
- 다운로드 감사 로그: F08과 같이 파일마다 `FILE_DOWNLOAD`.
- `selectByApprId`를 따로 둔 이유: 기존 `selectByParentId`는 옛 원본 정렬(`sys10_file_yn` 정렬 없음)이고, zip 번호가 정렬에 달려 있어 새 원본 정렬을 그대로 써야 한다.

## 제안 (사용자 승인 전 반영 안 함)
- **PDF 만들기(`createInPDF7`)**: 본문 파일이 없는 사내문서는 현재 TOBE에서 본문 없이 내려간다. 전자결재 PDF 생성기(Apr10_StampPDF7)를 변환하는 별도 ID(예: apr 도메인 `Apr10`)가 필요하다. 그때 `Dcr00_Tab_ApprList`의 `makePDF` 자리(`fileDownload` 앞)에 연결한다.
- AS-IS `getAppr` 요청에 `typeCode`가 없어 `common.dcr_tree_down`의 `dcr01_type_cd LIKE NULL`이 거짓이 될 수 있다(문서분류를 골랐을 때 0행?). F05·F08은 `%`를 고정으로 넣어 옮겼고 이번에도 같게 했다 — 사원/관리자 계정으로 AS-IS와 TOBE의 분류 선택 결과를 일괄 시험에서 대조 필요.
