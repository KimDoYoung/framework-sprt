## 남은 문제
- **시험 행 1건이 `sch04_list`에 남아 있다**: `sch04_list_id = 202610269013463`, `sch04_company_id = 28000`, `sch04_info_id = 1`, `sch04_manager_id = 1`, 마감일 2026-10-26, 처리여부 `0`, 제목 없음. 03 원칙 2("시험 행은 그 세션 안에 지운다")를 지키지 못했다. `yunhee sql`은 읽기 전용이고 지우는 API가 없다 — 사용자가 지우거나 지우는 방법을 정해야 한다(작업기록). 행의 처리자(`sch04_person_id`)는 시험 계정 admin(-28656)이고 `info_id` 1은 다른 회사(79)의 일정이라, 데일리 조회(`sch01_daily_yn`이 비어 있음)에는 나오지 않지만 같은 계정이 O04 업무일정 처리·H06 등 `sch04_list` 조회 화면을 열면 보일 수 있다(확인하지 않음).
