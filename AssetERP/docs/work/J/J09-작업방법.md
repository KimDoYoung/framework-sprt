## 공통 절차와 다른 점
- 등록(복사)는 원본이 선택된 모델 객체 자체의 ID를 비우는 방식이라(같은 행이 바뀌는 듯 보임) 선택 행을 복사한 **새 행**으로 넣는다. 변경으로 치지 않는 점(셀을 고쳐야 저장됨)은 원본과 같다.
- 조회창의 저장 완료 문구는 원본 `저장이 완료되었습니다.` 대신 공통 부품의 `n건 저장되었습니다.`를 쓴다.
- 삭제 선택이 없을 때 기준관리 본 화면은 공통 부품 문구("삭제할 행을 선택하세요.")를 쓴다(원본은 "0건의 정보를 삭제하시겠습니까?"를 그냥 묻는다).
