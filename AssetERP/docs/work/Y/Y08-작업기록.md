## 한계 / 넘긴 것
- 증빙자료 아이콘(`Com01_Lookup_RelateAppr`, 이벤트 14·그리드 2)은 다른 도메인 창이라 안내만 띄운다(U03·Y09와 같음, 다음 단계).
- 등록창의 [신규문서 작성]은 `Dcr01_Lookup_Class`로 문서분류까지 정하고 새 문서 편집창(`Apr01_Edit_ApprDoc` 새 문서)은 안내만 한다 — 새 문서 모드가 저장한 문서 ID를 돌려주지 않아서(링크 모드의 `onLinkSaved`만 있음). `Act80_Lookup_RelateAppr`와 같은 상태.
- 바로등록(`insertPass`)은 등록창에 `pass` 모드와 [불러오기]까지 만들었지만 부르는 U03 `Pay50_Tab_ExpenseManager`의 [바로등록] 버튼 연결은 하지 않았다(U03 2단계 항목).
- 브라우저 시험은 일괄 때(`Y08-화면시험.json`). 쓰기(등록·삭제·요청·파일 올리기)는 라이브 DB를 바꾸므로 누르지 않는다(03 원칙 2) — 로직은 롤백 테스트로 확인했다. `GET next-id`로 번호 하나(202611019892297)를 썼다(순번 표만 증가, 행 없음).
