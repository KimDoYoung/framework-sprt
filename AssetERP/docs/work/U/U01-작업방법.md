## 화면 구성
- 위 SearchBar(기준일 DatePicker 120 + [조회] + extra [출력/다운로드]·[예금잔고정리]) → 가운데 가로 3칸(30:35:35): 왼쪽 예금원장 그리드(`SingleGrid`, 계좌 200·통화 55·기초잔액(전일잔액) 120·마감잔액(당일잔액) 120) + 아래 200 통화별 합계 그리드(255·120·120), 가운데 입금 그리드, 오른쪽 출금 그리드(거래유형 100·거래처 150·적요 200·금액 120, 묶음 헤더 "입 금"/"출 금", 맨 아래 금액 합계 행 `getSumGrid(" ",1,4,4)`) → 아래 70 테두리 칸(문서분류 800 `LookupInput`·상신상태 읽기 전용·[상신]·[문서보기]).
- 기준일 기본 = 오늘 -1일. 목록이 있으면 첫 행을 고르고 입출금·상신상태를 읽는다(목록이 없으면 입출금·상신상태는 AS-IS처럼 그대로 둔다).
