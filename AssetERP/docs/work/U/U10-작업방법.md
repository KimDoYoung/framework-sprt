## 공통 절차와 다른 점
- **입력 형식 오류**: AS-IS는 기준년월이 `yyyy.MM`이 아니면 GWT 예외로 멈춘다. TOBE는 "기준년월을 yyyy.MM 형식으로 입력하세요." 안내를 띄운다(`-`도 `.`로 읽는 AS-IS 동작은 유지).
- **회사 조건**: AS-IS `deleteJournalBiz`의 "그 밖" 분기는 화면이 보낸 `journalId`를 믿는다 — TOBE는 로그인 회사의 전표만 지운다.
- **예금원장 정리**: AS-IS `ast.Ast06_Tr.updateDeposit`(`ast09_book.createDepositBook`, 결과 무시) 대신 U01의 `POST ast/books/deposits/clean`을 같은 날짜(기준월 1일)로 부르고 실패는 무시한다.
- **서버 경계**: 행의 `trCode`·`note`·`date`·`payMonthCode`는 AS-IS처럼 화면에서 받는다(회사·사용자는 로그인 값).
- 공통 부품 변경 없음. `tools/page-style-check.py` GG 점검 대상에 이 화면 추가.
