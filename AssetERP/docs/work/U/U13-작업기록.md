## 막힌 점
- 첫 `compare`에서 API 33건 vs SQL 28건: `crd01_bank_cd LIKE '%'`가 은행 코드 NULL인 카드를 거른다는 걸 모르고 "늘 전체"로 보고 조건을 뺐다. AS-IS 조건대로 되돌려 해결 — 이식할 때 늘 참인 것처럼 보이는 `LIKE '%'`도 NULL을 거른다.

## 제안 (사용자 승인 전에는 반영하지 않음)
- 은행 코드가 없는 카드(33장 중 5장)는 어느 조건에서도 목록에 나오지 않아 화면에서 고칠 수 없다. 새 카드를 만들 때 카드회사를 필수로 하거나 `LIKE '%'` 조건을 빼는 것을 검토.
- 사용자 그리드는 카드를 저장한 뒤에만 쓰게 막았다(AS-IS는 카드 ID 없는 이력이 저장될 수 있음) — 이 막음은 AS-IS와 다른 동작이므로 승인 필요.
