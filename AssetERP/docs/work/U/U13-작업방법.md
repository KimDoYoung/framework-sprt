## 공통 절차와 다른 점
- **사용자 그리드는 저장된 카드에서만 쓴다**: AS-IS는 저장 전 새 카드(카드 ID 없음)에서도 켜져 카드 ID 없는 이력이 저장될 수 있다. 저장 전(임시 ID)이면 그리드를 막았다 — 개선이라 `작업기록`에 제안으로 남긴다.
- 저장 뒤 카드사용자 열: AS-IS는 selectById에 그 열이 없어 비워졌다. 화면이 이전 값을 유지한다(저장이 바꾸지 않는 값).
- 열 이름: 비교 도구는 날짜 열을 `frDt/toDt`로 보지만 원본 모델 속성은 `frDate/toDate`라 DTO가 원본을 따른다.
- 서버가 믿는 값: 회사·카드 소유는 로그인 값으로 다시 확인한다.
