## 제안
- yunhee `page-style`: 아래 `*_Edit_*`에 저장 버튼([저장]이 `update()`를 부름)이 있으면 SGVF가 아니라 SGEF로 판별하면 좋겠다 — 지금은 편집형도 SGVF로 읽는다.
- SGVF 점검 규칙(`tools/page-style-check.py SGVF`)이 없다(`KeyError`). SGEF 규칙으로 대신 확인했다.
- `mapper-run`: `foreach` 파라미터(`ids=1,2`)를 받으면 삭제 문장도 롤백 시험할 수 있다.
- UX보강 제안: 이 화면은 완료/반려건 제외 체크 상태가 바뀌어도 자동 조회하지 않는다(원본 그대로). 필요하면 사용자 판단.
- 부품 제안: "표시 칸 + 돋보기 + 값이 있으면 x"는 `LookupInput`이 있지만 직접 입력도 되는 칸(지급요청계좌)은 antd `Input suffix`로 만들었다(이번 1회). 세 번째 쓰임이 생기면 부품 후보.
