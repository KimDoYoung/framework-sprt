## 공통 절차와 다른 점
- 색인이 "도달 불가"로 표시한 E3(`toggleGroup`)은 라디오가 툴바에 직접 붙어 있어 **도달 가능**하다(월별/분기별 클릭 → 월·분기 콤보 전환 + 조회). 라디오·콤보 초기 "비활성"은 `setEnableFalse()`의 호출을 색인이 선언 시점으로 읽은 것으로, 처음에는 모두 사용 가능하다.
- AS-IS는 화면을 열 때 `settings()`(보고주기 읽기)와 `retrieve()`를 동시에 부른다. 보고주기가 없으면 `apprChk(null)`에서 NPE로 끊기는 경쟁 상태라, 보고주기를 먼저 읽고 없으면 안내만 하고 조회하지 않는다.
- 실거래일 점검(E27)에서 계좌개설일(`accountSetupDate`)은 계좌정보 조회창에서 계좌를 고른 뒤에만 채워진다. 원본은 그 전이면 `Date.before(null)`로 NPE라 점검이 통째로 끊긴다 → TOBE는 알 수 없으면 그 한 가지만 건너뛰고 영업일·보고기간 점검은 한다.
- `sys12_calendar.selectByDay`는 원본 SQL에 회사 조건이 없다(사용 중인 첫 회사의 일자) — 그대로 옮기고 작업기록 "제안"에 올렸다.
- 삭제 뒤 원본은 `insertFloorTrBook()`과 `retrieve()`를 동시에 부른다 → TOBE는 원장반영이 끝나면 한 번만 조회한다.
- 엑셀업로드: 원본은 파일을 폼 제출로 보내고 응답 글자 "Y"를 확인한다 → TOBE는 `POST /flt/real-trs/excel`(성공 건수) + 오류는 서버 메시지. 종목유형을 못 찾으면(원본은 NPE) "종목유형코드(x)를 찾을 수 없습니다" 메시지.
- 저장(n) 버튼은 변경이 0건이면 눌리지 않는다(UX-03) — 원본의 "저장할 내역이 없습니다."는 `updateCheck10()`에 남겼다.
