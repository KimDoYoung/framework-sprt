## 제안 (사용자 승인 전 반영 안 함)
- 원본은 열 때 `toolBar.refresh()`를 부르지만(기준일 파라미터가 없어 빈 결과), TOBE는 D08처럼 열 때 조회하지 않는다.
- 기본 기준일(오늘)은 `MAX(std_date <= 기준일)`로 마지막 적재분(2023-05-26)을 보여 준다 — 원본 SQL 그대로.
- 목록이 행마다 소스 전문(text)을 싣는다(원본도 `icam50_source.*`). 300행이면 응답이 큰데, 보기 때 단건 조회로 바꾸면 줄지만 원본 구조라 그대로 둠.
