## 화면 구성
- 위: `SearchBar` = 기준일자(`DatePicker`) · 서버(`Select`) · 소스(`Select`) · 검색(`Input` 소스명, `Input` 소스내용) + 조회 + [ICAM DB소스 가져오기](extra). 아래: `SingleGrid`(행번호, 체크박스 없음, 8열: 기준일·서버·OWNER·구분·소스명·보기 아이콘·라인수·작업일시) + `PagingToolBar`(300).
- 버튼 type: 조회 `search`, 가져오기 `download`(D07·D08과 같음), 소스내용 창 닫기 `close`.
- `sourceId`는 numeric(18자리)라 문자열로 내린다(05 §6). 보기 아이콘은 `iconCell('view')`.

## 공통 절차와 다른 점
- 기존 `biz.icam`에 `IcamSourceController/Service/Mapper` 추가, `IcamBatchRunner`에 `runSource` 추가(구현은 `DisabledIcamBatchRunner` 하나뿐).
- 회사 컬럼이 없는 테이블(전역 데이터)이라 회사 조건 없음.
