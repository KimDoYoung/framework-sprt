- **제안(원본 동작, 반영 안 함)**: 원본이 서버 경로 앞 17자·뒤 7자를 잘라 고객을 뽑는 방식이라, 운영 경로 `/data1/IDMS/docs/`가 아니면(개발 서버 `/data1/IDMS_dev/docs/`, 실제 TOBE 업로드 경로 등) 이 화면이 비어 보인다. 고객 서브도메인을 경로 끝에서 두 번째 폴더로 뽑는 식으로 바꾸거나 `sys10_file`에 고객 컬럼을 두는 방법이 있다(DB는 못 바꿈, 03 원칙 1). 사용자 결정 필요.
- **미확인**: 데이터가 있는 상태에서의 화면 렌더링(연도·월 그리드 선택·표시). DB에 경로 형식이 맞는 행이 없고, 시험 행을 실제로 커밋하는 것은 하지 않았다(03 원칙 2는 허용하지만 yunhee `sql`은 롤백 전용). C05의 같은 구조는 데이터로 확인했다.
- **참고**: 단위 `MB`라고 적혀 있지만 SQL은 `SUM(sys10_size)*0.001`(KB로 저장된 크기를 ×0.001)이다. 그대로 옮김.
