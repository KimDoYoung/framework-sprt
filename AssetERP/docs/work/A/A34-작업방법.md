## 화면 구성
- 왼쪽(860, 분할) = `SearchBar`(분류 콤보 `SystemCodeComboBox(ManualType, 전체)` · 검색어 · 조회·초기화) + 저장(n) · 파일업로드 · 분류추가, `CellEditGrid`(행번호, 단일 선택, 6열: 등록일 90 · 분류 100(select 편집) · 파일명 300 · 공개 50(체크 편집) · 비고 250(편집) · 다운로드·삭제 아이콘 30). 오른쪽 = `Sys95_PDFViewer`(처음엔 `empty` 안내, 조회 뒤 `none`/PDF).
- `Sys09_Lookup_Code`(components/lookup, 모달 650): 행 추가·행 삭제·새로고침 + 코드·코드명·조회순서 편집 그리드 + 저장·닫기. 삭제는 목록에서만 빼고 deleteList에 모았다가 저장 때 보낸다.
- 버튼 type: 조회 `search`, 저장 `save`, 파일업로드 `upload`, 분류추가·행 추가 `addRow`, 행 삭제 `removeRow`, 닫기 `close`.
