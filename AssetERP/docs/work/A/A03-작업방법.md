## SQL 이식
| SQL | 그대로 / 수정(사유) |
|:---|:---|
| selectByRoleId / selectById | 조건·정렬 그대로(오늘 기준 최신 발령, 그 발령일의 조직 이름, org_cd·f_org_seq·직책·직위 순서). SELECT는 그리드 컬럼 + authOrgId·authOrgNm |
| update | 화면이 바꾸는 컬럼: user_id, role_id, auth_org_id. 신규는 f_create_seq. 권한그룹·사원이 로그인 회사 것인지, (사원, 권한그룹) 유일 인덱스 중복은 미리 세어 막음(05 §6) |

| emp03_trans.selectByText | 그대로(`UPPER(CONCAT(이름, 조직명, 사번)) LIKE UPPER(…)`, 겸직 포함·퇴직 제외, 겸직 기간 NOT EXISTS). SELECT는 사원찾기 컬럼 + personId·orgCodeId |
