## SQL 이식
| SQL | 그대로 / 수정(사유) |
|:---|:---|
| `selectByCompanyIdAll` | 조건 그대로(sys06_menu LEFT JOIN sys03_company_menu(그 회사), sys06_use_yn 조건 없음, 부모별 sys06_seq·sys06_menu_nm 순). AS-IS는 부모마다 SQL을 다시 부른다(665개 메뉴 → 665번) → **한 번에 읽고 서비스가 전위 순서로 편다**(같은 순서). 루트에서 닿지 않는 메뉴는 AS-IS처럼 안 나온다 |
| 회사·메뉴 연결 중복 | DB에 같은 회사·메뉴 연결 행이 3쌍 있다. 트리 행 ID가 메뉴 ID라 하나만 쓴다(작은 sys03 ID). AS-IS는 같은 메뉴가 트리에 두 번 나왔을 것 |
| `updateCompanyMenu` | UpdateDataModel(sys03_company_menu) → 연결 없으면 채번 INSERT(company, menu, use_yn), 있으면 use_yn UPDATE(+회사 조건) |
