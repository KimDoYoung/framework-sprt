## 공통 절차와 다른 점
- 원본 결함·특이 동작은 그대로 옮기고(03 원칙 4) 작업기록에 "제안"으로 남긴다: ① updateByMenuYn(일괄)의 권한삭제는 같은 부모의 사용 중 형제(자기 포함)가 있으면 자기 행을 바꾸지 않는다(countUseYn에 menuId 조건 없음) ② Sys01_Company.updateByMenuYn은 menuYn true면 기존 행이 있어도 새 행 INSERT(DB에 이미 중복 3쌍) ③ 메뉴 삭제가 자식·연결 행을 남긴다 ④ 이동이 자기/자손 대상도 허용.
- search()의 null 언박싱 예외는 옮기지 않는다(위 E1).
