## 남은 문제
- 편집 칸은 원본처럼 높이 400 안에서 세로 스크롤이다(줄 사이 여백 20, 계좌 그리드 150) — 계좌 첫 행이 스크롤해야 온전히 보인다. 원본과 같은 구조라 그대로 두었다(UX보강 제안으로 남김).
- admin 회사(#1155, 고객사 칸·기초데이터생성 버튼)는 화면으로 확인하지 못했다. API(`POST corps/init-data`: 일반 회사 403, 미선택 400)와 서버 테스트(관리자 회사 0 거래처 복사)로만 확인.
- 7-1 그리드 기본 점검의 정렬 표시는 직접 보지 않았다.
- 원본 필드 `companyId` 초기값을 색인이 잘라 보여 주지 않아, 고객사를 고르지 않고 기초데이터생성을 누르면 TOBE는 "고객사를 선택해주세요"(400)로 막는다(원본은 DB 오류 문구일 가능성).
