- 스타일 SGP: 바깥 `padding 20`, 세로 flex `gap 8`, `SearchBar`(분류 `LookupInput` 300 · 검색 250 "분류/점검내용/설명" · [조회] + extra [등록][삭제][사용여부설정][담당그룹 지정]) + `MultiGrid`(행번호 · 체크). 편집 팝업·조회창은 화면 끝에 붙인다.
