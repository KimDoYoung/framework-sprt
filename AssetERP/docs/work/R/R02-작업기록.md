## 제안 (사용자 승인 전에는 반영하지 않음)
- 원본 `selectByPersonId`는 `searchText`·`useYn`을 받지만 SQL이 쓰지 않아 **검색칸이 동작하지 않는다.** 필요하면 분류/점검내용/설명 검색 조건을 SQL에 더한다(지금은 원본 그대로).
- 원본 `updateAnswerCode`는 `chk03_answer_datetime`에 점검일자(`date`)를 넣는다(INSERT는 현재 시각) — 답변일시가 갱신 때는 날짜 0시가 된다. 의도라면 그대로, 아니면 `now()`로.
- 작성 행을 지우는 기능이 이 화면에 없어 API 쓰기 시험을 못 했다(시험 행이 남음). 일괄 시험 때 담당자 테스트 계정이 있으면 쓰기까지 본다.
