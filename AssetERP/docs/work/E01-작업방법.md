## SQL 이식
- `${companyId}`·`${parentId}` → `#{…}`, `common.rownumLimit1` → `LIMIT 1`, `COLLATE "ko_KR.utf8"` → `"ko-KR-x-icu"`, 공통 CTE(`ics_tree_all_postgresql`·`icsTreeDown`)는 매퍼 안에 펼침. 모두 `sql-check --tobe` ✅.
- `selectById`는 쓰지 않는다(저장 뒤 열 전체를 `refresh`로 다시 읽어 돌려줌 — 원본은 `selectById` 결과(주기·서식파일·개정이력·연결책무 열 없음)로 행을 바꿔 저장 직후 그 열이 비는 것을 고침. 작업기록 결정).

## 공통 절차와 다른 점
- 새 도메인 패키지 `biz.ics`, `biz.tdm`(연결책무). `useGridCrud.replaceRow`·`iconCell('move')` 신설(05 §5 등록).
- 쓰기는 모두 관리자 회사만(서버 보안 보강, 원본은 메뉴가 admin 회사에만 있어 막힘).
- 셀 편집 `법규명`·`제출처`·`관련조문`은 `largeText`(원본 TextArea), 상세내용은 읽기 전용 줄바꿈(높이 300에서 자름 = `addTextLimitArea`).
