## 공통 절차와 다른 점
- **본문 값은 서버가 행 번호로 다시 읽는다**(V22와 같은 원칙). AS-IS는 D01의 값을 그리드 셀을 클릭할 때 전역(`TempData`)에 넣어 두었다가 결재창이 읽는다(이상한점 #53) — TOBE는 [상신]한 행의 연봉을 읽는다.
- D01 양식이 둘 이상이면 AS-IS는 결재창을 먼저 열고 그 위에 고르는 창을 띄운다. TOBE는 **고른 뒤 결재창을 연다**(결재창의 본문을 밖에서 바꾸는 길이 없다). [닫기]하면 양식을 고르지 않은 채 결재창이 열려 본문은 문서분류의 대표 양식이다(AS-IS도 본문이 안 채워진다) — 이상한점 #52.
- 문서분류가 여러 개 연결돼도 AS-IS처럼 결재창을 여러 개 열지 않고 첫째만 쓴다(#51, V18 `Pay10_TabPage_Retire`와 같음).
- X01의 `Sys99_Print` 행은 클라이언트가 읽어 넘기는 대신 `link-seed`가 발급 행 ID로 서버에서 읽는다. 발급 행의 기준연도 `stdYear`와 사원 ID는 서버가 행에서 꺼낸다.
- 숫자 서식은 `NumberFormat.getIntegerInstance(Locale.US)`(`###,###,###`와 같음).
- `Seed`: D01은 `Seed.of`(읽기전용·저장 숨김·시행일자 오늘), X01은 제목 편집 가능·수신 = 신청 사원·저장 숨김.
