## 공통 절차와 다른 점
- AS-IS는 창을 열 때 클라이언트가 제목·본문을 만든다. TOBE는 DB 행과 HTML을 **서버가** 만들어 한 번에 돌려준다(본문 문자열은 원본 이어 붙이는 순서까지 그대로 — `tr` 열고 닫는 위치가 어긋난 것도 그대로, 이상한점 #40).
- 제목 읽기전용·[저장] 숨김은 provider가 정한다(`Seed.of(title, content)` 기본 = 읽기전용·저장 숨김, A25는 제목 편집 가능·저장 숨김).
- 링크 문서에는 `link` prop을 쓴다. 문서 열기 효과(`useEffect`)는 `openNew` 뒤 `linkSeed`를 불러 `form`에 제목·본문·시행일자를 넣고 `doc.linkCode`를 정한다(저장 요청이 `linkCode`를 같이 보낸다).
- 이미 상신한 행(`apprId`)은 `apprId`로 연다(V01 문서 읽기). 임시저장(99) 링크 문서를 다시 열 때의 제목 잠금은 AS-IS `retrieveApproval`의 기존 동작을 따른다(V07).
