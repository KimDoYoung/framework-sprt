## 공통 절차와 다른 점
- **본문 재료를 서버가 읽는다**(V30과 같음): 원본은 그리드 모델 `Sch04_ListModel`을 넘겼고 TOBE는 `ids`만 받아 같은 열을 다시 읽는다. 호출 화면이 retrieve로 다시 읽은 직후이므로 값은 같다. 결과 순서는 `ids` 순서(그리드 순서)로 맞춘다.
- 값이 null이면 자바 문자열 이음처럼 `null`이 본문에 찍힌다(분류명·비고 등) — 원본 그대로. A80의 `checkNull`만 공백.
- 문서분류가 없을 때(A31): 원본은 `classTreeModel`이 null이라 `insertLinkApprovals`가 NullPointerException으로 아무것도 안 연다 — TOBE는 안내 메시지 하나(이상한점 #69).
- 스타일: 두 화면 모두 `_Tab_`인데 `page-style --compare`가 불일치다(Sch04 AS-IS SGP / TOBE CG, Sys53 AS-IS SG / TOBE CG). 03 원칙 22 ④(다시 건드릴 때 견본에 맞춘다)에 따라 바깥 여백 20·안쪽 padding 10·테두리 없음·gap 8의 공통 틀만 맞췄다(Sch04의 안쪽 테두리 제거, Sys53의 바깥 여백 8→20·`#fff`). 판별기는 셀 편집 그리드·편집 팝업 유무로 갈라서 그대로 불일치 — 사유를 결과확인 13에 적는다.
