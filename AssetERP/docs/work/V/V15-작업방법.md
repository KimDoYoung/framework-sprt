## 왜 나눴나
- if-else 가지가 약 75종(A01~A94, B01~B16, C01, D01, X01). 가지마다 다른 도메인의 행 모델·서비스·HTML 클래스를 쓴다.

- 그래서 도메인 묶음마다 "그 화면의 단추 + 본문 생성 서버 API + 이 창 열기"를 한 ID로 만든다. 공통 뼈대는 V17이 첫 코드와 함께 만든다.
