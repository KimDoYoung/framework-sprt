## 공통 절차와 다른 점 (12 원칙 §적용·03 원칙 17)
- 03 원칙 17: 결재선에 사원을 넣는 위치는 항상 **맨 아래**(원본 `GridInsertRow`는 선택 행 아래).
- 아이콘 열은 행을 선택하지 않으므로 누른 줄로 처리(이상한점 #21).
- 결재요청 순서: 원본은 "결재권자 없음 확인 → 입력 검사 → 의견 창"이고 TOBE는 "입력 검사 → (결재권자 없음 확인) → 의견 창"이다. 확인은 서버도 되묻는다(`notice=confirm`).
- 대외문서 저장은 인감 선택(V05) 없이는 "대외문서는 인감선택이 필수입니다"에서 멈춘다.
- 신규문서 작성 시 `dcr.Dcr08_OftenUse.insertUpdate`(최근 사용 횟수)는 아직 올리지 않는다.
- 상세 열기에서 편집 모드 판정은 서버 `action-state`가 아니라 문서 상태(99)와 등록자로 한다(저장·삭제는 서버가 같은 조건으로 다시 막는다, V03).
