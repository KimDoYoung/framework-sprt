## 공통 절차와 다른 점
- [등록(복사)]: AS-IS는 줄을 그리드에 넣고 바로 저장(저장 응답은 안 읽음). TOBE는 바로 저장 뒤 목록을 다시 읽고, 고친 내용이 있으면 "저장 후 복사해 주세요"로 막는다. 이상한점 #103.
- 저장 전 새 줄의 영수증 [등록]은 "저장 후 영수증을 등록하세요"(AS-IS는 ID 없는 줄에 올려 부모 ID 없이 올라감).
- 영수증이 없는 줄의 [삭제] 아이콘은 "삭제할 영수증이 없습니다".
- 선택 없이 [삭제]는 경고만(05 §8). 상신·마감 검사와 필수 칸 검사를 서버도 한다.
- 영수증 보기: AS-IS는 파일 ID만 넘기고 화면이 확장자를 읽지만, TOBE 뷰어는 파일 정보를 받아 `fileApi.searchByParentId`로 읽어 넘긴다.
