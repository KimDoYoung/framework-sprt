## 공통 절차와 다른 점
- **첨부 엑셀은 원본과 같은 열·스타일(HSSF `.xls`, 머리 연노랑, 합계 줄 굵은 위 테두리)로 만들되 파일 저장은 TOBE의 `SysFileService.registerRdFile`을 쓴다**(원본은 `IdmsConfig filePath/위치/yyyyMM/파일ID`에 직접 쓰고 `sys10_file.insertUpdate`) — 폴더 규칙·행 INSERT가 같아야 하므로 V25 PDF와 같은 길.
- **엑셀 생성 시점**: 원본은 결재창 저장 직후(문서 ID가 있는 상태), TOBE는 호출 화면이 결재창 저장 뒤 `POST biz/relate-apprs/person`을 부를 때. 첨부 엑셀의 조건(기간·검색어)은 [상신]을 누른 시점 값(원본 `printModel`)이다.
- B15·B16·A10~A12는 시험 DB에 양식(`com10_form_mapping`·`dcr30_link`)이 없어 본문이 비어 나온다(원본도 양식이 없으면 `checkContent(null)`). 치환 자체는 롤백 테스트에서 양식·링크 행을 임시로 만들어 확인했다.
- 스타일: 세 화면 모두 이미 변환된 화면이라 레이아웃은 건드리지 않았다(`page-style --compare` 일치: SGP·SGHF·SGP).
