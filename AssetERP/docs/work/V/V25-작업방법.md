## PDF 엔진 (공통 부품, 새로 도입)
- 의존성: `org.xhtmlrenderer:flying-saucer-pdf-openpdf:9.4.0`(OpenPDF 포함) + `org.jsoup:jsoup:1.17.2`(느슨한 HTML → XHTML 정리). AS-IS는 iText 5.5.13 + iText 7.1.9(html2pdf)로 AGPL.
- `common.pdf.HtmlPdfRenderer { byte[] render(String html) }` — 만드는 쪽은 HTML만 넘긴다. 쪽 크기·여백·쪽 번호는 HTML 안 CSS `@page`로 정한다(Chromium 기반 Gotenberg도 같은 CSS를 따른다). 기본 구현 `OpenPdfHtmlRenderer`. **Gotenberg로 바꾸려면 이 인터페이스를 구현한 빈 하나로 갈아 끼우면 된다(만드는 쪽 변경 없음).**
- 설정 `asseterp.pdf.font-file`(AS-IS `fontPath/NotoSansKR-Regular.ttf`, 로컬 `${asseterp.base.dir}/fonts/`에 복사해 둠 — **배포 서버에도 글꼴 파일이 있어야 한다**)·`asseterp.pdf.doc-prefix.{지역}`(AS-IS `{지역}.docprefix`, idms-REAL의 10곳).
- 파일 저장은 기존 `SysFileService.registerRdFile`(RD 파일 옮기기, 새 파일 ID·`sys10_file` 행) 재사용.

## 공통 절차와 다른 점
- 구분명은 화면이 보낸 글자를 믿지 않고 서버가 상신 행(`pay05`)의 구분·지급일로 만든다(V22와 같은 원칙).
- PDF는 HTML 변환기가 iText html2pdf → Flying Saucer로 바뀌어 **모양이 조금 다를 수 있다**: 열 폭 고정(`table-layout: fixed`, 원본 표의 첫 빈 행이 정한 폭)을 CSS로 더했고, 쪽 번호는 아래 가운데에 둔다(원본은 가로 용지에서 왼쪽 치우침 — 이상한점 #48).
- 상신 행·PDF를 한 번에 만든다. PDF 오류는 AS-IS처럼 상신을 막지 않고 로그만 남긴다(#50).
- 원본의 닫히지 않은 `<tr>`(#47)은 본문에 그대로 둔다(결재창 편집기는 허용). PDF 쪽 HTML은 jsoup이 정리해서 변환한다.
- 합계 계산에서 null은 0으로 본다(AS-IS 모델 getter 기본값).
