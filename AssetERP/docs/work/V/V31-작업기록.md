## 한계 / 넘긴 것
- **브라우저에서 결재창을 열어 본 적은 없다**(화면 시험 지연 규칙). 본문 HTML은 문자열 단언과 `link-seed` 응답으로만 확인했다.
- 로컬 DB에서 `dcr30_link`에 A31·A80이 각 1건씩 있다(회사 28000). 문서분류가 없는 회사의 동작(A31 안내 / A80 빈 `Dcr01_Lookup_Class`)은 코드로만 확인.
- A31 `selectLinkRows`는 `foreach`라 `mapper-run --compare`로 AS-IS와 못 붙였다 — 같은 행의 분류명·처리결과명을 `yunhee sql`로 대조했다. 데일리 체크 일정이 공모주(`sch04_schedule_cd = '5'`)인 행의 `공모주` 분류는 시험 데이터가 없어 코드로만.
- `insertScheduleApproval`(일정 점검 상신 진입)은 대응 ID가 없다. 호출하는 화면이 TOBE에 생기면 그때 만든다.
- 이 ID 이전부터의 화면 구성 차이는 건드리지 않았다: `Sch04_Tab_DailyCheckList` 버튼 3/2(E8 [문서분류지정]은 툴바에 안 붙어 도달 불가), 이벤트 12/11.
