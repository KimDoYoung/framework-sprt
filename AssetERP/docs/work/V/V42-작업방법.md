## 공통 절차와 다른 점
- 삭제: AS-IS는 선택 행 하나의 상태만 화면이 검사했고 TOBE는 서버도 같은 검사를 한다. 선택이 없을 때 AS-IS는 오류 — TOBE는 안내.
- 결재창 제목은 AS-IS가 신청 창에서 만들어 행에 얹던 것을 서버(`BenefitLinkSeedProvider`)가 만든다. 사원명은 로그인 이름.
- 신청구분을 고르지 않고 [상신] → AS-IS NPE, TOBE 안내(이상한점 #99).
