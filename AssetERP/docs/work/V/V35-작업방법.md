## 공통 절차와 다른 점
- `CarJournalHtmlData`의 static `totalMileage`는 다 만든 뒤 `null`로 둬 같은 서버에서 두 번째 PDF는 NPE다 → TOBE는 지역 합계(이상한점 #84). 주행거리·첫 행 주행 전 거리가 `null`이면 AS-IS도 NPE로 파일을 못 만들어, TOBE도 파일을 만들지 않고 로그만 남긴다(상신은 이어진다).
- `"1".equals(getCloseYnText())` 갈래는 `getCloseYnText()`가 "마감"/" "라 항상 거짓 — 그대로 항상 아래 갈래(출퇴근 0·일반업무용 = 주행거리·비업무용 0)로 옮겼다(#85).
- 쪽 번호는 아래 가운데(AS-IS는 세로 폭 기준 x라 가로 용지에서 왼쪽으로 치우침, V25 #48과 같다).
- C01 본문 `계약회사대표이사`는 `ceo + "       (인)"` 그대로라 대표이사가 비면 `null       (인)`(원본 그대로).
- `CarJournalApprMapper`의 파일 연결 3문장은 V32·V34와 같은 식의 네 번째 복사다(부품 후보 — 작업기록 제안).
