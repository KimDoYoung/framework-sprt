## 공통 절차와 다른 점
- 새 출장은 저장 전이라 출장 ID가 없어 공유대상 창을 열 수 없다 — AS-IS는 ID 없이 열어 공유 행이 부모 없이 저장된다(이상한점 #100). TOBE는 "저장 후 목록의 공유 아이콘에서 공유대상을 지정해주세요" 안내.
- 삭제: AS-IS는 첫 선택 행의 상태만 검사했고 TOBE는 선택한 행 전부(화면+서버)를 검사한다. 선택이 없을 때 AS-IS는 오류 — TOBE는 안내.
- 공유 행 저장·조회·삭제는 부모 출장이 로그인 사원의 것인지 서버가 확인한다(`EmpShareService.requireOwnTrip`). 외출(Y04, `emp54`)이 같은 창을 쓰게 되면 그때 부모 확인을 넓힌다.
- `Emp56_Lookup_Share.view()`(읽기 전용 모드, [새로고침] 버튼)는 이 화면에서 쓰지 않아 만들지 않았다 — 버튼 수 5/4는 그 때문.
