- Q04의 [수요예측 참여] 아이콘을 이 ID에서 연결한다(`Sch10_Tab_Ipo.tsx`, `insertWith` 모드) — Q04가 남긴 연결 지점. 납입일자(`payDate`)는 창에 없지만 AS-IS `UpdateDataModel` INSERT가 모델의 다른 값도 쓰므로 저장 요청에 담는다.
- 신규 `cancelYn`: AS-IS 신규 창에는 참여취소 칸이 없어 모델 값이 비어 있지만 TOBE는 'false'를 저장한다(조회는 `COALESCE(…,'false')`라 같다).
- 삭제 검사: AS-IS `deleteCheck()`는 루프 안에서 "선택 없음"을 검사해 빈 선택이면 빈 확인창이 뜬다(결함) → "삭제할 정보를 먼저 선택해주세요"만 띄운다(03 원칙 4의 예외가 아니라 05 §8 "원본과 일부러 다르게 둔 것 ②"와 같은 처리).
