## 제안 (03 원칙 5 — 사용자 승인 전에는 반영 안 함)
1. 태그 목록: AS-IS는 용역계약체결(Q09)·용역결과보고서(Q12) 화면이 열릴 때 `TempData.setPfContractMappingList01/02`로 목록을 바꿀 수 있다(비면 기본 8개). 지금은 기본 목록만 쓴다 — Q09·Q12 분석 때 그 목록이 무엇으로 채워지는지 보고 `com11Tags.ts`에 연결한다(`utils/tempData.ts`의 `TempData.publish/subscribe`로 할 수 있다).
2. 양식 창 `HtmlEditor`는 굵게·기울임·밑줄·취소선·목록만 있다(11 §3) — 기존 DB 양식(4~4.4KB)에 표·글꼴 색이 있으면 편집 후 사라질 수 있다. 새 DB 양식 4건(`com11_form_mapping_multi`)이 어떤 태그를 쓰는지 화면 시험 때 확인.
3. 사용중 검사 결과(`checkList`)는 원본이 ID 목록만 보고 판단하는데 서버가 용역계약 전체 행을 돌려준다 — TOBE는 건수만 돌려준다(결과 같음).
