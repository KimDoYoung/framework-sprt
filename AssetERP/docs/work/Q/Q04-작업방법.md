## 화면 구성
- 바깥 20 여백 + 테두리 박스. 툴바 1줄 `SearchBar`(조회일자 [콤보·시작~종료]·시장구분·검색 250 "종목명/주간사"·☐ 관심종목만 보기 · [조회][출력/다운로드][DART 바로가기]) + 툴바 2줄([관심종목 등록][관심종목 제거][공모주 달력] + 파란 안내 2줄 12px) + `MultiGrid`(체크 다중, 1~3열 고정 `pinned: 'left'`, `selectionColumnDef={{pinned:'left'}}`, 2단 헤더 수요예측일정·청약일정).
- 그리드 열(20개): 관심 60·시장구분 100·종목 250(고정) / 수요예측 시작일·종료일 95→90 / 청약 시작일·종료일 95→90 / 납입(환불)일 120→90 / 수요예측 참여 아이콘 60 / 청약 운용지시 아이콘 60 / 상장(예정)일 120→90 / 희망공모가 120 / 공모가 80(굵게) / 주간사 250(줄바꿈) / 바로가기 아이콘 60 / ICAM 청약률(%) 80 / 일정공유 150(헤더 0069B4) / 공유 아이콘 30. 날짜 열(AS-IS 95·120)은 읽기 전용이라 UX-08에 따라 모두 90으로 한다.
