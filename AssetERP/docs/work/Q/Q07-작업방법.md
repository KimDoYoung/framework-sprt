## 공통 절차와 다른 점
- 엑셀 개설일자: 원본은 글자를 `yyyy-MM-dd`로만 읽어 날짜 서식 셀이면 읽기 오류(`ParseException`)로 끝난다. TOBE는 날짜 서식 셀도 읽고, 못 읽으면 "n행의 개설일자를 읽을 수 없습니다. (yyyy-MM-dd)" 안내(400).
- 템플릿 xlsx는 새 원본에 없어 옛 원본 트리에서 복사(Q06 작업방법과 같다).
- [등록(복사)]는 원본에서 새 행이 변경 표시 없이 DB에 저장된 채 그리드에 남는다 → TOBE는 서버 저장이 끝난 뒤 저장된 행(실제 ID)으로 넣는다.
- 저장은 원본 `update()`가 성공 뒤 `retrieve()`를 하므로 `reloadAfterSave: true`.
