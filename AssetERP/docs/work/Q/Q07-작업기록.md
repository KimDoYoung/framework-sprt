## 제안 (03 원칙 5 — 사용자 승인 전에는 반영 안 함)
1. 원본 `accountCode1ComboBox.Collapse`(L253-260)가 고른 이름을 `accountName1`이 아니라 `accountName2`에 넣는다 — 운용대상을 고르면 구분 열의 글자가 같은 이름으로 바뀐다(저장되는 코드는 맞고 저장 뒤 다시 조회하면 제대로 보인다). 그대로 옮겼다 — 고치려면 `codeCol('accountName1', …)`의 `sideEffect`를 지우면 된다.
2. [등록(복사)]는 원본이 복사본을 변경 표시 없이 곧바로 DB에 저장해 [저장]을 누를 필요가 없고 취소할 수도 없다. 그대로 옮겼다.
3. `compare`가 그리드 열 이름을 `accountNm1`·`accountNm2`로 추정해 "missing" 경고를 낸다(모델 속성은 `accountName1`·`accountName2`로 API 필드와 일치) — yunhee 개선 후보(숫자 접미 이름).
