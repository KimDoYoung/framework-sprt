## 제안 (03 원칙 5 — 사용자 승인 전에는 반영 안 함)
1. 결재 아이콘의 `statusCheck()`는 원본이 아래 목록(선택 행)을 보므로 다른 행의 결재 아이콘을 누르면 선택 행의 상태를 검사하는 허점이 있다 — TOBE는 누른 행으로 다시 읽어 검사했다(작업방법에 적음). 원본 동작이 필요하면 알려 달라.
2. 첫 조회에서 행이 없을 때 원본은 NPE(`getSelectedItem()`) — TOBE는 목록을 비운다.
3. Q09 제안과 같이 `TempData` 태그 양식 키는 Q12(`createMapping` L278-290)에서 `용역 수행계획` 대신 `용역 수행내역`·`첨부파일`을 채운다 — 값이 다르므로 결재 연결 단계에서 양식 태그 목록을 용도별로 나눠야 한다.
