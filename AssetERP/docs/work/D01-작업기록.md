## 제안 (사용자 승인 전 반영 안 함)
- **계정PW 저장이 원본에서도 안 된다(결정 필요)**: 편집 폼의 계정PW(`localPwDec`·`targetPwDec`)는 컬럼이 아니라 UpdateDataModel이 저장하지 않고 `*_pw`는 읽은 값을 되쓴다. 화면은 "저장이 완료되었습니다."라고 하지만 저장 뒤 PW가 원래 값으로 돌아온다(TOBE는 서버가 돌려준 행을 다시 보이므로 즉시 보임, 원본은 다음 조회에서 보일 듯). 고치려면 INSERT/UPDATE에 `ifi90_local_pw = to_encrypts(#{localPwDec})`·`ifi90_target_pw = to_encrypts(#{targetPwDec})`를 넣고 요청 DTO에 PW를 받는다. DB 함수 `to_encrypts`는 있음. 지금은 원본대로(03 원칙 4).
- 계정PW가 그리드·폼에 평문으로 보이고 서버는 로그인만 하면(메뉴 권한 없이도 URL로) 읽고 쓸 수 있다. A31처럼 `ROLE_SYSADMIN`만 쓰기 허용, 조회는 PW를 가리는 방안 검토.
- 원본 `Ifi90_Tab_Config`에는 선택 없이 삭제를 누르면 "삭제대상을 선택하세요"가 나오지만, 단일 선택 체크박스 그리드라 조회 뒤 첫 행이 항상 선택돼 화면에서는 이 문구에 닿을 수 없다(TOBE도 같게 구현만 해 둠).
- `yunhee compare … --grid Ifi90_Tab_Config`가 `missing: ifCd, new`를 낸다(그리드 컬럼이 `ifCode`인데 모델 속성 매핑을 `ifCd`로 읽는 듯) — yunhee 수정사항 후보. API 필드·그리드 컬럼은 직접 대조해 일치.
