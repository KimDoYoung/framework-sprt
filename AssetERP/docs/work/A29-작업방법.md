## 공통 절차와 다른 점
- 원본 `updateRow()`는 본문을 `replaceAll("'", "''")`해서 보낸다(동적 SQL 이스케이프의 흔적). TOBE는 `#{}` 바인딩이라 옮기지 않았다(옮기면 홑따옴표가 두 개로 저장됨) — 제안으로 기록.
- 서버 보강: PUT·DELETE는 이미 있는 행이 **로그인한 회사 것이 아니면 ACCESS_DENIED**(원본은 ID만으로 UPDATE·DELETE). 03 원칙 4의 "SQL을 안 바꾼다"는 지켰고 호출 앞에 검사만 더했다 — 제안으로 기록.
- 발생일자 칸은 지울 수 없게 했다(`allowClear=false`). 원본의 "발생일자를 입력해주세요" 검사는 코드에 남겼다.
- 파일 미리보기는 A30과 같은 한계(변환 서버 의존).
