## 남은 문제
- 시험 중 제외사원 행 `emp28_joint_leave_except_id=202610289018665`(사유 '시험')이 남았다. 시험용 공동연차(2099, ID `202610289018664`)를 먼저 지우는 바람에(제외사원 삭제 호출이 셸 변수 오류로 실패) 부모가 사라져 고아가 됐고, TOBE 삭제는 부모 회사 조건이라 API로는 못 지운다(AS-IS도 부모 삭제 때 제외사원을 지우지 않는다 — `Emp24_JointLeave.delete`). 사용자 확인 후 직접 삭제 필요(`DELETE FROM emp28_joint_leave_except WHERE emp28_joint_leave_except_id = 202610289018665`).
- 시험 중 실수로 실제 행(2025 '테스트')에 제외사원 1건('x')을 넣었다가 같은 세션에 API로 지웠다(확인: 시험 사유 검색에 남은 것 위 1건뿐).
