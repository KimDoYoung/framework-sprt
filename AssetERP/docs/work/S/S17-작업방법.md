## 화면 구성
- `Pay01_Tab_AnnualList`(S14)와 같은 모양: 바깥 20 여백 + 테두리 박스 + SearchBar(해당 연도 · 구분 · 항목 · 검색) + CellEditGrid(체크 다중, 금액 편집). 전체 폭(AS-IS 센터 위젯이 한 개뿐이라 비율 0.4는 무시됨).
- 그리드(`analysis grid`): 사번 100(가운데) · 사원명 150(가운데) · 직급 100(가운데) · 항목구분 150(가운데) · 항목명 250 · 금액 150(long, 편집 `number`), 행번호·체크박스 있음.
- 버튼 type: search / save / generate / download.

## 공통 절차와 다른 점
- AS-IS `update()`는 항상 행마다 서버가 payDate 기준으로 재계산 → TOBE는 서버가 monthId로 급여 행(지급일·사원·회사)을 다시 읽는다(S16과 같음). 클라이언트가 보낸 personId·payDate를 믿지 않는다.
- [저장]의 결재 검사는 AS-IS가 화면에서만 했다 → S16처럼 서버도 같은 `checkAppr`를 한다(TOBE 추가). [일괄생성]은 AS-IS에도 결재 검사가 없어 그대로 둔다. 금액이 비면(null) 서버가 막고, 일괄생성 항목은 `pay20_item`에 있는 구분·코드 쌍만 받는다(TOBE 추가).
