## 남은 문제
- [상신]의 결재문서 작성(상신 행 `Pay05_RelateAppr.insert`·`PDFCreate.createPayMonth10`·`Apr01_Edit_ApprDoc.insertLinkApproval`·`updateApprId`)과 [문서보기]는 다음 단계 — 지금은 검사 뒤 안내 메시지.

- 일반 사원 계정의 메뉴 노출·접근 미확인(8).
