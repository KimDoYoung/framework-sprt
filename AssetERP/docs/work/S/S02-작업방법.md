## 화면 구성
- 바깥 `div` 여백 20 → 테두리 박스(padding 10) → antd `Tabs`(card) 3개: 일반발령 / 자격사항 / 상벌내역. 탭마다 SearchBar(조건 + [조회] + `extra`로 [출력/다운로드]) + `SingleGrid`.
- 일반발령 툴바: 조회기간(~) · 발령구분 100(`EmpTransCode`, 전체) · 검색 200. 그리드 15열(행번호 + 발령일 … 비고).
- 자격사항 툴바: 기준일 · 재직구분 100 · 검색 300. 그리드 10열.
- 상벌내역 툴바: 조회기간(~) · 검색 200. 그리드 7열(수상(징계)사유·처분은 `textArea`).
- 날짜 열은 읽기 전용이라 UX-08(폭 90). RD 미리보기는 하나의 `RdViewer`를 세 탭이 공유.
