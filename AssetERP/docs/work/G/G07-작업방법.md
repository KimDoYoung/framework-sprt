## 공통 절차와 다른 점
- 저장 안 된 새 행의 올리기 아이콘: 원본은 `parentId=null`로 올려 실패 → "변경사항을 먼저 저장 후 진행가능합니다"로 안내.
- 사용가능 부서 팝업 [저장] 뒤 부모 행의 `roleName`은 원본이 `addChange`로 수정 표시를 남기지만, TOBE는 수정 대상으로 표시하지 않고 표시 값만 바꿈(저장 대상이 아니라서, 작업기록 제안).
- 사용가능 부서 팝업 [저장] 뒤 재조회로 새 행의 실제 ID를 받음(원본은 임시 행을 그대로 둠).
- `Org00_Lookup_SelectMulti`의 [전체] 단추(`allButtonYn`)는 만들었지만 이 ID에서는 쓰지 않음.
