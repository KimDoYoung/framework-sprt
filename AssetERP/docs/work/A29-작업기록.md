## 제안 (사용자 승인 전 반영 안 함)
- 원본 `updateRow()`의 `replaceAll("'", "''")`는 옮기지 않았다(바인딩 방식이라 불필요). 원본 DB 본문에 `''`가 섞여 있을 수 있음.
- 서버 회사 검사(PUT·DELETE)는 원본에 없는 보강이다. 관리자(A30) 쪽은 sysadmin 검사.
- 완료 행 삭제 금지는 화면에서만 막는다(원본과 같음). 서버에서도 막으려면 승인 필요.
