## 의존 (사용자 결정 대기)
- **ICAM가져오기 실제 구현**: D07~D10과 같은 외부 ICAM DB 연동(`DatabaseFactoryICAM` → `szx0st`). 지금은 "ICAM 연동(외부 ICAM DB)이 아직 없어 수탁사를 가져오지 않았습니다"만 보인다. D12·D13도 같은 연동일 가능성이 크다.

## 제안 (사용자 승인 전 반영 안 함)
- 이 DB의 `fnd03_consignment`에는 공통 회사(0) 행이 없고 모두 회사 28000 행이라, 원본 SQL 그대로는 어느 계정으로도 행이 보이지 않는다(운영 DB와 다를 수 있음). 관리자 화면에서 회사별 수탁사를 보려면 SQL 조건을 바꿔야 하므로 원본 그대로 두었다.
- 원본은 저장할 때 수탁사코드 중복을 검사하지 않는다(`preUpdate`는 `GridUpdate`가 안 부름). 같은 회사에 같은 코드가 둘 생길 수 있다.
- 사용여부는 `addBoolean`이라 편집기가 없어 화면에서 못 바꾼다(체크 표시만). 바꿀 방법이 없는 것이 원본 의도인지 확인 필요.
