## SQL 이식
모두 IDMS-IC `analysis sql … -o code` 그대로. 바뀐 곳: `selectOfficeAssets`의 `retireYn`(문자열 'false'/'true' 비교)을 `<if test="!retireYn">`로, 검색어를 `'%'||#{searchText}||'%'`(AS-IS와 같은 식)로 두었다. `selectByExpenseId`에 `ORDER BY ast06_tr_id`를 더했다(원본은 정렬 없음 → 줄 순서가 매번 같게). `insertOfficeTr`는 `port-save ast06_tr`의 INSERT에 `updateDepn2`가 넣는 값(금액·외화금액·약정외화금액 = 취득금액, 취득거래ID = 자기 자신, 통화 KRW, 환율 1, 미수미지급 false)을 고정했다. `countDepnAfter`는 `selectDepnCount`의 거래일·취득거래ID를 화면이 넘기던 값 대신 DB의 그 거래에서 읽는다.
