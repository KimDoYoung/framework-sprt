## 화면 구성
- 바깥 여백 20 + 흰 배경, 가로 `Splitter`(TG). 왼쪽(원본 west 500, min 300·max 1000): [검색 입력(150)][찾기] + 자산분류 antd `Tree`(아이콘: 하위 없으면 목록, 있으면 폴더). 오른쪽: `Ast02_Grid_Detail`.
- `Ast02_Grid_Detail`: 위(0.55) = 왼쪽 70% 툴바 [조회][삭제][항목추가] … [현금흐름표] + 상세 그리드(순번 70·항목 120·정보 350·비고 200, 항목은 읽기 전용), 오른쪽 30% 폼 ※회계정보(대/중/소분류·계정구분·적용통화·감가상각방식·감가상각기간/율) ※기타정보(발행일자·만기일자·거래단위·보관처). 아래(0.45) = 내용 HtmlEditor(70%) + 담당자 그리드(30%), 그 아래 가운데 [저장].

## 공통 절차와 다른 점
- **R09 대비 차이**: assetType 1, 버튼 [조회]→[찾기], west 500, 트리 선택 1건·IT 검사, 폼(회계·기타정보), 항목 읽기 전용, 항목추가 때 순번 가져오기, 상세 비고 폭 200, 위/아래 0.55/0.45.
- **TG 점검 2칸 불일치 (사유)**: `page-style-check.py --screen`에서 `useTreeGrid`·`트리 이름 열 pinned left`가 ✗. 원본 왼쪽이 TreeGrid가 아니라 `Tree` 위젯(검색+아이콘 트리)이라 antd `Tree`를 썼다(R09와 같음). 나머지 규칙(가로 Splitter·왼쪽 min 300·패널 테두리 `#d9d9d9`·border-box)은 통과.
- **중·소분류 목록은 미리 읽고 거름**: 원본은 상위 콤보가 바뀔 때마다 서버(`selectByKindCode`, `code LIKE '상위%'`)에 묻는다. TOBE는 `ItemMClassCode`·`ItemSClassCode`를 한 번만 읽어 상위 코드 접두어로 거른다(결과 같음, 호출 줄임). 세분류는 이 화면에 없다.
- **감가상각방식 "(해당없음)"**: 원본 `ComboBoxField("DepnType", null, "(해당없음)", …)`의 맨 앞 항목 → `altCode ['', '(해당없음)']`, 저장 때 빈 값은 null.
- 보관처는 읽기 전용 칸을 눌러 조회창을 연다(원본 `LookupTriggerField`). 지우기(x)로 비울 수 있게 했다(원본은 조회창의 [선택안함]).
- 12-화면우선원칙: 바깥 여백 20, 안쪽은 `gap 8`, 패널 선은 왼쪽 패널 1줄, 폼 라벨 오른쪽 정렬(폭 120).
