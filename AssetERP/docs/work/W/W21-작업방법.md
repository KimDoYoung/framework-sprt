## SQL 이식
- `selectDepositDiff` → `AstBookMapper.xml`. 원본은 `book.*`·`SELECT *`로 열을 다 내지만 그리드·본문이 쓰는 열만 별칭으로 명시. 공통 CTE는 U01이 풀어 둔 `depositBookQuery`를 그대로 쓴다(이미 `ast12_book_real` 조인으로 `real_amt`·`diff_amt`를 낸다).
- `ast12_book_real.selectByHoldDate`·`update`는 `AstBookRealMapper.xml`. 원본 `SELECT *`는 그리드 열만. UPDATE는 로그인 회사 조건을 더했다(보안 보강). 존재 확인(`countById`)은 `UpdateDataModel`이 ID로 INSERT/UPDATE를 가르는 것을 옮긴 것.
- 첫 시도 500: 공통 CTE가 `#{astType}`을 쓰는데 새 statement에 안 넘겨 `BindingException` → `@Param("astType")`을 더함.

## 공통 절차와 다른 점
- 상신 본문(A39)은 AS-IS가 화면 그리드의 행을 넘기지만 TOBE는 기준일·검색어로 서버가 같은 조회를 다시 한다(V33 A17과 같은 방식). 외화 통화 이름 순서는 AS-IS `HashSet` 순서라 TOBE는 조회 순서(이상한점 #139).
