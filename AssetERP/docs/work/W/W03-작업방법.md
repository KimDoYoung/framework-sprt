- 바깥 여백 20 + 흰 배경, 안쪽 `padding 10` `gap 8`. 위: `SearchBar`(기준연도 입력 80, [조회] 자동, `extra`에 [등록][삭제][저장(n)][투자한도/StopLoss 설정]). 아래: `CellEditGrid`(체크박스) — 기준일 100(날짜 편집)·자기자본금 200(숫자 편집)·비고 800(텍스트 편집). 조회 뒤 첫 행 선택.

## 공통 절차와 다른 점
- **기준연도 입력 폭 80**: 원본 50. 12-화면우선원칙 Page 6(년도 폭 80).
- **TOBE 저장 SQL**: `UpdateDataModel`이 컬럼 메타로 만드는 동적 SQL은 명시 SQL로 옮겼다(05 §6 "저장"). 저장 뒤 `selectById`로 다시 읽는 것도 같다.
- **필수 검사(서버)**: 원본은 NOT NULL 오류를 그대로 보여 주던 곳을 `BusinessException(INVALID_INPUT)`으로 미리 막는다(기준일·자기자본금 / 자산구분·적용일).
- **삭제 선택 없음 문구**: 공통 `useGridCrud`의 "삭제할 행을 선택하세요."로 나온다(원본 "삭제할 항목을 선택해주세요"와 문구 다름 — 공통 부품 동작).
- **Ast41 [삭제]·[행 삭제]**: 원본과 같게 [행 삭제]는 확인 창 없음(`deleteConfirm: false`).
- **SID**: yunhee가 AS-IS를 SG로 판별하지만 TOBE는 편집 그리드라 CG로 판별된다. 위 "페이지 스타일" 참고.
