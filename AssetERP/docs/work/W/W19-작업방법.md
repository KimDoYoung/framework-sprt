## API (새 2개)
| 메서드 경로 | AS-IS | 비고 |

## SQL 이식
- `selectByCompanyId` → `BmtPcHistoryMapper.xml#selectByCompanyId`. 원본 `SELECT a.*`(안쪽 `SELECT *`가 `bmt12_pc_history` 전 열 + `sort` + 사원명)는 그리드 열만 별칭으로 줄였다(결과 행 같음, `compare` 4=4·2=2). 정렬 `COLLATE "ko_KR.utf8"`는 원본 그대로(03 원칙 19).
- `deleteByInfoId`는 `AND bmt12_company_id = #{companyId}`를 더했다(보안 보강, 이전 ID들과 같은 방식).
