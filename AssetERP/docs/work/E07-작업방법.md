## 공통 절차와 다른 점
- **`설명` 열은 원본에서도 항상 비어 있다**: 그리드가 `reason`(모델 속성 → `chk02_reason`)을 보여 주는데 테이블에 그 열이 없고 SQL도 안 가져온다. 원본 그대로 빈 열로 둔다 → 제안(작업기록).
- 복사는 TOBE가 id만 받는다(위 API 표). 결과(복사되는 열)는 같다.
- `adminYn`은 `companyId == 0 || adminDailyListId != 0`. `adminDailyListId`가 NULL인 행(관리자 행이 아니라 직접 만든 행인데 값이 NULL)은 0으로 본다.
- `Sys01_Lookup_SelectMulti`는 A14에서 만든 것을 그대로 쓴다(원본 그리드가 최신 소스에서 상품구분 열이 늘었지만 이 화면 몫이 아니다 — drift는 A14에서).
