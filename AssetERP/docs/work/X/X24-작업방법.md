## 화면 구성
- 위: `SearchBar` = 기준년월(Input 100) · 검색(250) + 조회 + extra [ICAM 월말잔액 대사]. 아래: `SingleGrid`(행번호 + 11열, 체크박스 없음) + `PagingToolBar`(100).
- 버튼 type: 조회 `search`, ICAM 월말잔액 대사·잔액대사 `register`, 닫기 `close`(원본 "사용된 버튼들" 그대로).
- 대사 창: `LookupModal` 1100, 위 툴바([잔액대사][조회] + 기준일 안내) + 결과 그리드 5열 + 가운데 [닫기]. 열 폭 합계 1030 → AS-IS 1100 유지.

## 공통 절차와 다른 점
- 기준년월이 `YYYY.MM`(또는 `YYYY-MM`)이 아니면 "기준년월은 YYYY.MM 형식으로 입력해주세요." 안내(원본은 날짜 파싱 예외). 기준년월을 비운 채 [ICAM 월말잔액 대사]를 눌러도 같은 안내(원본은 예외).
- 대사 창에 기준일 안내 글자를 보여 준다(원본 `infoLabel`은 비어 있음 — 어느 달 결과인지 알려 주는 표시, 로직 영향 없음).
- 외부 ICAM DB 읽기(`checkFeeBook`의 `DatabaseFactoryICAM`)는 서버가 거절한다(03 원칙 1).
