## SQL 이식
- `selectPreDepositByHoldDate`: 원본 SQL 그대로(공통 `common.ast_book_postgresql` include가 펼쳐진 형태, 동적 `<choose>`는 CDATA 밖), 바깥 `SELECT x.<원본별칭> AS <DTO열> FROM ( … ) x`. 동적 조건이 읽는 `astClassTreeId`·`keepAccountId`는 이 화면이 안 쓰므로 null 파라미터로 둔다(없으면 MyBatis가 `Parameter … not found`).
- `selectByAstClassTreeId`(이력): 원본 그대로, 계산 열 별칭 `act02_journal_id`·`act02_note`가 `act02_journal.*`와 겹쳐 바깥 SELECT가 ambiguous라 `act02_hist_id`·`act02_note_calc`로 바꿨다(X15와 같은 이유).
