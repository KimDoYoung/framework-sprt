## 공통 절차와 다른 점
- 마감 검사 메시지의 날짜는 AS-IS `to_char(yyyy-mm-dd)`와 같게 `LocalDate`(ISO)로 만든다. 서버는 화면이 보낸 일자·회사를 믿지 않고 DB 값으로 검사한다(AS-IS는 클라이언트 모델 값).
- 승인(P)·승인취소(C) 중 한 건이라도 마감에 걸리면 전부 취소(한 트랜잭션). AS-IS도 `result.fail`로 중단하지만 앞 건이 이미 UPDATE된 채 커밋되는지는 AS-IS 서버 공통 처리에 달려 확인하지 못했다.
