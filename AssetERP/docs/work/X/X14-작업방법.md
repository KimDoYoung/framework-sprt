## SQL 이식 (38문장, `ActGenLedgerMapper.xml`)
- 조회 `selectCloseStatus`: 바깥 별칭만 DTO 이름으로(`act04_gen_ledger_id`→`gen_ledger_id` 등). 나머지 검증 SQL 19개는 **원본 그대로** 두고 바깥 `SELECT x.<원본별칭> AS <DTO열> FROM ( … ) x`로 감싸며, 검증마다 쓰는 열이 달라 15열 전부를 내고 안 쓰는 열은 `CAST(NULL AS …)`(생성자 자동 매핑은 열이 모자라면 실패한다). 파라미터는 한 레코드 `CloseParam`(원본 `request.getParam()`/Map). `<choose><when test="astClassTreeId…">`(원본에 있는 동적 조건)는 CDATA 밖으로 빼서 그대로 둔다.
- `act15_close_check.selectByText`: `companyId` 분기를 켠 형태(`selectCloseCheck`, 행이 없으면 원본은 NPE → TOBE `INVALID_INPUT`).
- `act01_account_code.selectTreeByAccountCodeAsc`: 마지막 SELECT를 `t.act01_account_cd` 하나만 읽도록 줄임(`act_list.act01_level, t.*` → 코드만), `ORDER BY act01_level`은 그대로. `act09_account_num.selectByStartDate`도 `act09_num`만.
- 쓰기 `insertUnApprEarnSurplus`·`updateUnApprEarnSurplus`·`insertGenLedgerClose`·`deleteGenLedgerClose`·`updateJournalCloseYn`·`insertAccountNumNext`: `:param`→`#{}` 외 그대로. `insertGenLedgerCloseEicp`는 이름과 달리 DB 함수 호출(SELECT). `todayDiffAmt`는 `jdbcType=NUMERIC`(원본은 null을 그대로 넘긴다).
- Java로 바꾼 것: `dbConfig.getDateTimeFormat(new Date())` → 서버 시각 `yyyy-MM-dd HH:mm:ss`(`LocalDateTime.now()`), `dbConfig.getSeq`(마감현황 행 키) → 줄 번호. `ast09_book.insertBookClose`·`deleteBookClose`는 원본에서도 주석이라 옮기지 않음.
