## SQL 이식
- `selectByAccountCode`·`getAccountCode`·`getOneAccountCode`·`selectByAstClassTreeId`: 원본 SQL 그대로 두고 바깥 `SELECT x.<원본별칭> AS <DTO열> FROM ( … ) x`(X14·X15 방식). 파라미터는 한 레코드 `JournalSubCond`. `journalNoStr`은 원본 모델이 `journalNo + ""`로 만드는 값(전월이월 줄은 "0")을 SQL에서 만든다. `sys99_print` 임시행은 `insertPrintJournalSub`(분개일자·번호·거래유형·적요·거래처 / 차변·대변·잔액 / 관리계좌·전표적요·계정과목·계정코드).
- Java로 바꾼 것: `dbConfig.getSeq` → `selectNextId`(f_create_seq). 엑셀은 `ActJournalSubExcelWriter`(POI XSSF)가 원본 `getAct02List`와 같은 짜임(제목 3줄·헤더 9열·계정마다 시트·월이 바뀔 때 [월 계]·[누 계] 줄)으로 만든다.
