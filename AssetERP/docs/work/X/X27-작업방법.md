## 화면 구성
- 위: `SearchBar` = 운용사(`LookupInput` 200 "전체") · 검색(300) + 조회 + extra [등록][저장(n)][삭제]. 아래: 가로 `Splitter` 왼쪽 850(최대 1000) 위 그리드 7열 / 오른쪽 이력 그리드 2열(`CellEditGrid`).
- 위 그리드는 `SingleGrid`(원본은 `setChecked(SINGLE)`이나 프로젝트의 단일 선택 규약대로 체크박스 열 없이 행 선택).
- 이력 그리드 `Icam11_Grid_MngFeeDeposit`: 적용시작일(날짜 편집) · 예금계좌(조회창 트리거 열). [등록][저장][삭제]는 위 탭 단추가 `ref`로 부른다.

## 공통 절차와 다른 점
- 왼쪽 폭: 원본 0.7 비율 대신 850 고정 + 이름 열 flex(12 원칙 1, X25와 같은 방식). 편집 가능한 날짜 열은 UX-08대로 100 → 120.
- 위 그리드 선택 행 없이 [등록]을 누르면 "펀드를 선택해주세요."(원본은 NullPointerException).
- 위 그리드 체크박스 열은 두지 않았다(프로젝트 `SingleGrid` 규약). 버튼·이벤트·그리드 수 대조에는 영향 없음.
