## 공통 절차와 다른 점
- 결산일자 입력 폭 100(12 원칙 7, 원본 70), 일자 열 폭 90(UX-08). 모달 폭은 열 폭 합계(1060+130)가 1120을 넘어 1120으로 하고 넘치면 스크롤(03 원칙 21).
- AS-IS는 결산 대상 한 행마다 `sqlSession.commit()`을 불러 중간에 실패하면 앞 행만 처리된다. TOBE는 **한 트랜잭션**이라 하나라도 실패하면 모두 되돌아간다.
- [변경] 아이콘은 AS-IS가 `getSelectedItem()`(선택된 행)을 열지만 TOBE는 누른 행을 연다(X12 `iconCell` 규칙: 행 선택을 바꾸지 않음).
- 결산 여부 검사("결산처리가 완료되었습니다. 취소 후 저장하세요")는 AS-IS가 화면에서만 하지만 TOBE는 서버에서도 한다(`countClosedBook`, 보안 보강).
- 성공 뒤 `message.success`를 더했다(AS-IS는 조용히 조회만 다시 한다, X12와 같은 처리).
