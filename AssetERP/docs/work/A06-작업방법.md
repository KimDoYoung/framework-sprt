## SQL 이식
| SQL | 그대로 / 수정(사유) |
|:---|:---|
| `selectByRoleId` | 조건 그대로: 회사 메뉴(sys03, 로그인 회사, `COALESCE(use_yn,'false')='true'`) ∩ 특정메뉴(sys50) 아닌 것, sys07(그 권한) 연결, `sys06_use_yn` 조건 없음, 부모별 `sys06_seq` 순. 표시명 `menu_no||' '||menu_nm`(번호 없으면 이름). AS-IS는 부모마다 SQL 반복 → **한 번에 읽고 서비스가 전위 순서로 편다**(A10과 같음). 같은 seq의 순서는 원본에 없다 → `sys06_menu_id`로 고정. sys03 중복 연결(DB 3쌍) 때문에 INNER JOIN 대신 EXISTS로 메뉴당 한 행. FULL JOIN sys07은 WHERE의 sys03 조건 때문에 사실상 LEFT JOIN → LEFT JOIN으로 씀(결과 같음) |
| `updateRoleMenu` | 연결 없으면 채번 INSERT(role_menu_id, role_id, menu_id, use_yn), 있으면 use_yn UPDATE(+권한 ID 조건). 권한그룹이 로그인 회사 것인지 먼저 확인(05 §6 회사 조건) |
