# FLT-BZ-0002 준법감시인이 회사 자기매매 기준을 정한다

> **한 줄 요약** — #1145 임직원매매 기준관리에서 적용시작일별로 **총 누적투자한도**·투자금액 계산대상·한도 초과 매수제한·월간 매매회전율·사전승인 금액/수량 초과비율·**사전승인 유효기간(영업일)**·주문유효일 기준(신청일/승인일)·운용펀드 보유주식 매수제한·**자기매매 보고 시작일**·증빙자료 필수·계좌 없으면 정기보고 안 함·**의무보유기간**(보유기간/매수주문건수, 영업일/개월)을 정한다(`flt01_company_std`). 같은 화면의 창에서 [종목유형설정](0001)·[매수제한종목](`flt08_buy_lockup`)·[예외사원](사원별 보고 시작일, `flt16_except_person`)을 관리한다.
