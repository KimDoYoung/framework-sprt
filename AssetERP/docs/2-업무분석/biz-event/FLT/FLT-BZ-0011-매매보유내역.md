# FLT-BZ-0011 직원·준법감시인이 매매내역과 보유내역을 본다

> **한 줄 요약** — 조회 화면 네 개다. 직원은 #1144 매매내역조회(기간·사전신고 포함 여부·매매구분·입출고 구분)와 #1143 보유내역(기준일 계좌·종목별 보유수량·장부금액, 0005)으로 자기 것을, 준법감시인은 #1153 임직원매매내역(준감인)·#1154 임직원매매 보유내역(준감인)으로 회사 전 직원 것을 본다. 매매내역은 사전신고·실거래·계좌대체·권리행사가 한 테이블(`flt10_tr`)에서 나오고, 보유내역은 영업일 보유원장(`flt11_book`)이다. 엑셀 내려받기가 있다.

## 업무 규칙 · 주의

- 원본 매매내역은 직원·관리자 화면이 같은 SQL(`flt10_tr.selectByTrList`)을 쓰고 `personId`가 있으면 그 사원만, 없으면 회사 전체다. 비교할 때 `personId=%`를 주면 숫자 열이라 SQL 오류가 난다(빼야 한다).
- 관리자 목록 API에 권한 검사가 없다 → [의심 #229](../../보안_및_버그_의심.md).
