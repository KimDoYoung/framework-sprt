# FLT-BZ-0001 KFS가 표준 종목유형을 고객사에 복사한다

> **한 줄 요약** — 어떤 금융투자상품이 자기매매 **신고대상**인지, **매도 사전승인**·**의무보유기간 체크**·주식시세 적용·상장지분증권 여부를 종목유형(`flt05_item_type`)마다 정한다. 표준은 회사 0에 10개(10 지분증권(국내상장) · 11 해외상장·비상장 · 20 증권예탁증서 · 30 주권관련 사채권 · 40 파생결합증권 · 50 장내파생 · 60 장외파생 · 71 공모주 청약 · 75 스톡옵션·우리사주 등 · 99 예치금)이고, KFS가 #1267에서 고객사를 골라 [등록(복사)]한다. 고객사는 #1145 [종목유형설정] 창에서 고친다.

| 항목 | 내용 |
|:---|:---|
| 누가 | KFS 관리자(복사), 고객사 준법감시인(수정) |
| 언제 | 고객사 도입 때 |
| 먼저 있어야 하는 것 | SYS-BZ-0001 고객사 |
| 다음 이벤트 | FLT-BZ-0002 기준관리 |
| 실제 실행 | 2026-11-14, API. kalpa 종목유형 0건 → KFS admin `POST /flt/item-types/copy {companyId:kalpa, itemTypeIds:[회사 0의 10개]}` → +10. 같은 `10`을 다시 복사 → +1(**중복, ⚠#217**) → 지움. 사원 401 복사 → 403. **사원 401이 `PUT /flt/item-types`로 국내상장 지분증권의 신고대상을 false로 바꿈(⚠#216)** → 되돌림 |
| 메뉴 | #1267 기초자료 > 00. 내부통제 > 임직원매매 종목유형관리(KFS), #1145 [종목유형설정] 창. kalpa 메뉴 없음. 화면 눈 확인 `대기(일괄)` |
