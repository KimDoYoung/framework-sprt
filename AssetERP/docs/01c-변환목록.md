# 01c. 변환목록 (기초자료 관리자 화면 — 내부통제·책무·문서·자산&경영·관리회계)

`01b-변환목록.md` 다음에 이어지는 상태판이다. 상태는 ID가 속한 파일에만 적는다. ID는 `E` 접두사(E01~E32)로 01a의 A·B·C, 01b의 D와 겹치지 않는다.
ID 하나의 기록은 `work/{ID 첫 글자}/{id}-작업방법.md`, `…-작업기록.md`, `…-결과확인.md`(예: E11 → `work/E/`).

- 상태: `대기` → `분석` → `백엔드` → `프론트` → `확인` → `완료`, 또는 `보류`(사유를 비고에).
- **다음 작업은 아래 표에서 상태가 `대기`인 첫 줄**(01a·01b가 끝난 뒤). 순서는 사용자 지정(2026-10-17).
- 패키지는 도메인별(`biz.ics`, `biz.chk`, `biz.flt`, `biz.bbs`, `biz.tdm`, `biz.dcr`, `biz.rpt`, `biz.sch`, `biz.ast`, `biz.pay`, `biz.crd`, `biz.emp`, `biz.act`). 이미 있는 패키지(`emp` 등)는 거기에 더한다. 하위 클래스(팝업·조회창)는 분석 단계에서 `yunhee analysis screen <화면> --list`로 확인해 같은 ID에서 함께 한다.
- 메뉴 열의 번호는 이 ID가 대표로 삼는 메뉴다. 같은 클래스가 여러 메뉴에 걸리면 나머지는 비고에 적고, 결과확인 항목 9(메뉴 여러 개)에서 같이 확인한다.
- 줄·서비스·테이블 수는 분석 단계에서 채운다. 이 목록은 사용자가 준 클래스 목록을 `docs/as-is/src/menus.md`에서 찾아 만들었다(2026-10-17). 아래 구분선은 사용자가 준 묶음(빈 줄) 단위다: ① E01~E09 내부통제·일일점검·임직원매매 ② E10~E15 회사규정·책무 ③ E16~E18 문서 ④ E19~E26 자산&경영 ⑤ E27~E32 관리회계.
