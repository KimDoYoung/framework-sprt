# modal-style — 조회창·편집창 모양 이름표

모달(조회창 `LookupModal`·편집창 `EditModal`) 하나가 어떻게 보이는지(머리·검색 줄·본문·푸터·스크롤)를 이름(MID)으로 부른다. 화면 배치는 `page-style.md`(SID), 그리드 모양은 `grid-style.md`(GID), 이 문서는 모달 모양이다.
견본 코드는 `docs/modal-style/{MID}/`(참조용 복사본). 새 모달은 해당 MID 견본을 뼈대로 만들고, 견본에 없는 모양이면 사용자에게 알린 뒤 새 MID로 먼저 등록한다. 기존 모달은 일괄 수정하지 않고 다시 건드릴 때 맞춘다(page-style과 같은 규칙).

## 모달 공통 원칙 (사용자 결정 2026-10-30, Page 원칙과 같이 정함)
1. 머리 아래 선, 푸터 위 선을 둔다.
2. 최대한 스크롤이 생기지 않게 한다 — 모달 자체의 폭·높이를 늘리거나, 그리드면 열 폭을 줄인다.
(선은 늘리지 않는다 = 선 최소화. 구분이 필요한 영역은 배경색으로 나눈다.)

| MID | 이름 | 한 줄 설명 | 견본 |
|:---|:---|:---|:---|
| modal-TREE | 트리를 고르는 조회창 | 회색 검색 줄(입력 200 + [찾기] + 펼치기·접기 아이콘) 아래 트리, 말단에 아이콘, 스크롤은 트리 하나 | `Dcr30_Move_DcrClass` (문서분류, 2026-10-30) |

## modal-TREE — 트리를 고르는 조회창 (초안, 2026-10-30 U18에서 사용자 확정)

견본: `docs/modal-style/modal-TREE/Dcr30_Move_DcrClass.tsx` (실제 파일 `components/lookup/Dcr30_Move_DcrClass.tsx`, 다른 도메인도 쓰는 공통 조회창)

| # | 특징 | 값 | 이유·결정 |
|---:|:---|:---|:---|
| 1 | 모달 | `LookupModal`(antd `Modal` 아님), `maskClosable={false}`, `style={{ top: 20 }}`, 폭 580(AS-IS 500 — 검색 줄이 한 줄에 들어가도록 늘림) | 원칙 16: 열면 첫 입력칸 포커스·푸터 위 선은 `LookupModal`이 둔다. 위에서 20만 띄워 높이를 확보 |
| 2 | 머리 아래 선 | `styles.header = { borderBottom: '1px solid #d9d9d9', paddingBottom: 12, marginBottom: 12 }` | 모달 원칙 1 |
| 3 | 푸터 | 가운데 정렬 [확인][선택안함][닫기], 위 선은 `LookupModal`. **[선택안함]은 회색**(`type="select"` + `style={{ background: '#a6a6a6' }}` — 공통 darkGray `#646362`는 너무 진해 더 옅게, 마우스를 올려도 색은 그대로) | 모달 원칙 1. 선택을 비우는 보조 동작이라 [확인]의 초록과 구분 |
| 4 | 검색 줄 | **연한 회색 바탕 `#f5f5f5`**, 안쪽 `6px 10px`, 모서리 4, 선 없음 | 트리와 구분하되 선을 늘리지 않는다(선 최소화) |
| 5 | 검색 줄 구성 | 라벨 없음, 입력 **폭 200**(placeholder 안내), [찾기], **모두 펼치기·접기 아이콘은 맨 오른쪽** | 줄은 모달 폭에 맞춰 늘고 줄어 아이콘이 항상 오른쪽 끝. `SearchBar`(Enter 조회·지우기)를 감싸고 `ExpandCollapseButtons`(UX-09)를 줄 끝에 둔다. `SearchBar.Field`는 `label={null}` |
| 6 | 트리 높이 | `min(560, 창 높이 − 250)`, 최소 200 | 창이 낮아도 모달이 화면 밖으로 나가 바깥 스크롤이 생기지 않게 |
| 7 | 스크롤 | 트리 자체(가상 스크롤) 하나만. 감싼 박스는 `overflow: hidden` | 바깥 `overflow: auto`가 겹쳐 스크롤바 둘이 생기던 것 |
| 8 | 말단 아이콘 | 최하위 분류(`typeCode 'T'`, 선택 가능)에 회색 문서 아이콘(`FileTextOutlined`), `showIcon` + 노드별 `icon` | 폴더와 구분. 자식 없는 노드가 `children: []`라 antd의 `isLeaf`를 쓰면 안 나온다 → 데이터로 판정 |
| 9 | 노드 클릭 | 한 번 눌러도 선택하고 펼침·접힘 토글 | AS-IS 동작 |
| 10 | 보기 전환 | 검색 줄 오른쪽에 공통 `TreeListToggle`(눌린 버튼=보는 중), 그 오른쪽에 `ExpandCollapseButtons`(리스트에서는 비활성) | 사용자 요청. 기본은 트리 |
| 11 | 리스트 보기 | 최하위 분류만 `A ➡︎ B ➡︎ C`(callback 값은 AS-IS `/` 그대로), 검색어가 든 것만 즉시 거름, 행 클릭=선택·더블클릭=확인 | 사용자 요청. 화살표는 `➡`+글자표시(U+FE0E)로 이모지 배경색 없이 |

모달 모양이 새로 정해지면 이 표에 행을 더하고 견본 복사본도 같이 갱신한다. 새 트리 조회창은 이 견본을 뼈대로 만들고(03 원칙 22와 같은 방식), 다른 조회창(그리드형 등)은 별도 MID로 등록한다.
