# 업무분석

## 개요

- 업무분석이란 ASIS의 소스를 분석하여 각 도메인별 업무의 흐름을 분석한 후 그것이 TOBE에 적절히 적용되었는지를 판단한다.
- 업무분석 결과 TOBE의 구현이 적절하지 않은 경우 이를 판별하여 사용자에게 문서로서 보고를 한다.
- 보고는 명확하게 시나리오를 갖고 보고되어야 한다.
- 보고는 UI의 흐름과 DB의 변경을 함께 보고되어야 한다.
