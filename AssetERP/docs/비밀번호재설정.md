# 테스트를 위한 비밀번호 재설정

● 로그인 SQL은 sys01_loc_nm이 회사코드, emp01_emp_no가 사번(ID)이고, 비밀번호는 sys25_password에서 가장
  최근 seq 한 행을 TO_ENCRYPTS()로 저장합니다. 이 구조에 맞춘 SQL입니다. 아래 SQL은 실행해 보지
  않았습니다.

  -- 1) 현황 확인 (잠김 여부, 비번 행 존재 여부)
  SELECT p.emp01_person_id, p.emp01_emp_no, p.emp01_lock_yn,
         (SELECT MAX(sys25_seq) FROM sys25_password w
           WHERE w.sys25_person_id = p.emp01_person_id) AS last_seq
    FROM emp01_person p
    JOIN sys01_company c ON c.sys01_company_id = p.emp01_company_id
   WHERE c.sys01_loc_nm = 'kfstest'
     AND p.emp01_emp_no = '121';

  -- 2) 비번 1111로 변경 (최근 seq 행)
  UPDATE sys25_password w
     SET sys25_pwd = TO_ENCRYPTS('1111'),
         sys25_work_date = f_sysdate()
    FROM emp01_person p
    JOIN sys01_company c ON c.sys01_company_id = p.emp01_company_id
   WHERE c.sys01_loc_nm = 'kfstest'
     AND p.emp01_emp_no = '121'
     AND w.sys25_person_id  = p.emp01_person_id
     AND w.sys25_company_id = p.emp01_company_id
     AND w.sys25_seq = (SELECT MAX(sys25_seq) FROM sys25_password x
                         WHERE x.sys25_person_id = p.emp01_person_id
                           AND x.sys25_company_id = p.emp01_company_id);

  -- 3) 계정 잠김 해제 (로그인 실패 누적으로 잠겼을 수 있음)
  UPDATE emp01_person p
     SET emp01_lock_yn = 'false'
    FROM sys01_company c
   WHERE c.sys01_company_id = p.emp01_company_id
     AND c.sys01_loc_nm = 'kfstest'
     AND p.emp01_emp_no = '121';

  - 1번 결과에서 last_seq가 NULL이면: sys25_password 행이 없는 것입니다. 이 경우 2번 UPDATE는 0건이
    됩니다. 아래 INSERT를 쓰세요.
  INSERT INTO sys25_password (sys25_password_id, sys25_company_id, sys25_person_id, sys25_seq,
  sys25_pwd, sys25_work_date)
  SELECT f_create_seq(), p.emp01_company_id, p.emp01_person_id, 1, TO_ENCRYPTS('1111'), f_sysdate()
    FROM emp01_person p JOIN sys01_company c ON c.sys01_company_id = p.emp01_company_id
   WHERE c.sys01_loc_nm = 'kfstest' AND p.emp01_emp_no = '121';
  - 비번이 오래돼서 막히는 경우: sys25_work_date를 f_sysdate()로 갱신하므로 password_age_days가 0으로
    리셋됩니다.
  - 121이 관리자 계정(sys02_user)인 경우: 위 SQL이 아니라 UPDATE sys02_user SET sys02_passwd =
    TO_ENCRYPTS('1111') WHERE sys02_login_id='121' AND sys02_company_id=(SELECT sys01_company_id FROM
    sys01_company WHERE sys01_loc_nm='kfstest');를 쓰세요.
