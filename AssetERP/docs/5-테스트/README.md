# 테스트

## 개요

- 업무 로직 기준으로 TOBE 테스트를 자동화하는 작업이다. 핵심 명령: `yunhee run "gradle test"`
- 화면 시험 데이터(시나리오 명세)는 `../1-변환/work/{첫글자}/{id}-화면시험.json` 에 있다.
- 브라우저 시험 도구는 2026-11-04에 삭제했다. 시험 방법을 이 작업에서 정립한 뒤 새로 만든다(위 명세를 입력으로 재사용 가능).
- 2026-11-07 `tools/test/list.cjs`(화면 **열기+조회** 연기 시험)를 새로 만들었다. **열기와 조회만 본다 — 통과해도 데이터·업무 규칙이 맞다는 뜻이 아니다(첫 번째 시험일 뿐).** 무엇을 보고 못 보는지, 다음에 할 시험은 `../../tools/test/README.md`.
- 쓰기 시험(등록·수정·삭제) 전에는 `tools/db_dump_backup.sh`로 DB 를 백업한다.

## 파일 및 폴더

- `테스트용-회사-계정.md` : 로그인 회사코드/ID/비밀번호와 계정별 보이는 메뉴
- `정적분석/` : TOBE 정적분석 보고서(`tools/code-health.sh`)와 수정대장. 읽는 법은 그 폴더 `README.md`
- `../비밀번호재설정.md` : 테스트용 비밀번호 재설정 SQL

## 연결되는 다른 작업
