# 변경반영 대장

AS-IS 변경 한 건 = 한 줄. 규칙(종류·상태·절차)은 `README.md`.
새 줄은 맨 아래에 붙인다. 지우지 않는다(잘못 넣었으면 `해당없음` + 비고). 끝난 줄(반영·해당없음)은 `make-change-docs.sh`가 `보관/{처리일 달}.md`로 옮긴다.
