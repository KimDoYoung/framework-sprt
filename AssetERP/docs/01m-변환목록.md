# 01m. 변환목록 (준법감시 — 대외활동·법규통제 현황·확인대장)

`01l-변환목록.md` 다음에 이어지는 상태판이다. 상태는 ID가 속한 파일에만 적는다. ID는 `M` 접두사(M01~M06)로 01a의 A·B·C, 01b의 D, 01c의 E, 01d의 F, 01g의 G, 01h의 H, 01i의 I, 01j의 J, 01k의 K, 01l의 L과 겹치지 않는다.
ID 하나의 기록은 `work/{ID 첫 글자}/{id}-작업방법.md`, `…-작업기록.md`, `…-결과확인.md`(예: M03 → `work/M/`).

- 상태: `대기` → `분석` → `백엔드` → `프론트` → `확인` → `완료`, 또는 `보류`(사유를 비고에).
- **다음 작업은 아래 표에서 상태가 `대기`인 첫 줄**(01a·01b·01c·01d·01g·01h·01i·01j·01k·01l이 끝난 뒤). 순서는 사용자 지정(2026-10-20).
- 패키지는 도메인별이다. 대부분 `ics`(소스 색인 `ics/screens/`)이고, M04는 `sch` 소속이다. 하위 클래스(팝업·조회창)는 분석 단계에서 `yunhee analysis screen <화면> --list`로 확인해 같은 ID에서 함께 한다. 다른 도메인 컴포넌트(예: 전자결재 편집창 `Apr01_Edit_ApprDoc`)는 링크만 있으므로 01d·01g처럼 **1단계만** 할지 분석 때 정한다.
- 메뉴 열의 번호는 이 ID가 대표로 삼는 메뉴다. 같은 클래스가 여러 메뉴에 걸리면 나머지는 비고에 적고, 결과확인 항목 9(메뉴 여러 개)에서 같이 확인한다.
- 이 목록은 사용자가 준 클래스 목록을 `docs/as-is/src/menus.md`에서 찾아 만들었다(2026-10-20). 메뉴는 세 묶음이다: `12. 대외활동`(M01·M02), `90. 법규통제 현황(사용X)`(M03·M04), `90. 기타`(M05·M06).
- M03·M04의 메뉴 그룹 이름에 `(사용X)`가 붙어 있다. 운영에서 쓰지 않는 메뉴일 수 있으므로, 변환 여부를 분석 시작 전에 사용자에게 확인한다(필요하면 `보류`).
- 줄·서비스·테이블 수는 분석 단계에서 채운다.
