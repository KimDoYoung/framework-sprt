## 공통 절차와 다른 점
- **RD 첨부 PDF(`createRd` L575-648, `sys.Sys99_Print.insertComplianceState`)는 만들지 않는다** — TOBE에 RD 리포트·PDF 엔진이 없고, AS-IS도 파일 저장 경로가 없으면(`filePath == null` 또는 `c:`) PDF 없이 `insertRelateApprId()`로 간다(L603-605). V19 A32와 같은 길. 본문 표는 서버가 직접 만든다.
- **옛 데이터**: `ics32_relate_appr`에 이미 있던 17행은 `ics32_appr_type`이 NULL이다. 새 조회(A32 = 구분 '1')는 이 행을 못 찾는다 → 사용자가 `UPDATE ics32_relate_appr SET ics32_appr_type='1' WHERE ics32_appr_type IS NULL`을 실행해야 옛 달의 A32 상신 상태가 보인다(코드는 원본대로 구분을 조건으로 건다).
- 스타일 SG: 외곽 테두리 없이 안쪽 `padding 10`·`gap 8`, 그리드 아래 폼 줄은 `flex: none` 높이 70(page-style SG 규칙). 기존 화면은 테두리가 있었으나 이 ID에서 화면을 크게 바꾸므로 견본에 맞췄다(03 원칙 22④).
- 사원명 칸 `LookupInput`에는 x(`onClear`)를 주지 않았다 — 원본은 조회창의 [전체]로 비운다.
- 조회창 폭: 열 합계 600(200+120+80+100+100) + 행번호·선택 60 + 여백 130 = 790(원본 700보다 큼 — 03 원칙 21).
