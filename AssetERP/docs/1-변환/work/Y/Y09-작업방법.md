## 화면 → API
| AS-IS | TOBE |
|:---|:---|
| `pay50_expense.selectByDateConfirm` | `GET pay/expenses/confirms` (`PayExpenseMapper.selectExpenseConfirm`, 승인자 = 로그인 사원) |
| `Pay50_Expense.updateConfirmReason` | `PUT pay/expenses/confirms` `{ids, confirmStatusCode, confirmReason}` (승인일자는 서버가 정한다) |
| `Pay50_Expense.confirmSendMessage` | `POST pay/expenses/confirm-notices` (요청자 수를 돌려준다) |
| 앱알림·메일·SMS 보내기 | 기존 `AprNoticeService`에 `planExpenseReject`·`mailEnabled` 추가(`dispatchAfterCommit`로 커밋 뒤 발송) |

## 공통 절차와 다른 점
- 원본은 툴바+그리드를 테두리 박스에 넣지만 SG 견본대로(12 화면우선원칙 2) 테두리를 뺀다.
- 승인일자(`confirmDate`)는 AS-IS가 클라이언트의 오늘을 보냈고 TOBE는 서버 오늘(취소는 NULL)을 쓴다. 승인상태는 10·20·30만 받는다.
- 모든 쓰기에 로그인 회사 조건을 더했다(없는 건·다른 회사 건은 `DATA_NOT_FOUND`).
- 메일 조건이 원본은 비밀번호 유무인데 TOBE는 이메일 유무다(이상한점 #108).
- 내역상세 아이콘은 AS-IS가 "선택된 행"을 열지만 11 §1대로 아이콘이 행 선택을 바꾸지 않아 누른 행을 연다.
