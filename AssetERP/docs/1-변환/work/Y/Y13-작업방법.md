## 공통 절차와 다른 점
- 새 신청서는 저장 전에는 목록에 임시 행을 넣지 않는다(원본은 넣었다가 닫을 때 지움). 첫 저장 때 맨 아래에 넣는다(03 원칙 17).
- 조회 뒤 첫 행을 고르지 않는다(원본은 체크박스가 첫 행에 체크된 채 열림 — 이상한점 #119).
- 삭제·수정의 본인·상태 검사를 서버도 한다(#118). 선택 없이 [삭제]는 경고(05 §8).
- 문자 발송은 `SmsSender`(비활성, 2026-10-15 사용자 지시)라 실제로는 나가지 않고, 수신자가 있으면 notice = -1이 된다.
