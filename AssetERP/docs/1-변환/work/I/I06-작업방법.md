## 공통 절차와 다른 점
- 원본 [등록]은 `GridInsertRow`로 그리드 맨 아래(또는 선택 행 아래)에 임시 행을 먼저 넣고 창을 연다(닫기에서 행 제거). TOBE는 임시 행을 넣지 않고, 저장이 성공하면 목록을 다시 조회한다(결과는 같고 "닫기" 때 되돌릴 행이 없다).
- 변경(MODI) 창의 편집값은 복사본이다 — 원본은 모델 자체를 고치므로 저장하지 않고 닫아도 그리드 행의 값이 화면에서만 바뀌어 보인다. TOBE는 닫으면 버린다.
- 원본 [삭제]는 `delete2`가 서버에서 행마다 `insertFloorTrBook`을 부르고 실패하면 그 행에서 멈춘다(앞 행 삭제는 이미 반영) → TOBE는 한 트랜잭션이라 실패하면 모두 되돌린다.
- 원본 `Flt10_Tr.update`가 열 전부를 `UpdateDataModel`로 쓰지만 이 창이 값을 정하는 열은 위 10개뿐이다.
