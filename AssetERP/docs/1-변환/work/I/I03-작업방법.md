## 공통 절차와 다른 점
- 열 편집은 `useGridCrud`로 하되 저장 전 검사(`preUpdate`)는 `validate` 대신 화면 `preUpdate`에서 한다(AS-IS도 서버 전송 전 검사 + 확인창). 
- `Flt10_Lookup_ExpectTr`: 시작일 = 기준일의 그 달 1일, 종료일 = 기준일(`settings()` L104-148)로 맞췄다.
- 종목명 칸은 원본 `LookupTriggerField`(글자 입력 + Enter로 창 열기 + 돋보기)라 TOBE는 **편집 가능한 글자 칸 + 돋보기 렌더러**로 하고, 입력을 확정하면(Enter·다른 칸 이동) 그 글자로 `lookupItemMain`을 연다.
- 정렬 UX-08(읽기 전용 날짜 90): 사전신고일·주문유효일 원본 폭 100 → 90.
- `Com50_Lookup_StkItem`을 `pages/com` → `components/lookup`으로 옮겼다(파일 머리 주석의 약속, IM-02). 05 §5·11에 반영.
