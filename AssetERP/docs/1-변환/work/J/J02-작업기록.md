- 1단계에서 다른 도메인 조회창 둘(`Emp93_Lookup_SmsNoticeTarget`·`Fnd10_Lookup_RelateFund`)은 안내 메시지(J01·I02 선례). 사용자 선택 없이 선례를 따랐다.

- 위반내역 열(`flt10_check_violate`)은 이 화면 그리드에 없어 SQL에서 뺐다(그에 쓰이던 `flt11_book`·`apr01_appr` 조인도 함께).
