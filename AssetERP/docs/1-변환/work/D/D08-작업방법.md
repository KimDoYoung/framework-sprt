## 화면 구성
- 위: `SearchBar` = 기간(`DatePicker` ~ `DatePicker`) · 구분(`SystemCodeComboBox` FundFeeType) · ICAM운용사(읽기 전용 칸 100) · 검색 + 조회 + [ICAM 발생보수 가져오기](extra). 아래: `SingleGrid`(행번호, 체크박스 없음, 10열) + `PagingToolBar`(100).
- 버튼 type: 조회 `search`, 가져오기 = `download`(원본 문구가 `button-types`에 없어 "외부에서 가져오기" 뜻으로 고름, D07과 같음).
- `feeId`는 numeric(18자리)라 문자열로 내린다(05 §6).

## 공통 절차와 다른 점
- 기존 `biz.icam`에 `IcamFeeController/Service/Mapper` 추가, `IcamBatchRunner`에 `runFee` 추가(구현은 `DisabledIcamBatchRunner` 하나뿐).
- 서버 보강(D07과 같음): 관리자 회사가 아니면 자기 회사만. 제안으로 기록.
