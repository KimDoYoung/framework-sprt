# EE36 Dcr01_Tab_DcrManager (업무별 문서작성(관리자) #1003) — 작업방법
- 원본: `client/vi/dcr/Dcr01_Tab_DcrManager.java`(277줄, 메뉴 #1003 자체. `Dcr01_Tab_DcrUser`가 상속). 함께 쓰는 클래스: `Apr01_Grid_DocList`(F02에서 변환).
- 스타일: TG (`yunhee page-style --compare` 일치).
- 원본과 DcrUser의 차이: ① 트리 `dcr.Dcr01_ClassTree.selectByCompanyId`(typeCode `%`, 문서구분까지) ② `managerYn = LoginUser.getIsManager()`(L70) ③ `addInsertButton()`은 DcrUser만 호출 → [신규문서 작성] 없음.
- F02에서 이미 만든 본체를 `DcrManagerView`로 이름만 바꾸고 `Dcr01_Tab_DcrManager`는 메뉴 화면(props 없음)으로 만들었다. `Dcr01_Tab_DcrUser`는 `DcrManagerView`를 쓴다.
- 트리 API는 EE05의 `GET /api/v1/dcr/class-trees?typeCode=%`(`selectByCompanyId`)를 그대로 쓴다. 새 API는 `GET /api/v1/apr/apprs/doc-list/manager` 하나 — 서버가 `SysMenuSearchService.isManager`(F05와 같은 판정)로 `admin=true` 분기(EE05 `searchDocListAdmin`) 또는 `admin=false` 분기(F02 `searchDocList`)를 고른다.
- `Apr01_Grid_DocList`는 F02 때 `admin` prop을 받기만 하고 쓰지 않았다 → 이번에 `admin`이면 `searchDocListManager`를 부른다.
