## API / SQL

"오늘 하루 열지 않음" 저장(`updatePersonId(noticeId=0)`)은 기존 `POST bbs/notices/{id}/history`를 쓴다. AS-IS는 기록이 이미 있으면 날짜만 오늘로 고치는데(L44-52, `UpdateDataModel`) TOBE 서비스는 없을 때만 넣고 있어서, **이미 있으면 `bbs05_date`를 오늘로 고치게** 서비스(`updateHistoryDate`)를 보강했다(안 그러면 한 번 누른 사람은 이후 날짜에 다시 "오늘 하루"를 못 쓴다).
