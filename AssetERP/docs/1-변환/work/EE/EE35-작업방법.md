## 서버 발송 (mailSenderTest / mailSender)
- 메일서버 설정 = 로그인 회사의 `sys01_company.mailInfo`(=`LoginUser.getMailInfo()`) → `MailConfig`(TOBE는 `common.mail.MailServerConfig.load`). 못 읽으면 `메일서버( X )가 설정되지 않았습니다. 관리자에게 연락바랍니다.`(-100).
- 보내는 계정: 본인=`emp01_person` 메일주소·복호 비밀번호(`to_decrypts`), 공용=`cmp10_mail_book.selectByEmailAddress`(회사·UPPER LIKE, 역할 조인, 첫 행) 주소·복호 비밀번호. 발송 이름 = 사원 한글명(UTF-8 B 인코딩).
- 수신·참조는 `;` 분리, `이름<주소>` 형식이면 이름을 UTF-8 B 인코딩. 제목 UTF-8. 본문 = 에디터 HTML + **서명 표**(`buildMailHtml`): 본인=로고(cid:image)+사원명·부서 | 직위(+개인정보 체크면 `(T. 내선 / M. 휴대폰)`) + 회사 전화·팩스·메일·주소, 공용=로고+회사명+전화·팩스·공용주소·주소. 로고 파일은 `{filePath}/{회사위치}/{mailSignImage}`, 회사 전화·팩스·주소는 `IdmsConfig` `{회사위치}.tel/.fax/.address`.
- 첨부: `sys10_file.selectByFileId(fileList)` → `{serverPath}/{fileId}`(없으면 건너뜀), 이름 원래 파일명. multipart mixed > related(html + 로고).
- 발송 후 회사 `mailLogYn`이 true면 `[AssetERP-발송메일] 제목`으로 보낸 계정에게 사본 발송.
- 오류 문구: 수신 주소 형식 `받는 메일주소가 올바르지 않습니다`, 인증/전송 실패 `…사용자 이름과 비밀번호가 허용되지 않습니다. 웹메일 비밀번호를 확인하세요.`, 그 밖 `메일발송 중 에러가 발생했습니다`. (옛 `mailSender`(testYn=false)와 `Test`는 같은 구조 — 옛 방식의 차이는 본문 `text/html` 한 덩어리·로고 `Content-ID` 방식. 두 경로를 한 서비스로 두고 `testYn`으로 가른다: 작업기록 "다른 점" 참고.)

## 조회창 (3개)
- `Emp10_Lookup_MailRetrieve`: 본인 메일 주소·비밀번호 입력창. 열 때 `emp01_person.selectByPersonId`로 주소를 채움; [검증] → `utils.mail.SendMailSMTP.checkMail`(회사 mailInfo로 입력 계정이 자기에게 시험 메일; 성공이면 확인창 `E4` 뒤 `changeMail`(주소+`to_encrypts` 비밀번호 UPDATE)); [초기화] → `resetMail`; [닫기]. 메시지 원문은 구현 때 `analysis method`로 확인.
- `Cmp10_Lookup_MailBookList`(600폭류): 검색 + 체크 그리드(이메일 220·비고 340) `cmp10_mail_book.selectByText`(`이메일||비고 LIKE %검색어%` + 내 역할), [조회][확인][취소], 더블클릭=확인, 미선택 "공용메일을 선택해주세요".
- `Emp10_Lookup_MailAddress`: 3그리드(개인 주소록·사원·공개 주소록) 선택 → 주소 문자열, [그룹]=`Emp57_Lookup_List`(TOBE 있음). TOBE에 이미 있는 `GET /emp/addr-books`·`/public`을 쓰고 사원 목록 `emp00_trans_info.selectByText`는 기존 엔드포인트를 찾아 쓴다.
