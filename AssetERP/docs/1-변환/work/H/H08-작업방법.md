## 공통 절차와 다른 점
- 툴바 2줄은 SearchBar 한 줄 흐름(줄바꿈)으로 — 버튼 순서(조회·저장·사용여부·관리그룹)는 같지만 법규검색·조문검색이 버튼 앞에 온다(H04와 같은 처리).
- 쓰기 SQL의 회사 범위: `ics03_company_info`는 로그인 회사로, 관리그룹은 로그인 회사 것만 허용(AS-IS는 클라이언트 값을 믿는다).
- 사용여부 설정 창의 같은 법규 여러 행(기한 수만큼)은 AS-IS와 같이 그대로 보여 주고 행마다 임시 번호(`rowId`)로 구분한다.
