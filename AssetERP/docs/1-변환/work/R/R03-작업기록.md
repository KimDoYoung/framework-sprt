## 제안 (사용자 승인 전에는 반영하지 않음)
- yunhee 수정사항: `analysis ui --tobe`가 `SearchBar`의 [조회]는 세지만 `SearchPanel`의 자동 [조회]는 세지 못한다(4/3). `SearchPanel`도 `SearchBar`처럼 [조회] 1개로 세도록.
- 원본 `updateConfirmYn`은 호출한 사람이 확인자인지 서버에서 검사하지 않는다(목록이 확인자 행만 주므로 화면에서는 문제 없음). API 직접 호출을 막으려면 저장 때도 "확인자 = 로그인 사용자" 조건을 건다.
- 원본 INSERT 경로(작성 행이 없는 대상)는 [확인취소]에서도 확인자를 로그인 사용자로 넣는다. 다만 화면이 "답변이 없는 대상"을 먼저 막아 실제로는 도달하지 않는다.
- [출력/다운로드] 버튼은 원본 핸들러가 비어 있다. 필요하면 RD(출력) 연결을 따로 승인받아 만든다.
