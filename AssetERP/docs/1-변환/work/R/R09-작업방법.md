## API 및 SQL 설계
1. `GET /api/v1/ast/details/by-tree`: `ast02_detail.selectByClassTreeId` (그대로)
2. `GET /api/v1/ast/details/templates`: `ast02_detail.selectByCompanyId` (그대로)
3. `PUT / DELETE /api/v1/ast/details/templates`: `ast02_detail` 기본 항목 CUD
4. `PUT / DELETE /api/v1/ast/details/items`: `ast02_detail` 종목 상세 CUD
5. `GET /api/v1/ast/cf-infos`: `ast03_cf_info.selectByClassTreeId` (그대로)
6. `PUT / DELETE /api/v1/ast/cf-infos`: `ast03_cf_info` CUD
7. `GET /api/v1/ast/cfs`: `ast04_cf.selectByCfInfoId` (그대로)
8. `PUT / DELETE /api/v1/ast/cfs`: `ast04_cf` CUD
9. `POST /api/v1/ast/cf-infos/batch-create`: `Ast03_CfInfo.bacthUpdate` 이식 (`ast04_cf.deleteByCfInfoId`, `ast04_cf.lastDate`, `ast04_cf.bizDate`, `ast04_cf.insert`, `ast03_cf_info` 업데이트)
