## 공통 절차와 다른 점
- 평가기간 콤보·년도 초기 조회는 T01과 같은 결정(설정을 읽은 뒤 조회).
- 평가완료·취소 뒤 평가등급 콤보(셀 편집) 사용 여부는 원본이 `refresh()` 응답 전에 `enableComboBox()`를 불러 이전 상태를 쓴다(완료 직후에도 콤보가 켜져 있다 → 다시 열기 전까지) — TOBE는 상태를 다시 읽은 값으로 곧바로 맞춘다(결정, 작업기록).
- 원본 [저장](평정사유)은 결과 메시지가 없어 TOBE도 메시지를 띄우지 않는다(오류만).
