## SQL 이식
| SQL ID | 그대로 / 수정(사유) |
|:---|:---|
| selectInvestAssetLimit · selectFinanceByHoldDate | 공통 CTE(`common.ast_book_postgresql`)는 AstBookMapper와 같은 것을 `bookCte`로 풀어 썼다. `selectFinanceByHoldDate`는 바깥 `SELECT *`를 이 화면이 읽는 열만으로 줄였다. `holdYn`·`periodType`은 `<choose>`로 |
| selectByAstClassTreeId | `SELECT *`·`t.*` 대신 화면이 읽는 열만(원본은 `ast08_price`가 두 번 나오는데 앞의 `trunc(…,2)` 값을 읽는다 → 같은 값). `periodType` 분기는 화면이 주지 않아 뺐다 |
| sys99_print.insert (Opr1·Opr2) | 채우는 열만. `insertRdFinanceBookOpr2`의 `insert`→`updateBuy`/`updateSell`(+`selectByCnt`)는 종목별로 메모리에서 [보유+매수+매도] 줄을 합친 뒤 순서대로 한 번에 넣는다(결과 줄은 같다: 매수 첫 줄에 합치고, 매수가 모자라면 매수 칸 0으로 비운 새 줄) |
