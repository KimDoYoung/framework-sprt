## 공통 절차와 다른 점
- 새 부품·공통 부품 변경 없음. `CellEditGrid`는 기본이 체크박스 다중이라 `rowSelection`을 상수(단일·체크박스 없음)로 넘겨 AS-IS(체크 없음)에 맞춘다.
- 아이콘(내려받기·삭제)은 누른 **그 행**을 쓴다. AS-IS는 "선택 행"을 쓰지만 GXT에서는 아이콘을 누르면 행이 먼저 선택된다 — 공통 `iconCell`은 선택을 바꾸지 않아 같은 효과로 클릭한 행을 직접 쓴다.
