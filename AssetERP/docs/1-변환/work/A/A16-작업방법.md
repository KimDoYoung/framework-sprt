## 공통 절차와 다른 점
- **이 DB에서는 조회가 0건이다.** 원본 SQL은 서버 경로를 `/data1/IDMS/docs/{고객}/{yyyyMM}`(앞 17자 + 뒤 7자)로 가정해 고객 서브도메인을 뽑는다. asseterpdb의 `sys10_file`은 `c:\KIDMS\…`(1,185행, 제외 조건)이거나 `/data1/IDMS_dev/docs/…`·`/data1/asseterp/dev/IDMS/docs/…`(222행, 앞 길이가 17이 아님)라 조인이 안 맞는다. 원본 SQL 그대로 옮겼다(03 원칙 4). B10의 TOBE 업로드 경로(`{asseterp.upload.dir}/{회사코드}/{yyyyMM}`)도 17자 규칙과 다르다 → 작업기록 "제안".
