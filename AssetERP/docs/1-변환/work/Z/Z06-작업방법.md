## SQL 이식
- `mkt03_history.selectByTargetCompanyId`: Z05 매퍼에 `isManager`만 더했다. `<if test="!isManager">`로 본인·공유 조건 블록을 감쌌다(AS-IS 분기 그대로).
- `selectTargetCompanyPaging`: 기존 조회창(L08)이 구분을 `%` 고정으로 옮겨 둬서 구분 파라미터가 있는 문장을 `selectTargetCompanyItemPaging·Total`로 새로 두었다(전체 `%`일 때 결과는 같다). 주석 `AS-IS(IDMS-IC)`.

## 공통 절차와 다른 점
- 서버 `histories/manage`는 `isManager`를 요청으로 받지 않고 경로로 정했다(원본은 클라이언트가 `isManager=true`를 실어 보냄). 메뉴 권한 검사는 AS-IS와 같이 메뉴 단위(이 API 자체는 로그인 사원이면 호출 가능) — 이상한점 #181.
- 활동처 입력칸에 지우기(x)는 두지 않았다(원본에 없음, 비우기는 조회창의 [전체]).
