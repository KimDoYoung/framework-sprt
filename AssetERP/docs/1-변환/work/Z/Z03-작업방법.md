## API
- `GET /api/v1/bbs/notices/mine?noticeType&noticeDetailCode&searchText&startDate&closeDate&offset&limit` — `bbs.Bbs02_Notice.selectByPersonIdPaging`·`Total`. companyId·personId는 서버. 구분이 전체일 때만 기간을 건다(서버도 같게). 새 API 1개.

## SQL 이식
`bbs02_notice.selectBbsByPersonId`(WITH 3개: 공지구분·구분상세·bbs) → `BbsNoticeMapper.xml#selectBbsByPersonId`(`<sql>`) + `selectByPersonIdPaging`·`selectByPersonIdTotal`. 안쪽 `<choose>`의 noticeType·noticeDetailCode·searchText 분기는 항상 값이 있어 뺐다(startDate 분기는 그대로). 정렬 `(top_yn='true') DESC, from_date DESC, seq ASC, notice_id DESC` 그대로.

## 화면 구성
SG 형태, 박스 테두리 있음(H01과 같은 모양). 툴바: 공지구분 120·구분상세 200·공지기간(오늘-3개월~오늘, 구분이 전체일 때만 켜짐)·검색 250. 그리드(단일 선택, 행번호): 핀 35·공지일 100·공지번호 100·공지구분 200(HTML)·제목 600(HTML)·상세보기 70, 페이징 100.
