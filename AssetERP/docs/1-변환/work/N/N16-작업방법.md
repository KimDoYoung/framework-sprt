## 공통 절차와 다른 점
- 확정/확정취소는 서버 검사와 처리를 한 번에(AS-IS 두 호출). 결과 메시지는 같다
- 확정(insertManlOrg)은 작성시작일 검사를 insert 앞에서 한다(AS-IS는 insert 뒤 실패 처리라 반쯤 들어간 행이 남을 수 있다)
- 부서변경은 점검항목(tdm43)이 없는 직책-부서 확정 행(tdm42)을 마지막에 지운다(AS-IS 그대로) — 점검항목이 없는 확정 상태에서 부서변경을 하면 확정이 풀린 것처럼 보인다
- 그룹 그리드의 체크 열은 보기 전용이고 행 클릭이 뒤집는다 — AS-IS는 체크 셀 클릭과 `RowClick`이 둘 다 값을 바꾸는 구조라 체크 칸을 정확히 눌렀을 때 결과가 불확실해 "어디를 눌러도 한 번 뒤집힘"으로 정리
- 책무 선택 창 [전체]·직책 [전체]는 원본이 `callback.execute(null)`을 부르므로 `onAll`로 처리(N15에서 고친 공통 부품 변경)
