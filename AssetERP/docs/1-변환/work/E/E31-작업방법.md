## SQL 이식
- `selectByCompanyId`·`selectById`: `act13_real_account_map.*`를 DTO 열로 풀었다(대표계정명 INNER JOIN·실계정과목 LEFT JOIN·`(사용X)` 접두어는 원본 그대로). **`selectById`는 원본이 INNER JOIN이라 없는 대표계정코드를 직접 입력해 저장하면 저장 직후 행이 비어 `LEFT OUTER JOIN`으로 바꿨다**(E30과 같은 처리, 저장 응답이 항상 있어야 한다)
- `insertInitData`: 열 목록 없는 `INSERT … SELECT`를 열 순서대로 적었다. 회사 0의 행을 대상 회사로 복사
