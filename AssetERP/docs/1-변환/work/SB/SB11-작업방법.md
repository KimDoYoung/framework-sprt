# SB11 BatchMain `filemissing` — 작업방법

골격은 `SB01-작업방법.md`. `BatchAction` 구현체 `FileMissingAction`(`biz.batch.action`)이다.

## AS-IS → TOBE
- 원본: `BatchMain.filemissing` L3830-3861 (`/BatchMain?actionCode=filemissing&year=2026`)
- 처리: `year`(yyyy)에 등록된 파일(`sys10_file.selectByYear`: `to_char(sys10_reg_date,'yyyy') = year`, 지운 것 포함)을 읽고, 파일마다 `{serverPath}/{fileId}`가 서버에 있는지 `File.exists()`로 확인해 없는 것은 로그만 남긴다. DB는 읽기만 한다.
- 호출: `GET·POST /api/v1/batch/filemissing?year=2026`
- 결과 문구(그대로): `filemissing 작업완료` — 건수는 응답에 없고 서버 로그에 `총 파일 수`·`[없음] ID/경로/size`·`존재하지 않는 파일 수`가 남는다(`yunhee log tail --level WARN`로 볼 수 있다).
- 파일 경로 규칙은 TOBE `SysFileService`·`FileRes`와 같다(`{serverPath}/{fileId}`, 확장자 없음).

## SQL 이식
`BatchFileMapper.xml` — `sys10_file.selectByYear`, `SELECT a.*` 대신 쓰는 열(`file_id`·`server_path`·`size`)만 적고 조건 그대로. `yunhee mapper-run --compare`로 AS-IS와 행 수 일치(2026년 283=283).

## 공통 절차와 다른 점
- 응답은 `ApiResponse<BatchRes>`(SB01). 읽기 전용 트랜잭션.
- `year`가 없으면 AS-IS처럼 그대로 조회한다(0건).
