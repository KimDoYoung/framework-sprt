# SB03 BatchMain `sch09Insert` — 작업방법

골격은 `SB01-작업방법.md`. 이 ID는 `BatchAction` 구현체 `Sch09InsertAction`(`biz.batch.action`) 하나다.

## AS-IS → TOBE
- 원본: `BatchMain.sch09Insert L140-185` (`/BatchMain?actionCode=sch09Insert`)
- 처리: stdDate가 비면 오늘 → 사용 중인 회사마다 `sch03_deadline.createSch09`(반복일정 행마다 DB 함수 `f_create_schDeadlineDay` 호출) → 결과가 "Y"면 오류 로그만 → commit
- 호출: `GET·POST /api/v1/batch/sch09Insert` (파라미터 `stdDate`가 필요한 작업만 사용). 인증은 API key + IP.
- 결과 문구(그대로): `업무일정(스케줄) 반복일정 Sch09에 Insert 작업완료.. commit`
- 한 트랜잭션: 모든 회사를 `@Transactional` 하나로 묶는다(AS-IS도 한 SqlSession, 마지막에 commit, 예외 시 rollback). 실패하면 `sys97_notice_log`에 `BatchMain.sch09Insert` 오류가 남는다(`BatchService`).

## SQL 이식
`sch03_deadline.createSch09` → `BatchSchMapper.createSch09`(**`selectOne`과 같은 단일 `String` 반환 그대로**)
날짜 파라미터는 DB 함수 시그니처가 `date`라서 `LocalDate`로 넘긴다(AS-IS의 `java.util.Date`와 같은 값).

## 공통 절차와 다른 점
- 응답은 `ApiResponse<BatchRes>`(SB01 결정).
- `stdDate` 형식 오류는 AS-IS처럼 null이 된다(원본-이상한점 #201).
