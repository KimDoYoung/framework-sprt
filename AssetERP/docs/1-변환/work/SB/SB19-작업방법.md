# SB19 BatchMain `icamBook` — 작업방법

골격 `SB01`, ICAM 읽기 `SB12`(운용=`ICAM`, 자문=`ICAM2`).

## icamBook 분기
- 원본 `BatchMain.icamBook` L2569-2758. `GET·POST /api/v1/batch/icamBook?companyId=ALL|숫자&stdDate=yyyy-MM-dd&worker=…`
- `stdDate` 없으면 직전 영업일. 형식이 틀리면 거절(#214). 한 트랜잭션.
- **① 운용 펀드원장 (ICAM)** — 회사: `selectIcamCompanyCode`(S3·A1). 회사마다
  1. `fnd10_book.delete` — 그 날·그 회사의 **ICAM 관리펀드(`fnd01_icam_yn='true'`)** 원장.
  2. ICAM `fnd10_book.selectIcamBook` 읽기(0건이면 `icamBookList(fnd10) size : 0` 알림).
  3. 각 행: `fnd01_fund_code.selectByFundCode`로 펀드ID, `ast01_class_tree.selectByDetailCode`(표준코드·`IT`·운용자산·ICAM자료)로 자산분류ID를 찾아 `fnd10_book.insert`. **없으면 NPE로 전체 실패**(#214).
- **② 자문/일임 (ICAM2)** — 회사: `selectIcamAdvisCompanyCode`. 회사마다 `adv10_book.delete`(그 날·회사) → ICAM2 `adv10_book.selectIcamBook`(0건이면 `icamAdvisBookList(adv10) size : 0` 알림) → `adv10_book.insert`. 평가금액은 AS-IS 별칭 오류로 항상 null.
- 결과 문구(그대로): `BOOK 작업완료..commit`. 오류: `단계 문구 / 예외`(AS-IS `errMsg / e.toString()`).
- **순서 의존**: 펀드는 `icamFund`, 종목은 `icamItem`이 먼저 만들어야 한다.

## 시뮬레이터 CSV
- `icam/fnd10_book.selectIcamBook.csv`: 조건 `@icamCompanyCode`·`@stdDate`(2018, 2026-11-03).
- `icam2/adv10_book.selectIcamBook.csv`: 조건 `@icamAdvisCompanyCode`(ZZ98)·`@stdDate`. 평가금액 열 이름은 AS-IS 별칭 그대로 `fnd10_eval_amt`.
- 샘플 펀드(`ZZBK01`)·종목(`ZZBKITEM1·2`)은 개발 DB에 없다. 시험은 시험 안에서 만들고 롤백한다. 직접 돌리려면 `icamFund`/`icamItem`의 CSV 코드와 맞추거나 해당 펀드·종목을 먼저 만들어야 한다.
