## icamOfficeMngFee 분기
- 원본 `BatchMain.icamOfficeMngFee` L3128-3319. `GET·POST /api/v1/batch/icamOfficeMngFee?companyId=28000&startDate=…&closeDate=…&worker=…`
- 회사는 1·28000(한국펀드서비스)만. 기간은 없으면 (전영업일 `bizDate -1` ~ 어제), 있으면 둘 다 필요(형식 오류 거절, #219).
- 처리(한 트랜잭션): ① `icam10_fee.deleteOfficeMngFee`(20407·24926)·`icam12_fee_book.delete` ② ICAM 두 쿼리(`selectOfficeMngFeeIcamData` — 모든 KSD 운용사, `selectLastDayFeeIcamData` — feeType 20407) ③ 0건이면 알림 `icamOfficeMngFeeList(icam10) data size : 0 ` ④ 행마다 계약사관리 운영구분 '자산운용'(`biz13.selectManageTypeIs1`)인 것만 `icam10_fee.insert` → 신규 펀드 `icam11_fee_deposit` 입금계좌(기준일 이전 시작분이 없을 때) → 운용사 거래처 `sys15_corp`(코드가 사용 중으로 없을 때, 구분 5·사용·순번=회사코드 숫자) ⑤ 말일 잔액도 같은 필터로 `icam12_fee_book.insert` ⑥ DB 함수 3개 `f_create_fundFeeBook`·`f_create_fundFeeRcvTr`·`f_create_depositBook`(회사, 시작일) — 하나라도 `'Y'`가 아니면 그 문구로 전체 실패.
- 결과 문구(그대로): `사무관리보수분개 가져오기 작업완료..commit`. 오류: 원인 문구만.
- 부품: `BatchFeeMapper`(+XML), DTO `BatchIcamFee`·`BatchIcamFeeBook`, 공용 `IcamFeeSupport`(기간 결정·행 변환·입금계좌 생성).
