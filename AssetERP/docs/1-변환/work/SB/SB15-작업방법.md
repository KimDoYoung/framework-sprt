# SB15 BatchMain `icamAdvice` — 작업방법

골격은 `SB01-작업방법.md`, ICAM 읽기는 `SB12-작업방법.md`. **자문 서버(`IcamServer.ICAM2`)** 를 처음 쓰는 분기다.

## icamAdvice 분기
- 원본 `BatchMain.icamAdvice` L2040-2142 + `updateTrCorp` L2144-2171. `GET·POST /api/v1/batch/icamAdvice?companyId=ALL|숫자&worker=…`
- 회사: `sys01_company.selectIcamAdvisCompanyCode`(**자문 ICAM 회사코드** `sys01_icam_advis_company_cd`가 있는 회사. 운용 쪽 `selectIcamCompanyCode`와 다름).
- 회사마다 ICAM2에서 두 가지를 읽는다: `adv02_account.selectIcamAccount`(계좌), `adv02_account.selectIcamTrCorp`(증권사).
  - 계좌가 0건이면 `sys97_notice_log`에 `icamAccountList(adv02) size : 0`.
  - 계좌: 관리코드로 `adv02_account`를 찾아 없으면 insert, 있으면 관리명·증권사코드/명·계좌번호·시작일·해지일 중 다른 게 있을 때만 update. 계좌번호는 평문(`adv02_account_no_dec`)으로 읽어 `TO_ENCRYPTS`로 저장, 비교는 `TO_DECRYPTS` 값과.
  - 증권사(`updateTrCorp`): `sys15_corp`(회사, 구분 `3`=증권회사, 이름)로 찾아 없으면 insert(사용 true), 있으면 새 코드가 null이 아니고 다를 때만 코드 update.
- 한 트랜잭션, 실패 시 원인 문구만. 결과 문구(그대로): `icamAdvice 작업완료..commit`.
- 비교는 null 안전(AS-IS는 기존 값이 null이면 NPE — #210).

## 시뮬레이터 CSV (`data/icam-simulator/icam2/`)
- `adv02_account.selectIcamAccount.csv`: 조건 `@icamCompanyCode` + 열 `adv02_manage_cd`·`_manage_nm`·`_tr_corp_cd`·`_tr_corp_nm`·`_account_no_dec`·`_start_date`·`_close_date`.
- `adv02_account.selectIcamTrCorp.csv`: `@icamCompanyCode` + `adv02_tr_corp_cd`·`_tr_corp_nm`.
- 샘플 코드 `ZZ99`는 개발 DB 어느 회사에도 없다. 시험은 회사 28000의 자문 코드를 ZZ99로 **시험 안에서만** 바꾼다(롤백). 화면에서 직접 돌려 보려면 그 회사의 `sys01_icam_advis_company_cd`를 CSV 코드로 맞춰야 한다.
