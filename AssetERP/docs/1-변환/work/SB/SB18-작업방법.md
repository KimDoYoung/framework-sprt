# SB18 BatchMain `icamItem` + `AssetErpItemSync` — 작업방법

골격 `SB01`, ICAM 읽기 `SB12`.

## icamItem 분기
- 원본 `BatchMain.icamItem` L2254-2418. `GET·POST /api/v1/batch/icamItem?companyId=ALL|숫자&stdDate=yyyy-MM-dd&worker=…`
- `stdDate` 없으면 직전 영업일(`sys12_calendar.bizDate`, 회사 0, -1). 형식이 틀리면 거절(#213).
- 회사: `selectIcamCompanyCode`(ICAM 회사코드가 있는 사용 중 S3·A1). 회사마다 ICAM `ast01_class_tree.selectIcamItem`을 읽는다(0건이면 `icamItemList(ast01) size : 0` 알림).
- 각 행:
  1. **대분류** `ast01_icam_l_nm`: 회사의 운용자산(2) 분류를 (상위 0, 이름)으로 찾고 없으면 `IC`로 생성.
  2. **중분류** `ast01_icam_m_nm`: 비어 있으면 건너뜀. 있으면 (상위=대분류, 이름)으로 찾고 없으면 `IC` 생성.
  3. **종목** `ast01_isin`: (상위=마지막 분류, 표준코드)로 찾고 없으면 `IT` 생성(이름 `ast01_class_tree_nm`).
- 결과 문구(그대로): `ITEM 작업완료..commit`. 한 트랜잭션.

## AssetErpItemSync (= assetErpItemInsert + createAstManager)
- 새 ID(`dbConfig.getSeq`), 분류코드(`f_create_ast_class_tree_cd(상위, 유형, 회사)`), 순번(최상위는 코드 숫자, 아니면 상위 안 최대+1).
- `IT`일 때 ICAM 대분류 코드로 종목 대/중/소 분류: `1`채권→20/2040, `2`유동성→10/1010(+표준코드 `10101`이면 소 101003), `3`주식→20/2010/201099, `F`부동산→50/세부(소분류 코드 1·H 건물 5020, 2·I 토지 5010, 4·K 건설중 5060, 5·L 구축물 5030, 7·N 차량 5040, 8·O 비품 5050, 그 밖 5090; 소=중+`99`), `6`집합투자→20/2050. 그 밖은 null(#213).
- 공통: 자산구분 `2`(운용자산), ICAM자료 `true`, 사용 `true`.
- 회사의 `sys01_ast_manager_auto_yn='true'`이면 `IT` 생성 때 기준일에 유효한 모든 부서(`org01_code`)를 담당부서(`ast10_manager`, 구분 2)로 지정.
- 이후 종목을 만드는 분기(`icamBook` 등)가 같은 서비스를 쓴다.
