# 11a. 조회창·선택 부품

`11-프론트부품.md` §4에서 2026-10-29 옮겼다(사용자 결정: 11이 한 번에 읽기 큰 문제). **조회창을 새로 만들 때만 읽는다**(규칙 몇 줄뿐이다) — 그리드·버튼·편집창 등 화면 뼈대는 11을 본다. 03 원칙 16·21과 옛 문서가 가리키는 "11 §4"는 이 문서다. 경로는 `frontend/src/` 기준.

## 조회창 규칙 (옛 11 §4)

열릴 때 조회하고, 값이 있거나 `open`이 true인 동안 모달로 뜬다. 닫힘은 항상 `onClose`.

**조회창을 새로 만들 때 (03 원칙 16, UX-05·06)**
- 모달은 antd `Modal`이 아니라 `LookupModal`(`components/lookup/LookupModal.tsx`, props는 `Modal`과 같다). 열릴 때마다 안쪽 첫 번째 글자 입력칸(antd `Input`·`TextArea`, 편집 가능·보이는 것)에 포커스한다 — 날짜·콤보는 건너뛰고, 입력칸이 없으면 아무 일 없다. 끄려면 `focusFirst={false}`. `autoFocus`를 따로 달지 않는다(두 번째 열기부터 안 먹는다). `Modal.confirm` 같은 정적 메서드는 antd `Modal` 그대로.
- **모달 폭 (사용자 결정 2026-10-20, H02·H03 후속)**: 열이 있는 조회창은 `gb.*` 열 폭을 모두 더하고(행번호·선택 열 약 60 포함) 거기에 안쪽 여백·스크롤바 약 130을 더한 값을 `width`로 손으로 정한다(예: 법규 기한 880+100 → 980, 개정이력 1120+130 → 1250). 자동 계산 부품(`fitColumns` 등)은 만들지 않는다. 합계가 **약 1120을 넘으면 모달을 더 키우지 않고** 가로 스크롤이 생기게 둔다. AS-IS 폭이 있으면 그것보다 작게 하지 않는다.
- 체크박스 다중 선택 목록은 `<MultiGrid rowClick …>` — 행 아무 곳이나 클릭하면 선택·해제(누적). 단일 선택은 `SingleGrid` 또는 `rowSelection={{ mode: 'singleRow', checkboxes: true, enableClickSelection: true }}`. 삭제·저장용 체크를 쓰는 CRUD 그리드에는 `rowClick`을 쓰지 않는다.

AS-IS 클래스 → TOBE 파일은 `yunhee analysis tobe <클래스>`. 안 만든 모드·미연결 창은 `13-누락대장.md`가 기준이다.
