# 04 키보드 단축키 (계획 확정, 구현 전)

AS-IS(GWT)에는 단축키가 없다. TOBE에 **고정 단축키 3개**를 더한다(2026-11-11 사용자 결정). 나의 화면 저장(03)의 `F9`도 같은 처리기에 넣는다.
사용자가 키를 바꾸는 기능은 만들지 않는다 — 사용자가 고령이라 단순하게 간다. 라이브러리(`react-hotkeys-hook` 등)도 쓰지 않는다.

## 1. 단축키

| 키 | 동작 | 비고 |
|:---|:---|:---|
| `Alt+X` | 현재 탭 닫기 | 활성 탭셋의 선택된 탭. 닫을 수 없는 탭(MyPage)이면 아무 일도 안 함 |
| `Alt+Shift+X` | 모든 탭 닫기 | 전체 레이아웃의 닫을 수 있는 탭 전부(MyPage는 남김). **확인창 한 번** ("열린 화면 N개를 모두 닫을까요?") |
| `Esc` | 화면번호 입력란으로 이동 | TopBar의 "화면번호/메뉴명" 칸에 포커스 + 글자 전체 선택(바로 덮어 칠 수 있게) |
| `F4` | 최대화·복원 (기존) | 이미 `MainFrame.tsx`에 있음. 새 처리기로 옮긴다 |
| `F9` | 나의 화면 목록 열기·닫기 | `03-나의-화면-저장.md`. 목록 안의 `↑↓`·`Enter`·`1`~`9`·`0`은 패널이 직접 처리한다(전역 처리기는 관여하지 않음). `F9`는 입력칸에 포커스가 있어도 동작 |

`Ctrl+W`·`Ctrl+Shift+W`를 쓰지 않는 이유: 브라우저가 먼저 가져가 웹페이지에서 막을 수 없다(탭·창이 닫힘). `Ctrl+T`·`Ctrl+N`·`Ctrl+Tab`도 같다.

## 2. 동작 규칙

- **물리 키로 판정** — `e.code`(`KeyX`, `Escape`)를 본다. `e.key`는 한글 상태에서 `'ㅌ'`가 되어 안 맞는다. → 한글/영문 상태와 무관하게 동작.
- **한글 조합 중이면 무시** — `e.isComposing || e.keyCode === 229`. 조합 중의 `Esc`는 브라우저가 조합을 끝내는 데 쓴다(다음 `Esc`부터 이동).
- **`Alt+X`·`Alt+Shift+X`** — 어디에 포커스가 있든(입력칸·그리드 편집 중 포함) 동작한다. `preventDefault()`. 반복 입력(`e.repeat`)은 무시 — 누르고 있어도 한 번만 닫는다.
- **`Esc`는 양보한다** — 다른 것이 Esc를 쓰는 중이면 아무것도 하지 않는다:
  - 팝업(antd `Modal`·`Drawer`)이 열려 있음 → 팝업이 스스로 닫힌다
  - 드롭다운·자동완성·날짜선택 목록이 열려 있음
  - AG Grid 셀 편집 중 → 편집 취소가 먼저
  - 탭 우클릭 메뉴(컨텍스트 메뉴)가 열려 있음 → 메뉴만 닫는다
  - 이미 화면번호 칸에 포커스 → 그대로(antd 자동완성이 목록을 닫음)
- 판정은 처리기 하나에서 DOM 상태(`.ant-modal-wrap` 보임, `.ant-select-dropdown:not(.ant-select-dropdown-hidden)`, `.ag-cell-inline-editing` 등)로 한다. 화면마다 코드를 넣지 않는다.

## 3. 구현 위치 (frontend)

| 무엇 | 어디 |
|:---|:---|
| 키 처리기 하나 | 새 파일 `hooks/useGlobalHotkeys.ts` — 키→동작 표 + `window` `keydown` 처리기. `Alt` 조합은 capture 단계(그리드가 이벤트를 삼키기 전), `Esc`는 bubble 단계(다른 부품이 먼저 처리) |
| 탭 닫기 | `MainFrame.tsx` — `model.getActiveTabset()?.getSelectedNode()` → `Actions.deleteTab`. 모든 탭은 `model.visitNodes`로 `isCloseable()` 탭을 모아 닫는다(기존 탭 우클릭 "전체 탭 닫기"는 탭셋 하나만 닫는다) |
| 기존 F4 | `MainFrame.tsx:375` 처리기를 새 훅으로 옮기고 삭제(처리기는 하나만) |
| 화면번호 칸 포커스 | `components/TopBar.tsx:406` `<Input>`에 ref. MainFrame에서 부를 수 있게 `registerMenuOpener`(`MainFrame.tsx:362`)와 같은 등록 함수 방식으로 `focusScreenSearch()`를 둔다 |
| 알아보기 쉽게 | 화면번호 칸 placeholder `화면번호/메뉴명 (Esc)`, 탭 우클릭 메뉴 `이 탭 닫기  Alt+X`·`전체 탭 닫기  Alt+Shift+X`, 탭 닫기 버튼 툴팁 `닫기 (Alt+X)` |

## 4. 순서

1. `useGlobalHotkeys.ts` 작성, F4 옮기기
2. `Alt+X`·`Alt+Shift+X`(확인창 포함)
3. `Esc` + 양보 규칙
4. 표시(placeholder·메뉴 라벨·툴팁)
5. 실측(아래 표) → 결과를 이 문서에 적는다
6. 이 README 4번 줄 상태를 `완료`로

브라우저: Chrome · Edge · Firefox (Windows 사용자 기준, 가능하면 Linux도). 각 칸에 영문·한글 상태 둘 다.

## 6. 결정 (2026-11-11 사용자, 제안대로)

- `Alt+Shift+X` 범위: **전체 레이아웃**(분할된 탭셋 모두). MyPage는 남긴다.
- 입력 중인 값이 있는 탭을 닫을 때 경고: **이번 범위에서 뺀다**(지금 TOBE에 "수정 중" 표시 수단이 없음). 필요하면 재설계 2·3번(사용자 설정·화면 저장)과 함께 다룬다.
- iframe(RD 미리보기 등) 안에 포커스가 있으면 키가 부모 창에 오지 않는다 → **그 경우는 동작하지 않음을 받아들인다.**
- 구현은 사용자가 추가로 말한 새 기능과 함께 검토한 뒤 시작한다(아직 착수 전).
