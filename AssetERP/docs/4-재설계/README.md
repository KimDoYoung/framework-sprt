# 재설계

## 개요

- AS-IS 의 UI·로직(업무흐름)을 TOBE 에서 다르게 바꾸고 새 기능을 더하는 작업이다 (Strangler Fig).
- 정할 것: 전환 단위(메뉴), 기존 세션과 JWT 의 공존, 문제 시 되돌리는 방법. 아직 문서가 없다.


## ASIS에 없는데 TOBE에 추가/보완/변경 되는 기능 목록

1. security가 jwt로 변경 :  `../../docs/security-설계.md`.
2. 사용자 설정 보완 : 설계 중
3. 나의 화면 저장 추가 (탭 배치를 이름 붙여 서버에 저장·복원, F9, 새 테이블 `sys90_user_props`) : 계획 `03-나의-화면-저장.md`
4. 키보드 단축키 추가 (고정 키 3개: Alt+X·Alt+Shift+X·Esc, 라이브러리 없음) : 계획 `04-키보드-단축키.md`
