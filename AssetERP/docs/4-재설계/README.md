# 재설계

## 개요

- AS-IS 의 UI·로직(업무흐름)을 TOBE 에서 다르게 바꾸고 새 기능을 더하는 작업이다 (Strangler Fig).
- 정할 것: 전환 단위(메뉴), 기존 세션과 JWT 의 공존, 문제 시 되돌리는 방법. 아직 문서가 없다.
