# 테스트

## 개요

- 업무 로직 기준으로 TOBE 테스트를 자동화하는 작업이다. 핵심 명령: `yunhee run "gradle test"`
- 화면 시험 데이터(시나리오 명세)는 `../변환/work/{첫글자}/{id}-화면시험.json` 에 있다.
- 브라우저 시험 도구는 2026-11-04에 삭제했다. 시험 방법을 이 작업에서 정립한 뒤 새로 만든다(위 명세를 입력으로 재사용 가능).

## 파일 및 폴더

- `테스트용-회사-계정.md` : 로그인 회사코드/ID/비밀번호와 계정별 보이는 메뉴
- `../비밀번호재설정.md` : 테스트용 비밀번호 재설정 SQL

## 연결되는 다른 작업

- 시나리오는 `../업무분석/`에서 가져온다.
