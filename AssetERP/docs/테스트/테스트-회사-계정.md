# 테스트 회사 및 계정

## 개요

- 로그인은 **회사코드 / ID / 비밀번호**로 한다. 회사(`sys01_loc_nm`)와 ID로 보이는 메뉴가 달라지므로, 시험할 메뉴에 맞는 계정을 아래 표에서 고른다.
- 회사 관리자(`admin`)는 그 회사에서 사용 중인 메뉴를 모두 본다. 사원(`104` 등)은 권한 그룹(역할)에 부여된 메뉴와 기본 역할의 메뉴만 본다(`SysMenuMapper.searchTailMenusByUser`).
- 사용 중지 회사(`sys01_use_yn=false`)는 로그인이 `COMPANY_NOT_FOUND`로 막힌다. 로컬 DB는 바꿔도 되지만(사용자 지시 2026-11-03) 바꾼 내용은 이 문서에 적는다.
- 계정 확인일: 2026-11-03. 로그인은 `yunhee api GET v1/sys/menus -u <ID> -c <회사코드>`로 확인한다(비밀번호는 `.env.yunhee`/기본 `1111`).

- `kfstest/admin`은 사용자가 손으로 시험하는 계정이기도 하다. 스크립트로 쓸 때는 `yunhee log tail`로 겹치지 않는지 본다.
