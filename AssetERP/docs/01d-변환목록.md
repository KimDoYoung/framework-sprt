# 01d. 변환목록 (문서작성 — 문서작성·문서검색·파일 및 양식관리)

`01c-변환목록.md` 다음에 이어지는 상태판이다. 상태는 ID가 속한 파일에만 적는다. ID는 `F` 접두사(F01~F12)로 01a의 A·B·C, 01b의 D, 01c의 E와 겹치지 않는다.
ID 하나의 기록은 `work/{ID 첫 글자}/{id}-작업방법.md`, `…-작업기록.md`, `…-결과확인.md`(예: F03 → `work/F/`).

- 상태: `대기` → `분석` → `백엔드` → `프론트` → `확인` → `완료`, 또는 `보류`(사유를 비고에).
- **다음 작업은 아래 표에서 상태가 `대기`인 첫 줄**(01a·01b·01c가 끝난 뒤). 순서는 사용자 지정(2026-10-19).
- 패키지는 도메인별(`biz.dcr`, `biz.ics`, `biz.apr`, `biz.fbx`). 이미 있는 패키지(`dcr`·`ics`·`apr`)는 거기에 더한다. 하위 클래스(팝업·조회창)는 분석 단계에서 `yunhee analysis screen <화면> --list`로 확인해 같은 ID에서 함께 한다.
- 메뉴 열의 번호는 이 ID가 대표로 삼는 메뉴다. 같은 클래스가 여러 메뉴에 걸리면 나머지는 비고에 적고, 결과확인 항목 9(메뉴 여러 개)에서 같이 확인한다.
- 줄·서비스·테이블 수는 분석 단계에서 채운다. 이 목록은 사용자가 준 클래스 목록을 `docs/as-is/src/menus.md`에서 찾아 만들었다(2026-10-19). 구분: ① F01~F04 문서작성 ② F05~F10 문서검색 ③ F11~F12 파일 및 양식관리.
