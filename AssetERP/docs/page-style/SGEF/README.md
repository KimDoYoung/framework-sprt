견본: `docs/page-style/SGEF/` (`Fnd01_Tab_FundCode.tsx` + `Fnd01_Edit_FundCode.tsx`)

- 구조는 SGVF와 같고 아래 폼이 편집형이다. 아래 가운데 [저장] 버튼 줄(60), 선택 행이 없으면 폼 비활성.
- 위 공통 규칙 4가지를 그대로 적용한다. 라벨 폭(120/145)과 칸 폭은 원본(AS-IS) 값을 따른다.
- 아래 폼이 둘(읽기 폼 + 편집 폼)이면 SGVF처럼 분할이 셋이다: 위 그리드 / 가운데 읽기 폼(테두리 박스, 기본 150·최소 120) / 아래 편집 폼(테두리 박스, 최소 360). 예: `Scm01_Tab_DevMng`(EE16, 점검 규칙은 아직 없다).
- 위쪽 박스(SearchBar + 그리드)에는 테두리를 두지 않는다(SGVF와 같음).
- **변형 — 아래 왼쪽 폼(570) 오른쪽에 편집 그리드가 더 붙는 경우** (U13 `Crd01_Tab_Card`): 아래 패널(여백 `0 20 20 20`, 최소 높이 = 폼 높이 합계)을 가로 flex로 나눠 왼쪽 폼 `570`(`marginRight -1`)·오른쪽 그리드 `flex: 1`. 그리드는 자기 테두리 박스 안에 버튼 줄(50) + 그리드. 이 변형의 점검 규칙은 아직 없다.
