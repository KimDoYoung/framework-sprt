## 공통 절차와 다른 점
- **폼 줄 테두리 없음.** 원본 폼은 테두리 패널이지만 GG 규칙("외곽 테두리 없음", `page-style-check`)을 따랐다.
- **문서분류 기본값은 흐린 글씨.** 원본 `setEmptyText`처럼 신청구분의 지출결의 문서분류를 칸에 흐리게 보이고, 모델(`classTree`)에는 값이 들어 있다. 고르면 칸에 값이 채워진다.
- **선택 ID 전달.** 원본은 선택한 모델 전체를 서버에 보내지만 TOBE는 ID만 보내고 서버가 읽는다.
- **`selectAccountName`·`selectByBenefitCode`(Emp55)는 한 API로 합쳤다.** 같은 테이블의 같은 행(LIMIT 1 / 전체)을 읽는다.
- **문자발송은 SMS 연동이 켜질 때까지 거절한다**(`DisabledSmsSender`, E17과 같은 방식).
- 공통 부품 변경 없음.
