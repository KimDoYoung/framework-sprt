## 공통 절차와 다른 점
- **화면 클래스 `Crd11_Lookup_ExcelCode`**는 관리자 화면 E24의 `Crd11_Lookup_ExcelCodeAdmin`과 그리드·API가 같고 [커스텀 설정]·기본 맵핑 보기만 다르다. 파일은 따로 만들고 API만 재사용했다.
- **복사 등록(copyInsertRow)**: AS-IS는 복사 행을 그리드에 넣고 서버로 보내지만 클라이언트 행에는 서버가 정한 ID가 돌아오지 않는다. TOBE는 저장한 내역(서버 ID)으로 행을 바꿔 넣는다 — 같은 결과를 보이면서 이중 저장을 막는다.
- **내역확정 실패는 전부 되돌린다**: AS-IS `insertList`는 카드·사용자가 하나로 잡히지 않는 내역을 만나면 그 전 내역까지 이미 반영한 채 실패를 돌려준다. TOBE는 한 트랜잭션이라 실패하면 전부 되돌린다(제안으로도 남김).
- 서버가 믿는 값: 회사는 로그인 값, 확정·삭제 대상 내역은 서버가 DB에서 다시 읽는다.
- 승인상태 열이 맵핑에 없을 때: AS-IS는 `stateName.equals`에서 NullPointerException으로 서버 오류가 난다. TOBE는 "업로드 구분코드(승인상태)가 설정되지 않았습니다."를 돌려준다.
