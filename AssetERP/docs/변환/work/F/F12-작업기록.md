## 결정
- 원본 `Fbx01_Tab_Search`의 `insertRow()`·`deleteRow()`·`update()`·`statusComboBox`는 화면에 연결된 곳이 없는 F11 복사 흔적이라 옮기지 않았다(03 원칙 12의 "화면에 있는 버튼·이벤트" 기준). UI 대조표 E4·E5는 TOBE에 주석으로 남겨 수를 맞춤.
- 박스 첫 행 자동 선택은 파일 목록을 채우지 않는다(AS-IS `select(0, false)`는 `CellClick`을 일으키지 않음) — 원본 그대로.

## 제안 (사용자 승인 전 반영 안 함)
- 박스 조회가 끝나 첫 행이 선택돼도 오른쪽 파일 목록이 비어 있어 사용자가 한 번 더 눌러야 한다. 첫 행 선택 때도 파일 목록을 읽게 하면 편하다(원본 동작을 바꾸므로 승인 필요).
- 파일 목록 툴바가 박스를 고르기 전 [검색]을 눌러도 아무 일 없다(원본 `boxId` null로 서버 호출 → 0행). 안내 메시지가 있으면 좋다.

## 의존
- 없음. `Fbx02_Popup_History`는 F11, `Sys10_Lookup_FileViewer`는 B10에서 이미 변환(재사용).
