## 결정 (사용자 확인 필요 없는 것)
- 트리의 `retrieveButton[조회]`는 원본도 툴바에 달지 않는다(`buttonBar`에는 라벨·docSearch·[찾기]뿐) → 만들지 않고 `[E1 생략]`.
- `search()`: GXT는 찾은 노드의 **직접 부모만** 펼치지만, 먼저 모두 접어서 조상이 접혀 있으면 노드가 안 보인다 → 조상을 모두 펼친다(의도에 맞춘 변경). 선택은 마지막으로 찾은 노드(단일 선택), 스크롤은 처음 찾은 노드(AS-IS `chk` 플래그와 같음).
- 문서 목록 SQL은 이 메뉴가 `admin=false`(DcrUser가 `managerYn=false`로 덮음)라 `<when test="admin == 'false'">` 분기만 옮겼다. 관리자판 #1003은 `admin=true`(`COALESCE(apr01_link_cd,' ') NOT IN (...)`만)를 쓴다 — 그 ID에서 `admin` 파라미터를 더한다.
- 검색 조건 `searchText`는 서버가 `%…%`로 만든다(AS-IS 클라이언트는 비면 `%`, 값이 있으면 `%값%` — 빈 글자일 때 `%%`와 같은 결과).
- 트리 SQL은 편집창이 쓰는 열(인감·결재유형·상품유형·전체경로·메일 등)을 뺐다 — 이 화면이 쓰는 건 이름·부모·구분·개요·depth·작성권한뿐이다. 편집창 단계에서 `selectByOrgIdRoleWrite_1Bang`의 나머지 열을 더한다.
- 연관펀드 SQL은 AS-IS의 `fnd00` CTE에서 행을 정하는 조인(펀드·그 시점 펀드정보·실제펀드)만 남기고 LEFT JOIN 3개(위탁·사무·수탁은행)는 뺐다(행 수에 영향 없음, 7=7 확인).
