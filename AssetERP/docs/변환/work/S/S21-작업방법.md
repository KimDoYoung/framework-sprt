## 화면 구성
- S20과 같은 모양, 왼쪽 그리드 470: 일자(120→읽기 전용 90, UX-08) · 구분 80 · 실수령액 160, 행번호 있음, 단일 선택. 툴바에 사원명 칸(조회창 아이콘, 입력 후 Enter/포커스 이동 = ValueChange).
- 사원명 칸은 S14(`Pay01_Tab_AnnualList`)의 같은 AS-IS 패턴(`emp.Emp00_TransInfo.selectByText`)을 따른다.

## 공통 절차와 다른 점
- AS-IS는 `selectByText` 결과가 있으면 첫 사원을 바로 쓴다고 읽히지만, S14에서 확인한 대로 "한 명이면 바로 선택, 여러 명이면 조회창"으로 옮겼다(같은 서비스·같은 인자).
