## 화면 구성
- 바깥 여백 20(`border-box`) → 테두리 박스(padding 10, gap 8) → 툴바 두 줄(기준년도 50·사원 100 + [조회][엑셀다운로드][휴가취소] + 초과휴가 [승인][반려][취소](회사 `leaveYn && leaveConfirmYn`일 때만) + [초기설정 휴가일수][기본설정][문서분류지정]) → 요약 줄 두 개(유급휴가 총 일수 + 전년도 미사용 월차 / 사용 / 잔여 / 휴가사용기간, 포상휴가 총/사용/잔여 + 안내 글) → `SingleGrid`(행번호 + 체크 단일 + 시작일 100·종료일 100·휴가구분 100·기간 60·대직자 120·사유 550·문서상태 100 + 묶음 헤더 "초과휴가"(승인상태 70·승인자 100·승인일시 150, 위 `leaveYn && leaveConfirmYn` 아닐 때 숨김)).
- 날짜 열 폭 UX-08(90) 적용. 포상휴가 창은 `view()`만(선택 모드는 쓰는 화면이 생길 때).
