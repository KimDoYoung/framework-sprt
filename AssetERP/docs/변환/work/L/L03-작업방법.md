## 공통 절차와 다른 점
- **새 행은 서버에 저장되기 전에는 인원 칸을 열지 않는다.** 원본은 번호 없는 모델을 그대로 넘겨 인원 칸·자동등록이 번호 없는(null) 내역에 붙는데, 이렇게 만든 행은 화면에서 보이지 않는다(저장 후 다시 읽으면 번호가 있는 새 내역만 나온다). 결과는 같고 보이지 않는 쓰레기 행만 만들지 않는다.
- **삭제 성공 메시지** "n건 삭제되었습니다."는 05 §8 공통 결정(원본에는 메시지 없음).
- **저장 뒤 선택**: 저장하면 목록을 다시 읽는다 — GXT는 다시 읽으면 선택이 풀린다. L02와 같이 마지막으로 고른 행 번호(`num`)가 0이면 첫 행을 고르고 아니면 그 행에 포커스만 둔다(AS-IS retrieve L216-224). 새로 저장한 행은 맨 아래에 있으므로 새 행 선택은 풀리고 편집 칸은 비활성이 된다.
- 증빙자료 창의 제목이 "법인카드 증빙자료"인 것은 원본 그대로다(복사해 쓴 흔적이지만 바꾸지 않는다, 03 원칙 4).
