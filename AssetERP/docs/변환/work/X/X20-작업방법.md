## SQL 이식
- `act04_gen_ledger.selectBSPL`: 원본 SQL 그대로(결산원장/가결산원장 `choose`, `exceptZeroYn`). 별칭만 DTO 열(`gen_ledger_id`·`account_name2`·`cur_bal_amt`·`pre_bal_amt`)로.
- `deleteGenLedgerCloseTmp`·`insertGenLedgerCloseTmp`·`insertGenLedgerCloseTmpEicp`(DB 함수 `f_create_genLedgerCloseTmp_eicp`): 그대로. `selectCloseDateCount`는 X14 것 재사용.
- `dbConfig.getAccountCloseDate` = `f_get_account_close_date(companyId, stdDate, type)`, `dbConfig.getPreQuarterCloseDate` = `f_get_quarter_date(stdDate, type)`.
- `sys99_print` 임시행: `insertPrintReport`(과목 string01 / 당기금액 long01 / 전기금액 long02 / id long03). `dbConfig.getSeq` → `selectNextId`.
