## SQL 이식
- `selectByStdDate1`·`selectByStdDate2`·`selectByAccountCode`: 원본 SQL 그대로, 바깥 `SELECT x.<원본별칭> AS <DTO열> FROM ( … ) x`. 세 문장이 한 DTO(`GenLedgerRes`)를 쓰려고 안 쓰는 열은 `CAST(NULL AS …)`(X14와 같은 이유). 하위계정 트리는 서버가 트리로 만들던 것을 평평한 전위 순서(`level`)로 내려 보내고 화면이 부모를 찾는다.
- `sys99_print` 임시행: `insertPrintGenLedger`(계정코드·계정과목 / 차변·대변 각 3 / 당일잔고액 / id). `dbConfig.getSeq` → `selectNextId`.
