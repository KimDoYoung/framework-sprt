## API (기존 `ActJournalDtl*`에 더함)
| 메서드 | 경로 | AS-IS |
|:---|:---|:---|
| GET | `/api/v1/act/journal-dtls?startDate&closeDate&corpId&searchText&trCode&abroType=0` | `act.Act03_JournalDtl.selectByCompanyId` (corpId 없음 → "%", 검색어 → "%…%" 또는 "%", trCode 없음 → "%") |
| POST | `/api/v1/act/journal-dtls/rd` (`windowClassName`·기간·조건·`journalIds`) → 출력그룹ID | `sys.Sys99_Print.insertRdJournal` |

`insertRd`: ① `sys99_print`에서 "출력용 선택전표"·화면 클래스 행 삭제 ② `journalIds`가 있으면 연속 같은 전표를 한 번씩 "출력용 선택전표" 그룹(long01 = 전표ID)에 넣고 ③ `selectByCompanyId`를 `checkedGroupId`로 걸러 그룹ID를 새로 만들어 화면 클래스 이름으로 한 줄씩 넣는다(전표일자·번호·거래유형·거래처·적요·통화 / 차변 4 / 대변 4). mrd `Act02_Rd_Journal`, rv `rdGroupId·companyId·personId·startDate·closeDate`(`rdApi.buildUrl`, `RdViewer`).

## SQL 이식
- `act03_journal_dtl.selectByCompanyId`: 원본 SQL 그대로 두고 바깥 `SELECT x.<원본별칭> AS <DTO열> FROM ( … ) x`(X14와 같은 방식). 동적 `<choose><when test="checkedGroupId != null">`는 CDATA 밖으로 빼서 그대로. **한 곳 바꿈**: 계산 열 별칭 `AS act02_note`가 `act02_journal.act02_note`(`t1.*`로 같이 나옴)와 겹쳐 바깥 SELECT가 "ambiguous"라 `act02_note_calc`로 바꿨다(원본 모델은 둘 중 앞의 계산 열을 읽는다). `act03_print_yn`은 DB 열이 아니다(모델 전용, 기본 false).
- `dbConfig.getSeq` → `selectNextId`(`f_create_seq()`), `sys99_print.deleteByPersonId` → `deletePrint`, `sys99_print.insert` → `insertPrintChecked`(출력용 선택전표)·`insertPrintJournal`(분개장 한 줄).
