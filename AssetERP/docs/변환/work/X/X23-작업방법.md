- 위: `SearchBar` = 기간(`DatePicker` ~ `DatePicker`) · 검색(250) + 조회 + extra [ICAM발생내역 가져오기][BATCH 재실행]. 아래: `SingleGrid`(행번호 + 13열, 체크박스 없음) + `PagingToolBar`(100).

## 공통 절차와 다른 점
- 창 폭 500·550 → 560(스크롤 방지, 12 원칙). 그 밖은 원본과 같다.
- `Icam10_Lookup_getICAM`: 원본은 구분이 20407이 아니면 운용사 칸에 로그인 회사의 ICAM 운용사 코드를 넣는데, 로그인 사용자 타입에 그 값이 없고 이 화면은 20407만 열어 코드 칸을 비워 둔다.
- `getICAMFundFee`는 외부 ICAM DB(`DatabaseFactoryICAM`)를 읽는 작업이라 서버가 거절한다(03 원칙 1, D08과 같음).
