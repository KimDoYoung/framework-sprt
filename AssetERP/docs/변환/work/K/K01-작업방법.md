## 공통 절차와 다른 점
- 콤보 폭 80(원본 60): antd 선택 화살표 때문에 "12월"이 잘린다(J08과 같음).
- 체크박스 동작은 원본 `StoreRecordChange`와 같다: 예/아니오/해당없음은 라디오처럼 그 코드로 정해지고, 이미 체크된 칸을 눌러도 해제되지 않는다(원본의 `setYes(false)`도 코드를 Y로 둔다).
- 수정 아이콘은 누른 행으로 연다(원본은 선택된 행 `grid.getSelectionModel().getSelectedItem()` — GXT는 아이콘을 누르면 행도 선택되므로 같다).
- 엑셀은 RD 리포트 모양을 재현하지 않고 한 시트에 같은 항목(구분·내용·예·아니오·해당없음·사유·제출여부·확인여부·확인자, 체크는 ✓)을 쓴다. `IcsExcelWriter`는 `biz.ics` 안의 보조 클래스(`FltExcelWriter`와 같은 방식) — 공통 부품 제안은 작업기록.
- 파일명의 소속·이름은 원본이 그리드 첫 행에서 읽는다(작성 행이 없으면 비어 있음 → 원본은 "null null"). TOBE는 빈 글자로 둔다.
