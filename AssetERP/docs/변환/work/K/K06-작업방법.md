## 공통 절차와 다른 점
- **K05와 다른 점(원본대로)**: ① 확인자는 로그인 사용자가 확인할 작성 행의 대상(다른 사람이 작성한 행) ② 미제출 보기/미확인 보기 두 개 ③ 검색 대상이 대분류·중분류·체크대상·담당부서·담당자 ④ 페이징(100) ⑤ 행 선택(확인 대상)은 체크박스 다중.
- 행 키가 `row_number()`가 아니라 (체크리스트 id, 작성자 id)다(위 SQL 이식).
- 출력/다운로드는 RD 뷰어 대신 xlsx(F05·E10과 같은 방식). RD 양식과 같은지는 확인 못 함.
- 콤보 폭 80(원본 60) — K01·K05와 같다.
