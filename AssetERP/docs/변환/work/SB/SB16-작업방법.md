# SB16 BatchMain `extrFundHoldItem` — 작업방법

골격은 `SB01-작업방법.md`. SB14 `extrFund`와 같은 계열(타사무 SFTP 수신분, **ICAM 없음**)이라 `BatchExtrMapper`에 SQL을 더했다.

## extrFundHoldItem 분기
- 원본 `BatchMain.extrFundHoldItem` L2176-2249. `GET·POST /api/v1/batch/extrFundHoldItem?companyId=ALL|숫자&ifCode=ALL|SFTP_SHFP_01…&sendDate=yyyy-MM-dd&worker=…`
- `sendDate` 없으면 오늘(원본의 전영업일 계산은 주석 처리). 송신일은 `yyyyMMdd`로 바꿔 `ifi34_stk.ifi34_send_date`와 비교.
- 처리: `ifi34_stk ⨝ ifi29_am_corp_mapping`(기간 맵핑)에서 수신분의 **(회사, 기준일)** 조합을 구해 각각 `flt09_fund_item.deleteByStdDate` → `insertByIfi34`(수신분 전부, 종목구분 `2010` 고정).
- 한 트랜잭션, 실패 시 원인 문구만. 결과 문구(그대로): `extrFundHoldItem 작업완료..commit`.
- 원본-이상한점 #211(종목구분 2010 고정, sendDate 오류 NPE → TOBE는 거절, 사용자 입력분도 지워짐).
