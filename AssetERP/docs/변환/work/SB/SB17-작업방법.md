## icamFundBook 분기
- 원본 `BatchMain.icamFundBook` L3034-3123. `GET·POST /api/v1/batch/icamFundBook?companyId=ALL|숫자&startDate=yyyy-MM-dd&closeDate=yyyy-MM-dd&worker=…`
- 기간: `startDate` 없으면 종료일=어제, 시작일=종료일의 3개월 전. 있으면 `startDate`·`closeDate` 둘 다 필요(#212).
- 회사: `sys01_company.selectIcamCompanyExcept` = ICAM 회사코드가 있는 사용 중 **A1(자산운용)** 회사.
- 회사마다: ① `icam06_fund_book.deleteByStdDate`(그 ICAM 회사·기간) ② ICAM `icam06_fund_book.selectIcamFundBook` 읽기(0건이면 `icamFundBook(icam06) data size : 0` 알림) ③ 각 행 `icam06_fund_book.insert`(회사코드·작업자는 액션이 채움).
- 한 트랜잭션, 실패 시 원인 문구만. 결과 문구(그대로): `펀드원장 작업완료..commit`.
