# SB04 BatchMain `flt11Insert` — 작업방법

골격은 `SB01-작업방법.md`. 이 ID는 `BatchAction` 구현체 `Flt11InsertAction`(`biz.batch.action`) 하나다.

## AS-IS → TOBE
- 원본: `BatchMain.flt11Insert L278-306` (`/BatchMain?actionCode=flt11Insert`)
- 처리: 사용 중인 회사마다 `flt11_book.deleteByCompanyId`(오늘 이후 원장 삭제) → `flt11_book.selectInsert`(직전 영업일 원장 중 수량 > 0을 오늘 날짜로 복사) → commit
- 호출: `GET·POST /api/v1/batch/flt11Insert` (파라미터 `stdDate`가 필요한 작업만 사용). 인증은 API key + IP.
- 결과 문구(그대로): `자기매매 보유원장 이월 작업완료.. commit`
- 한 트랜잭션: 모든 회사를 `@Transactional` 하나로 묶는다(AS-IS도 한 SqlSession, 마지막에 commit, 예외 시 rollback). 실패하면 `sys97_notice_log`에 `BatchMain.flt11Insert` 오류가 남는다(`BatchService`).

## SQL 이식
`flt11_book.deleteByCompanyId` → `BatchFltMapper.deleteFlt11FromToday`; `flt11_book.selectInsert` → `BatchFltMapper.insertFlt11Carry`(둘 다 본문 그대로)
날짜 파라미터는 DB 함수 시그니처가 `date`라서 `LocalDate`로 넘긴다(AS-IS의 `java.util.Date`와 같은 값).

## 공통 절차와 다른 점
- 응답은 `ApiResponse<BatchRes>`(SB01 결정).
- `stdDate` 형식 오류는 AS-IS처럼 null이 된다(원본-이상한점 #201).
