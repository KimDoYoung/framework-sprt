## icamPrice 분기
- 원본 `BatchMain.icamPrice` L2763-2845 + `insertStkItem` L2847-2869. `GET·POST /api/v1/batch/icamPrice?stdDate=yyyy-MM-dd&worker=…` (**companyId 없음** — 회사 무관 공통 시세)
- `stdDate` 없으면 직전 영업일. 형식이 틀리면 거절(#215). 한 트랜잭션.
- 처리: ① `icam20_price.delete`(그 날 전체) ② ICAM 읽기 두 가지: `icam20_price.selectIcamStkPrice`(주식, 테이블 `oms9jj`, 현재가≠0), `icam20_price.selectIcamFundPrice`(사모펀드 기준가, `pzm1ti`) — 각각 0건이면 `icamStkList(icam20) size : 0` / `icamFundList(icam20) size : 0` 알림 ③ 주식: 종목구분 `2010`으로 `icam20_price.insert` 후 `insertStkItem` ④ 펀드: `2050`으로 insert.
- `insertStkItem`: `com50_item`을 (표준코드, 2010)으로 찾아 없으면 insert(코드=표준코드, 이름, 구분, 단축코드=코스콤코드), 있으면 종목명이 다를 때만 이름 update.
- 결과 문구(그대로): `시세 작업완료..commit`. 오류: 원인 문구만.
