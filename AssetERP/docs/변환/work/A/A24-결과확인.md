## 남은 문제
- **미확인**: 사원이 실제로 접속한 상태에서 알림이 수신되고 강제 로그아웃으로 그 화면이 끊기는 왕복(실제 사용자에게 영향이 가고, 사원 계정으로 로그인할 방법이 없어 시험하지 않음). 서버 쪽은 `PushService`·`AuthService.forceLogout`(B06·B04 기반)에 위임하고 호출 인자는 Mockito로 확인.
- "전송 및 로그아웃"의 5분 뒤 자동 로그아웃은 원본에도 없다(작업기록 제안).
