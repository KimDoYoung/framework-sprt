## 의존 (사용자 결정 대기)
- **가져오기 실제 구현**: D07과 같은 외부 ICAM DB 연동(`BatchMain.icamOfficeMngFee`·`icamFundMngFee`). 지금은 "ICAM 연동(외부 ICAM DB)이 아직 없어 발생보수를 가져오지 않았습니다"만 보인다. D09 `Icam50_Tab_DbSource`도 같은 연동일 가능성이 크다.

## 제안 (사용자 승인 전 반영 안 함)
- 사무관리보수(20407)는 원본이 회사 ID 1을 고정으로 보내 조회·가져오기를 하는데, 이 DB의 `icam10_fee`에는 회사 1 행이 없어 기본 구분 조회가 0행이다. 운영 DB의 회사 ID와 다를 수 있어 원본 그대로 두었다.
- 원본은 가져오기 결과를 화면에 알리지 않는다(숨은 폼 제출). TOBE는 거절 사유를 오류 메시지로 보인다.
- 가져오기 버튼 type은 `button-types`에 없어 `download`로 골랐다(D07과 같음).
- 관리자 회사가 아니면 자기 회사만(서버 보강, 05 §6 회사 조건). 단 사무관리보수는 회사 1 고정이라 회사 1이 아닌 비관리자는 거절된다.
- yunhee 개선: `compare`가 `PageRes`({total, rows}) 응답의 `rows`를 풀어 비교하지 못한다(D07·D08 모두 건수를 `analysis sql --count`로 따로 대조).
