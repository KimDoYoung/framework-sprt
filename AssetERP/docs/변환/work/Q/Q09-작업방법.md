## 공통 절차와 다른 점
- 원본 `LoginUser.getOrgCodeId()`와 담당자 조직(`managerOrgId`, 수행시작일 기준 `f_get_emptrans`)을 클라이언트에서 비교하는 검사를 그대로 옮겼다. 서버는 이 검사를 하지 않는다(원본도 클라이언트 검사) — 제안으로 남김.
- 삭제를 선택 없이 누르면 원본은 서버를 부른 뒤 NPE(첫 선택 행이 null) — TOBE는 "삭제할 행을 선택하세요." 경고(05 §8 공통 결정).
- 등록 창의 새 번호는 첨부파일을 먼저 올리려고 받는다. 창을 [저장] 없이 닫으면 올린 파일은 고아로 남는다(원본 그대로).
- 수행계획 편집기(`HtmlEditor`)는 잠글 수 없어 바깥 `div`에 `pointer-events: none`으로 막는다(공통 부품은 안 바꿈).
