## 공통 절차와 다른 점
- 엑셀 템플릿 `Template_공모주청약 펀드배분.xlsx`·(Q07용) `Template_공모주참여계좌.xlsx`는 새 원본(IDMS-IC)의 `webapp/excelTemplete`에 없어 옛 원본 트리(`~/work/oms-react/asis/src/main/webapp/excelTemplete`)에서 파일만 복사했다(코드가 아닌 정적 양식).
- 수요예측에 펀드별 신청이 하나도 없는 채로 "수요예측 신청내역"에서 청약을 만들면 AS-IS는 `oprFundList.get(0)`에서 IndexOutOfBounds → 실패한다. TOBE는 배정 없이 청약만 만든다.
- `UpdateDataModel`이 모델의 비어 있는 값은 안 쓰므로 수요예측에서 복사한 배정 행의 `fundAdviceType`은 AS-IS처럼 null이다(조회 SQL은 ID로 두 테이블을 모두 본다).
- 03 원칙 4의 예외가 아니라 05 §8 ②와 같은 처리: [삭제](본 화면·아래 목록)에서 고른 행이 없을 때 AS-IS는 빈 확인창/NPE → 안내만.
