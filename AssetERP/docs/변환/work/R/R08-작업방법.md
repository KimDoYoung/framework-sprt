## SQL 이식
- `ast01_class_tree.selectByCompanyId`: 재귀 CTE 그대로 이식. `isPostgreSql` 분기 없이 PostgreSQL 전용으로 최적화.
- `ast01_class_tree.selectByParentId`: 그대로 이식 (`ast01_company_id = #{companyId}`, `ast01_parent_tree_id = #{parentId}`, `ast01_type_cd = #{typeCode}`).
- `ast01_class_tree.createCode`: `SELECT f_create_ast_class_tree_cd(#{parentId}, #{typeCode}, #{companyId})`.
- `ast01_class_tree.insert` / `infoUpdate` / `modelUpdate` / `updateParentId` / `delete`: 원본 쿼리 그대로 이식.
- `ast10_manager.selectByLinkId` / `insert` / `update` / `deleteByLinkId`: 원본 쿼리 그대로 이식.
