## SQL 이식
`selectByDepnDate2`: 원본 안쪽이 `ast13_book_depn.*`·`ast01_class_tree.*`를 계산 열과 같은 이름으로 중복해 뽑고 결과 맵이 먼저 나온 열을 읽는다 → 이식은 PostgreSQL이 모호하다고 거부하므로 안쪽 `.*` 대신 쓰는 열(`ast13_book_depn_id`·`pur_tr_id`·`pur_date`·`pur_amt`·`retire_date`·`acm_depn_cost`, `ast01_depn_type`)만 명시하고 바깥에 한 겹 더 감쌌다. 결과는 같다(`compare` 17=17·19=19). `retireYn` 문자열 비교는 `<if test="!retireYn">`, `#{depnDate}::date`는 `CAST(… AS date)`.
