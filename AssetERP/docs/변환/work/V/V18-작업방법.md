## 공통 절차와 다른 점
- 호출 화면 행(`gridDataModel`)을 믿지 않고 `refId`(퇴직정산 급여 월 ID)로 서버가 다시 읽는다(V22와 같음). 월 ID가 로그인 회사의 퇴직정산(03)이 아니면 거절.
- `retireDate`는 `f_get_emptrans`가 `yyyy-MM-dd` 글자로 준다(AS-IS는 Date로 받아 같은 형식으로 찍음).
- AS-IS는 `updateApprId` 뒤에 상신 상태를 다시 읽지 않는다 — 그대로(다시 조회하면 바뀐다).
