## 한계 / 넘긴 것
- **A52 (사용자 선택 범위 중 일부를 하지 않았다)**: 호출 단추가 원본에서도 툴바에 붙지 않아 도달할 수 없고(`Ics31_Tab_ComplianceConfirm` L110 주석) 목록창 `Ics32_Lookup_RelateAppr`·`ics30_compliance.selectWriterList`(CTE 100줄+ 이식)가 TOBE에 없다 → 01v **V28**로 넘김.
- **RD 첨부 PDF·[미리보기]**: A27 `createRd`·`viewRd`, A32 `createRd`는 RD 서버가 PDF를 만들어 서버 폴더에 저장하고 앱이 `sys10_file`에 이름을 바꿔 등록한다(`fileReName`). TOBE에는 RD 리포트(`.mrd`)·PDF 엔진이 없다. RD 대책 결정 뒤에 연결(V11·V25와 함께).
- 이 회사 기준 A27/A32 문서분류(`dcr30_link`)가 없을 수 있다 — 그때는 `Dcr01_Lookup_Class`(A27)나 [문서분류](A32)로 고른다.
