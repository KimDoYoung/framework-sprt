## 공통 절차와 다른 점
- 새 등록 행은 그리드에 먼저 넣지 않고 저장 뒤 다시 조회한다.
- 신청자·회사는 서버가 로그인에서 정한다(요청 본문에 신청자 ID 없음). `privateYn`은 varchar 열이라 서버가 'true'/'false' 글자로 넣는다.
- `Emp00_Lookup_SelectSingle`은 `open(Date, callback)`(널 단추 없음)이라 `noneLabel={null}`로 쓴다. 조직명은 `orgKorNm`(원본 `orgTitleName`과 같은 `f_org_nm`).
