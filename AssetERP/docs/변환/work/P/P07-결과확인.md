## 남은 문제
- 항목 7·7-1 브라우저 시험은 도메인 일괄 때. RD 엑셀(파일명·내용)은 `tools/run-rd-server.sh`를 켠 뒤 일괄 때 같이 확인.
- **`fnd25_terms.fnd25_fund_id`의 값(펀드↔규약 연결)이 비어 있어 최종 규약 3열과 규약 팝업의 데이터 경로는 DB 값으로는 시험하지 못했다.** 값이 들어오면 `/fund-codes/search`와 `terms/{id}/details`를 `yunhee api`로 다시 확인한다.
