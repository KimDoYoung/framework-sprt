## 제안 (사용자 승인 전 미반영)
- 원본 `Car04_Lookup_PublicJournal.update()`에는 일반업무용 거리가 0이 아닐 때 행선지·목적을 다시 검사하는 부분이 있는데, 앞의 무조건 검사와 겹쳐 실행되지 않는다(죽은 코드). 그대로 두었다.
- 확정은 로그인 사원 몫(예약자 또는 등록자) 행만 바꾼다. 같은 달 다른 사람의 예약은 확정 대상이 아니다 — 원본 그대로이며, 관리 부서가 한꺼번에 확정하려면 별도 화면(T15 변경 화면)을 쓴다.
