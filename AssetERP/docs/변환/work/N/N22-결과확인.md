## 남은 문제
- 항목 7·7-1 브라우저 시험은 일괄. 위 부서 점검현황 묶음 헤더, 목록의 점검 아이콘(점검상태 없는 행은 숨김), 점검상세 창의 모양·단추 상태(점검진행에서만 [점검완료][저장] 활성, 점검완료에서 [완료취소])는 눈으로 못 봤다.
- **증빙자료가 없어 "적정"으로 점검완료가 안 되는 점검이 있다(2단계 전까지).** `tdm91_company_setup`에 설정이 없거나 증빙 필수 설정이 켜진 기간이면 적정은 증빙이 1건 이상이어야 하는데, 증빙을 올리는 창이 아직 없다. 해당없음(9)·미흡(2)·개선(3)은 막지 않는다. kfstest 설정은 2026-01-11부터 증빙 필수가 꺼져 있다.
- [AI] 점검의견 자동 작성(`BotService`가 외부 AI 서버로 POST — 주소 설정 필요)은 연결하지 않았다.
- 시험 흔적: DB 테스트는 모두 롤백. API는 GET만 불러 흔적 없음.
