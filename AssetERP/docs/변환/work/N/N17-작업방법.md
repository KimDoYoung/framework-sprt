## 공통 절차와 다른 점
- 책무관리자(`checkIsManager`) 여부는 화면 열 때 한 번 읽는다. 관리자가 아니면 부서 칸이 비활성이고 매뉴얼 선택 창이 작성중만 조회(비활성)로 열린다 — 원본 그대로
- `copyDutyList`·`copyManlList` 서버 처리는 원본처럼 항목마다 새 번호를 받아 한 트랜잭션에서 넣는다. 원본은 오류 메시지를 `<br>`와 예외 메시지 앞 100자로 만들었는데, TOBE는 같은 안내 문구 + 서버 로그에 상세
- 작성완료 뒤 TabPage 버튼 활성화는 원본처럼 `endYn`에 따른다(작성완료면 등록·삭제·불러오기 비활성)
