## 남은 문제
- 항목 7·7-1 브라우저 시험은 일괄. 위 부서 점검현황 묶음 헤더·합계, 점검항목 목록의 그룹 머리글·행 번호, 승인선 창의 위로/아래로와 view 모드(두 열 숨김), 사원찾기 창, 점검이력 창의 모양과 동작은 눈으로 못 봤다.
- **확정·승인요청의 API 실데이터 시험은 하지 않았다** — DB 테스트(롤백)로 갈음했다. 서비스 중간 실패가 AS-IS에서 롤백되는지는 확인하지 못했다(작업기록 "결정").
- 점검항목 [상세] 아이콘의 점검 창은 N22에서 연결한다.
- `Emp00_Lookup_SelectMulti`가 승인선 등록에 로그인 회사 사원을 정확히 가져오는지(겸직 없음)는 브라우저 시험에서 본다.
