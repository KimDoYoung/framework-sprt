## 공통 절차와 다른 점
- **일괄 알림발송**: 원본은 대상 사원마다 Talk·메일·SMS를 보내고 `confirm_sms_yn`을 'true'로 바꾼다. TOBE에는 Talk·메일·SMS 발송 연동이 없다(`SmsSender`는 `DisabledSmsSender`). 보내지 않은 건을 보냈다고 표시하지 않도록, 대상 사원이 있으면 **발송 없이** "알림 발송 연동이 아직 없어 N명에게 발송하지 않았습니다" 오류로 끝낸다(플래그 변경 없음). 대상이 0이면 원본처럼 "0건이 발송완료되었습니다". 발송 연동은 별도 B 작업 후보.
- 승인 사유 창에서 사유를 비워 [저장]하면 빈 글을 그대로 처리한다(반려만 필수). 원본은 `TextArea.getText()`가 빈 칸일 때 null이라 승인에서 비우면 "승인이 취소되었습니다"로 갈 수 있으나, 반려 검사(`== null`)와 같은 뜻인지 확인하지 못해 **비운 승인은 처리**로 두었다(미확인 — 결과확인 남은 문제).
- 신고자 사원찾기는 AS-IS가 `open(오늘, "One", cb)`(널 단추 없음)이라 [전체]를 뺐다 → 공통 부품에 `noneLabel`(null = 단추 없음) 추가. 협의승인자 지정은 `openNull`([선택안함]) → `noneLabel="선택안함"`.
- 날짜 열 폭은 AS-IS 그대로 90. 정렬은 서버 `ORDER BY`뿐(03 원칙 13).
- 쓰기 SQL 세 개에 `flt10_company_id` 조건을 더했다(원본은 trId만) — 다른 회사 행을 못 바꾸게.
