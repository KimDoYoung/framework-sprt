## 결정
- I06(계좌대체)과 같은 테이블·서버 메서드지만 열이 달라(출고계좌 없음, 거래구분·비고 있음) 컨트롤러·서비스·DTO를 `FltRightsExercise*` 한 벌로 따로 뒀다. 매퍼 SQL 조각과 원장정리 문장은 I06 것을 재사용했다.
- 거래구분명(`tr_type_name`)은 I06 안쪽 조각에 없던 `f_cdnm(...)`이라 바깥 SELECT에 직접 넣었다(AS-IS는 안쪽에서 만들지만 쓰는 열이 같아 결과 같음, `mapper-run --compare`로 7=7 확인).
- 종목유형 콤보의 'I' 가지(신고대상 아닌 종목유형만)는 원본이 서버 SQL의 `targetYn` 가지로 하지만, 기존 API가 `targetYn`을 열로 주므로 화면에서 거른다 — 새 SQL을 늘리지 않았다.
- 종목 칸은 원본이 `LookupTriggerField`의 `setEditable`로 주식시세 적용 여부에 따라 직접 입력을 허용한다. `LookupInput`은 읽기 전용이라 `Input` + 돋보기(`addonAfter`)로 만들었다.
- 거래구분 콤보 "전체"의 값은 `%`(원본 `CommonComboBoxField(…, "%", "전체")`)이고 선택 즉시 조회한다(원본 `Collapse`는 같은 값을 다시 골라도 조회하지만 TOBE는 값이 바뀔 때만 — 같은 값 재선택 시 조회가 안 된다는 작은 차이).
- 변경 창은 저장 성공 직후 `createBook`(원장정리)이 실패해도 창을 닫지 않는다. 다시 [저장]을 눌러도 같은 행을 갱신하도록 저장된 `trId`를 기억한다(I06과 같은 결정).
