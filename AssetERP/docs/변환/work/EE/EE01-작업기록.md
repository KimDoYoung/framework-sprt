## 한계 / 넘긴 것
- [상세보기]는 안내만(다음 단계: 열람권한 + 폐기문서 보기). 브라우저 시험은 일괄 때.
- `mapper-run`은 `@Param("c")`의 점(`c.companyId`) 파라미터를 못 받아 조회 문장은 `yunhee compare`(API 경유)로 대조했다.

## 원본 이상한 점
- `selectByCompanyId`의 `closeDate`는 날짜(00:00)라 `apr99_reg_date BETWEEN` 때문에 종료일 당일 등록분은 시각이 있으면 빠진다. 원본 그대로 옮겼다.
- 원본 `restore`는 회사 조건이 없다(TOBE는 추가).

## 제안 (03 원칙 5)
- yunhee: `mapper-run`이 `c.xxx` 형태 파라미터를 받으면 `@Param` 객체를 쓰는 조회 문장도 `--compare`로 대조할 수 있다. page-style 판별기가 연결 클래스(`*_Edit_ApprDoc`)를 편집 팝업으로 보지 않게 하면 SGP 오판정이 줄어든다.
