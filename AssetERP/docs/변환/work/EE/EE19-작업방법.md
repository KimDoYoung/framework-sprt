## 공통 절차와 다른 점
- 사용여부 열(`addBooleanString`)은 "사용"/"미사용" 글자다. `gb`에 같은 헬퍼가 없어 `gb.text` + `valueFormatter`로 그렸다.
- 그리드의 [파일다운]은 원본 모델에 `fileId` 매핑이 없어(`analysis model`: resultMap 열 비어 있음) 원본에서는 `fileId=null`을 보낼 수 있다 — TOBE는 SQL이 돌려주는 파일 번호로 내려받는다(작업기록 제안 아님: 동작을 고친 것이 아니라 보이는 동작을 같게 한 것).
- 등록 때 새 행을 그리드에 끼우지 않는다(팝업이 값을 들고 있다가 저장하면 목록을 다시 조회한다, SGP 견본과 같다).
