## 공통 절차와 다른 점
- **진입점**: AS-IS는 `commutePopupYn`이 켜진 회사만 로그인 직후 자동으로 뜬다(그대로 구현). 시험용으로 TOBE TopBar에 시계 아이콘 "출퇴근"을 더했다(사용자 승인 2026-11-04) — AS-IS에는 없는 진입점.
- 서버가 `baseDate`를 오늘이거나 본인 마지막 근무일일 때만 받는다(AS-IS는 클라이언트 값을 그대로 씀) · 사유·퇴근시간은 본인 행만 수정(보안 보강, 매퍼 `countMine`).
- `getLastInfo` SQL에는 `att02_status_cd` 열이 없어 AS-IS의 `"99".equals(statusCode)` 분기는 항상 거짓이다 — 같은 모양으로 옮겼다(`원본-이상한점` 참고).
