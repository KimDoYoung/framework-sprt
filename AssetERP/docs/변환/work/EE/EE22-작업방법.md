## AS-IS 결함 의심 (옮길 때 판단 — 사용자 결정 대기)
1. `biz51_erp_cont_corp.selectById`: 상품코드 이름을 `f_cdnm('ContStatusCode', sys01_erp_product_cd, …)`로 구한다(목록 쿼리는 `'ErpProductCode'`). 화면은 `biz51_erp_product_nm`을 쓰지 않아 영향 없음 → **그대로 옮긴다**(원칙 4).
2. `Biz52_Lookup_ErpFee.insertRow`: 새 행 시작일을 만들 때 `CalendarUtil.addDaysToDate(lastModel.getCloseDate(), 1)`이 **원본 행의 종료일 객체를 직접 바꿔** 그리드의 직전 행 종료일이 하루 밀려 보인다(저장 전에는 DB와 다름, 그 행을 저장하면 하루 밀린 값이 저장될 수 있음). TOBE는 날짜를 새로 계산해 원본 행을 건드리지 않는다 — 원칙 4 예외 후보(결과가 의도에 맞게 됨). **승인 필요**.
3. `Biz51_ErpContCorp.deleteList`: DB 행만 지우고 첨부파일의 실제 파일은 그대로(다른 화면과 같은 방식).
4. `sys10_file.deleteByParentId`는 `${apprId}` 치환(숫자 ID만 들어와 안전) — TOBE는 바인드 변수로.
