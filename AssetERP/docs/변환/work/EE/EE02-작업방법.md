## 공통 절차와 다른 점
- 기간 중복 검사: 원본은 클라이언트가 그리드 전체 + 서버의 그리드 밖 행을 합쳐 검사. TOBE는 서버가 수정 행 + 수정 안 한 DB 행으로 검사하고, 화면은 그리드 전체로 먼저 검사한다. 새 행도 원본처럼 ID가 있는 것으로 보고(임시 음수 ID) 검사한다.
- 그룹 헤더 "대결자"의 파란 글씨(`setHtmlGridStyle`)는 부품에 헤더 색 옵션이 없어 열 글자색만 파랑으로 했다.
- 시작일 `minDate`(오늘) 제한은 이 화면에 없다(G05에만 있음).
