## API / SQL
새 API 2개(`FndPlanController`, `/api/v1/fnd/plans`): `GET /todo`(`selectById`·`selectByPersonId` — `FndPlanMapper`의 기존 `planColumns`와 같은 식에 펀드명(`fnd02_fund_info` 서브쿼리)만 더한 `todoColumns`, 회사 조건은 더했다) · `POST /{planId}/appr`(`Fnd20_Plan.insertAppr` L93-162). `insertAppr`는 상신 문서가 없으면(결재 상태 `closeYn`이 없으면) ① 문서 번호·기본 서식·기본 결재선을 `AprApprNewService.open`(= AS-IS `Apr04_ApprStep.createApprovalTypeCd`)으로 받아 ② `apr01_appr` 임시저장(99)·내부문서(20)·제목 " "로 넣고(`AprApprWriteMapper.insertAppr`, 문서번호 식별단어 `selectDcrIdWord` 포함) ③ 연관펀드 한 줄(`insertRelateFund`) ④ 결재선(`insertStep`, 상태는 만든 그대로) ⑤ `fnd20_plan.fnd20_appr_id`를 기록한다(`updateApprId` 새 문장). 이미 있으면 그 문서 ID를 그대로 돌려준다.
