## AS-IS와 다른 점 (사용자 확인용)
- 전환 방식: 세션 교체 → JWT 재발급 + 화면 새로고침.
- 서버가 대상 사원이 로그인 사원의 겸직 목록에 있는지 검사한다(AS-IS는 클라이언트가 보낸 `personId`로 바로 `getChangeInfo` — 서버 검사 없음, 보안 보강).
- `login()` 모드·[확인] 버튼은 만들지 않았다(LoginPage).
- 진입점: AS-IS는 사용자 이름 옆 ▼ 단추 → TOBE는 사용자 이름 드롭다운의 [겸직전환] 메뉴(TOBE TopBar 구조에 맞춤).

## 제안 (승인 전 반영 안 함)
- 겸직전환 감사 이벤트를 `LOGIN_SUCCESS`와 구분하는 전용 이벤트(`TITLE_SWITCH`) 추가 — 감사 이벤트 enum 변경이라 승인 뒤.
