## AS-IS와 다른 점 (사용자 확인용)
- [다시 표시하지 않음] 체크박스는 만들지 않았다 — AS-IS에서도 화면에 붙이는 줄이 주석이다.

## 사용자 확인 필요
- 작성 창(`open`)의 호출처 `Sys55_Tab_MenuGuideCompany`와 메뉴 열 때 자동 안내(`MenuOpener`)는 TOBE에 없어 연결하지 않았다. 보기 창은 `Emp91_Lookup_List`에서 열린다.
- 로컬 `sys55_menu_guide_company`가 비어 있어 보기 창이 실제 내용으로 뜨는 것은 확인하지 못했다(`미확인`).

## 제안 (승인 전 반영 안 함)
- AS-IS는 저장 뒤 `menuGuideCompanyId`에 회사 ID를 넣어(L213) 같은 창에서 두 번째 [저장]이 UPDATE 0행(저장 안 됨, "저장이 완료되었습니다."는 뜸)이다. 반환된 `menuGuideCompanyId`를 쓰도록 고치면 좋다.
- 저장할 때마다 `sys55_note`를 NULL로 덮는다. 기존 note를 유지하도록 고치면 좋다.
