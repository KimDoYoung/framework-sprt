## AS-IS와 다른 점 (사용자 확인용)
- AS-IS 그리드의 **부서·완료일 열은 SQL에 값이 없어 항상 빈칸**이다(`Opr01_CreateModel`의 부서 속성에 해당 열이 없고 완료일은 `opr03_reg_date`인데 이 SQL은 `opr03`을 읽지 않음) — TOBE도 열은 두되 빈칸이다.
- AS-IS [확인]은 한 건도 체크하지 않아도(빈 목록으로) 부른 쪽을 부르고 닫는다(`selectList != null`이 늘 참이라 "조회할 펀드를 선택해주세요" 안내가 안 나옴) — TOBE도 같다.
- 담당자 SQL 변경은 위 "SQL을 고친 곳".

## 사용자 확인 필요
- 호출처 `Opr02_Tabpage_Fund_Manager`(Opr 도메인)가 TOBE에 없다 — 창만 만들고 연결 안 함.
