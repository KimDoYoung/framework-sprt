## 화면 구성
- 바깥 여백 20·배경 흰색, 가로 `Splitter`: 왼쪽(20%, 최대 1000) = 툴바(오른쪽 정렬 [권한복사][조회]) + 조직 트리, 오른쪽 = 트리 그리드(문서분류 300 · 조회 60 · 작성 60 · 조회순서 80 · 상세설명 400) + 아래 흰 줄(60) ([전체선택][전체해제]) [저장] + 안내 문구
- 조직 트리는 기본 GXT Tree라 한 번 눌러도 열리지 않는다(화살표·더블클릭으로 연다). 문서분류 트리 그리드도 처음엔 접혀 있다(getServiceResult에 expandAll 없음)
