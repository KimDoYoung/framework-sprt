## API / SQL
`POST /api/v1/sys/login-manages/requests` — AS-IS `sys27_login_manage.selectByMacAddress`(중복) → `insert`. 이미 신청한 기기면 `false` → "이미 신청완료된 기기입니다". 메시지 "구분 값을 먼저 선택해주세요"·"간단한 사유를 입력해주세요" 그대로. 기존 `SysLoginManage*`에 메서드만 더함.

## 공통 절차와 다른 점
- **도달 불가**: 호출처 `LoginPage.checkMacAddress()`(L610~)는 `@SuppressWarnings("unused")` 이고 어디서도 부르지 않는다(AS-IS 로그인은 기기 승인을 검사하지 않는다). 창은 만들었지만 **화면에는 연결하지 않았다**. 연결이 필요하면 로그인 판정(기기 승인)과 함께 설계한다.
- 사원·회사는 요청 값이 아니라 로그인한 사용자(서버). 브라우저는 기기 Mac 주소를 알 수 없어 Mac은 비운 채 저장된다(AS-IS는 별도 프로그램이 준 `LoginUser.getMacAddress()`). 따라서 같은 사원의 두 번째 신청은 "이미 신청완료된 기기"로 막힌다(빈 Mac끼리 같다고 본다).
