## 제안 (03 원칙 5 — 사용자 승인 전에는 반영하지 않음)
- 요청사 칸: 원본 `Scm01_Edit_DevMng`은 `corpName`·`Biz13_Lookup_WithCorp`를 만들어 두고도 폼에 붙이지 않았다(죽은 코드). 화면에 요청사를 보여줄지 사용자 결정 — 지금은 원본 그대로 없다.
- 서버 보안: 개발 관리 쓰기 API(`PUT devs`·`PUT dev-steps`·`PUT dev-mng`)는 원본처럼 호출자 검사가 없다(화면이 메뉴 권한으로 막음). 개발자 본인·개발 관리자만 쓰게 서버에서 막을지 사용자 결정.
- 데이터 정리: 개발자를 지우면 진행단계는 같이 지우지만(원본 그대로) 개발 프로그램(`scm13`)·첨부파일은 남는다. 원본도 같다.
- 원자성: 원본 진행상태 [저장]은 삭제·저장을 두 호출로 부르지만 여기는 한 트랜잭션 한 호출(`PUT dev-steps`에 `deleteIds`+`steps`)이다 — 결과는 같고 중간 실패 시 어긋나지 않는다(작업방법에 기록).
- 부품 제안: ▲▼ 이동·삭제 목록·순서 번호(10 단위) 재계산 로직이 `Scm11_Lookup_DevStep`·`Scm12_Lookup_DevStepRule`에 같은 모양으로 두 번 있다. 세 번째가 생기면 `useReorderRows` 같은 훅으로 뽑을 후보.
