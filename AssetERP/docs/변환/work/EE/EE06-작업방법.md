## 화면 구성
- 바깥 여백 20·배경 흰색, 가로 `Splitter`: 왼쪽(400, 최대 1000) = 툴바(문서분류 · 입력 100 · [찾기]) + 트리, 오른쪽 = 트리 그리드(조직명 300 · 조직코드 100 · 조회 60 · 작성 60 · 비고 400) + 아래 흰 줄(60) [저장] + 안내 문구
- 안내 문구: 문서세부분류 사용 회사는 "※ 특정문서분류 지정 (바로가기)", 아니면 "※ 문서분류지정이 설정되어있으면 작성권한은 자동해제됩니다. (바로가기)" — 문구 전체가 링크, "(바로가기)"만 파랑 `#0078D7`

## 공통 절차와 다른 점
- 작성여부: 문서세부분류를 쓰지 않는 회사에서 Link가 걸린 문서분류는 서버가 `false`로 고친다(AS-IS와 같음). 화면에는 보낸 값이 그대로 보이다 [저장] 뒤 재조회에서 `false`로 나온다.
- 문서분류·조직은 로그인 회사 것만 저장한다(보안 보강). 원본은 요청에 실린 모델의 회사 ID를 믿었다.
- 저장 뒤 `n건 저장되었습니다.`(TreeGridUpdate 공통 안내, P02와 같음).
