## 공통 절차와 다른 점
- 선택 없이 [복구]: 원본은 선택 행이 null이라 클라이언트 오류 → 확인창 없이 "복구할 문서를 선택하세요." 경고(05 §8 선례).
- 복구가 실패한 경우: 원본은 예외를 삼키고 status -1 → "폐기문서 복구 중 문제가 발생했습니다…". TOBE는 4문장을 한 트랜잭션으로 묶어 하나라도 실패하면 모두 되돌리고 같은 문구를 보인다. 이 회사의 문서가 없으면(0건 INSERT) 원본은 성공으로 치지만 TOBE는 `DATA_NOT_FOUND`로 실패 처리(동작 같은 UI 문구, 보안 보강).
