## API / SQL
새 API 5개(`PlnResrchController`, `/api/v1/pln/resrches`; 새 패키지 `biz.pln`, 매퍼 `PlnResrchMapper`): `GET /init`(AS-IS `selectDetailInit` — 새 번호는 `common.sequenceNextVal` → `f_create_seq()`, 승인자는 `apr06_appr_step_rule_cd = 40` + `f_apr_get_approval`) · `GET /{id}`(`selectById`, 상위 분류명 열은 창이 안 써서 뺌) · `PUT`(`pln03_resrch.insert` 업서트 — 있으면 UPDATE, 없으면 INSERT) · `POST /{id}/close?close=`(`closeUpdate`) · `POST /{id}/confirm`(`apprUpdate`).
