## AS-IS와 다른 점 (사용자 확인용)
1. **회사 조건**: 연결 테이블에 회사 열이 없어 AS-IS는 조회·삭제를 회사로 막지 않는다. TOBE는 문서(`apr01_appr`)의 회사가 로그인 회사인 연결만 읽고·넣고·지운다.
2. **지출결의서 등 호출 후 새로고침**: AS-IS는 `lookupEnd(id)`/`selectById`로 그 행만 갱신. `Biz51`·`Pay50_Edit_Expense`는 같은 방식(한 건 다시 읽기), `Pay50_Tab_ExpenseRequest`는 목록 전체를 다시 조회한다(행만 바꾸는 부품이 없음).
3. **파일 끌어놓기**: AS-IS 파일 칸의 끌어놓기(`initFileDropNative`)는 `FileUpdownForm`의 파일 선택으로 대신(Biz05_Lookup_RelateFile과 같음).
4. **삭제 알림**: 연결제거 뒤 "n건 삭제되었습니다."를 띄운다(AS-IS `GridDeleteData`의 기본 알림에 해당, Biz05와 같음).
5. **tdm52 변형 제외**: `Apr05_Lookup_LoadDoc2`가 keyTable `tdm52`일 때 쓰는 `dcr.Dcr00_DocList.selectNoAuthByText`와 [연결된 문서분류만 조회](E1)는 옮기지 않았다. Tdm59(N23)·Tdm54(N24)의 증빙자료 창은 안내 그대로 — 새 ID 후보.
