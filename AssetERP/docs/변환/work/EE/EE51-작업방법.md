## API / SQL
- `GET /api/v1/emp/trans-infos/online?transDate&searchText` — AS-IS `emp00_trans_info.getOnlineList`. AS-IS는 `BroadcastWebsocket.getInfoList()`(웹소켓 접속자)를 `loginList`로 SQL에 넣는다 → TOBE는 접속자 현황(`PresenceService.searchPresence()`)의 사원 ID. SQL은 기존 `EmpTransInfoMapper`의 `emp00With`를 재사용하고 조건·정렬은 원본 그대로(`IN` 목록만 문자열 `CAST` 대신 숫자). 접속자가 없으면 AS-IS는 `"1"`을 넣어 빈 결과를 만든다 → 서비스가 빈 목록을 바로 돌려줌.
- `POST /api/v1/emp/alarms {personIds, message}` — AS-IS `SocketList`로 접속자를 확인한 뒤 `sendWebSocketAlarmMessage`로 개별 전송 → TOBE `PushService.sendToPersons`가 같은 회사 접속 중 사원에게만 `/user/queue/notifications`로 발송하고 오프라인 사원 ID를 돌려준다. 메시지 앞머리 "['이름'님이 보낸 메세지입니다.]"는 서버가 붙인다(위조 방지).
