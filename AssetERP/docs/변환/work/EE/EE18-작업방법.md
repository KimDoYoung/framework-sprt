## 공통 절차와 다른 점
- `yunhee analysis grid`는 위 그리드에 "선택 체크박스(SINGLE)" 열을 냈지만 원본은 `//gridBuilder.setChecked(...)`로 주석 처리돼 있고 `GridBuilder`는 `setChecked`를 불러야 체크 모델을 만든다 → 체크박스 없음(yunhee 수정사항 제안).
- 개발내용 열은 원본이 `devNote`(`scm10_note` 원문, HTML 태그가 그대로 글자로 보인다)다. 개발 탭은 `arrangeNote`(태그 제거본)를 쓰는 것과 다르다 — 원본 그대로(작업기록 제안).
- `Scm30_Edit_Program`은 이 화면에서 read 모드만 만들었다(나머지 모드는 EE19에서 같은 파일에 더한다).
