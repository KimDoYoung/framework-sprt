## 공통 절차와 다른 점
- **인증번호는 서버가 보관·비교**(Redis 60초, 확인 5회 제한, 맞으면 10분 동안 비밀번호 변경 허용 표시). AS-IS는 번호를 화면에 내려보내 화면에서 비교했다 — 로그인 전 공개 API에서 그대로 두면 번호가 응답에 노출돼 우회된다.
- **문자 발송 연동이 없다**(사용자 지시 2026-10-15, `DisabledSmsSender`): [전송]은 "SMS 발송 연동이 아직 없어 문자를 발송하지 않았습니다"로 거절된다 → 이 창의 전 과정은 문자 연동이 생겨야 끝까지 시험할 수 있다.
- 본문 문구 `[Asset-ERP] 비밀번호 재설정 인증번호는 'N' 입니다.`.
