## 제안 (03 원칙 5 — 사용자 승인 전에는 반영하지 않음)
- 개발내용 열: 원본 `devNote`는 `scm10_note` 원문이라 HTML 태그가 글자로 보인다(개발 탭은 태그를 뺀 `arrangeNote`). 원본 그대로 두었다. `arrangeNote`로 바꿀지 사용자 결정.
- 서버 보안: 배포처리·비고·완료 API는 원본처럼 "로그인한 사람이 배포 담당인가"를 서버에서 검사하지 않는다(위 목록이 `personId`로 거른 뒤 화면에서만 다룬다). 서버에서도 막을지 사용자 결정(EE16·EE17 제안과 같음).
- 서버 보안 2: `updateDeploy`는 배포자(`scm13_deployer_id`)를 채우지 않는다 — 원본 그대로.
- yunhee 수정사항: ① `analysis grid`가 `//gridBuilder.setChecked(...)` 주석 처리된 줄을 읽어 체크박스 열을 내 준다(주석 줄 제외). ② `mapper-run`이 `<if test="!checkBox">` 같은 불리언 분기를 문자열 파라미터로 평가하지 못한다(경고만 나옴) — `--branch '식'=on|off`가 `compare`에는 있는데 `mapper-run`에는 없다.
