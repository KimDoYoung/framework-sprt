- `GET /api/v1/emp/add-titles/login-list` — AS-IS `emp04_add_title.getAddTitleList`(UNION ALL: 본업무 + 유효한 겸직). SQL 본문 그대로, 바깥에서 그리드 열만 고름. `mapper-run --compare` 2행=2행 ✅.
- `POST /api/auth/switch-title {addPersonId}` — AS-IS `sys.Sys02_User.getChangeInfo` + `LoginUser.setUserModel`(클라이언트 세션 교체). TOBE는 JWT라 **새 토큰을 발급**한다: ① 로그인 사원(양수 ID)만 ② 대상이 자기 `login-list`에 있어야 함(아니면 403) ③ 같은 회사 계정·잠기지 않음 ④ 새 jti/refresh로 쿠키 재발급, 이전 사원 세션은 조용히 삭제(다른 탭에 종료 알림을 보내지 않음), 대상 사원의 다른 접속은 다중로그인 종료 알림. 감사 로그 `LOGIN_SUCCESS`(`겸직전환 from=…`).
- 전환 뒤 화면: AS-IS는 상단·MyPage·메뉴를 다시 만든다 → TOBE는 `window.location.reload()`(새 쿠키로 사용자·메뉴·권한을 다시 읽는다).
