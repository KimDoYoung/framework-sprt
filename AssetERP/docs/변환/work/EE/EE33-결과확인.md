## 직접 열어 본 것
- 엑셀: 시험이 만든 운용사 엑셀 1개(운영구분 1 첫 행)를 POI로 열어 머리 `No.`·펀드 합계 칸·오른쪽 요약 칸 값을 맞춰 봤다. 통합·계산상세 엑셀도 시험에서 열어 값을 맞췄다. 눈으로 엑셀 화면을 본 것은 아니다.
- PDF: 7개 중 2개(운영구분 1 케이핀자산운용·그 밖 블랙펄자산운용(일임))의 1쪽을 `pdftoppm`으로 그려 봤고, 지투지프라이빗에쿼티는 `pdftotext`로 글만 봤다 — 운영구분 1은 "운용사명 / 최저보수·분기·시작일·기준일·경과일수 / 총 보수 금액(A)·펀드발생금액(B)·청구금액(A-B)(노랑) / 펀드명·발생액 표", 그 밖은 "○○ 일별 보수현황 / 현재 / (금액:원,부가세별도) / 일별 표", 쪽번호 `1 / 4` 형식.
- 읽기 API(실서버): `GET /calcs/excel` HTTP 200(xls 시그니처), `GET /files/zip` 2024-06-30은 첨부가 없어 404 "파일 리스트가 없습니다."(작업기록 다른 점 3).
