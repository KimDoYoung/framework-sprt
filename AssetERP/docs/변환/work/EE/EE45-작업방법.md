## 공통 절차와 다른 점
- 문서분류 칸은 AS-IS `LookupTriggerField`의 안내글(emptyText)을 `LookupInput`의 placeholder로 보인다. 처음에도 `classTreeModel = defaultModel`이라 값이 비어 있어도 기본 문서분류로 상신된다.
- 파일 삭제 상태 1(연결만 지움) 뒤 원본은 `retrieve()`만 불러 파일 목록이 낡을 수 있다 — TOBE는 한도 그리드와 파일 목록을 모두 다시 읽는다.
- 모달의 X(닫기)도 [닫기]와 같이 `onClose`를 불러 부르는 쪽이 보고주기·서약서 상태를 다시 읽는다(원본 X는 callback이 없다. 화면 상태를 새로 읽을 뿐이라 같은 결과).
- 새 DB 객체 없음(03 원칙 1). 테이블 `flt02_emp`·`flt04_oath`·`flt07_family_consent`·`sys10_file`(기존).
