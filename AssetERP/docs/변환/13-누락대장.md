# 13. 해야 할 일 (미변환·미연결 창)

2026-11-05 조사로 새로 썼다. 옛 "누락 대장"(화면 104개 분류·미변환 목록 1·2 정리·JSP 정리)은 git 이력 `639c0c7c`에서 본다.

- **조사 범위**: `kfstest/104`·`kfstest/admin`으로 로그인했을 때 보이는 메뉴(`GET /api/v1/sys/menus`)를 합친 388개에서, 메뉴명에 `(X)`·`(구)`가 붙은 5개를 뺐다. 남은 `_Tab_` 클래스는 377개다. 각 Tab `.tsx`와 그 파일이 import하는 하위 파일(Grid·TabPage·Edit·Lookup)을 모두 봤다.
- **"미연결"의 뜻**: 창은 TOBE에 변환돼 있는데, 그 창을 열어야 할 자리에 "…다음 단계에서 연결됩니다" 같은 `message.info` 안내만 있는 것이다.
- **고칠 때**: 각 줄의 `message.info(...)`를 그 창을 여는 코드로 바꾼다. 원본의 사전 검사(예: 상태 30이 아니면 경고)는 그대로 둔다. 연결하는 방법은 이미 연결된 화면을 본뜬다(`yunhee grep "from .*Apr01_Edit_ApprDoc" frontend/src`).
- **진행 표시**: 끝낸 줄은 `- [x]`로 바꾼다. 줄 번호는 조사 시점 기준이다.
