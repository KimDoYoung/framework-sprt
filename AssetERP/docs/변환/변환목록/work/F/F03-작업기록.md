## 결정 (사용자 확인 필요 없는 것)
- 오른쪽 목록 툴바는 노드를 고르기 전, 그리고 법규분류(`IC`)를 골랐을 때 비활성이다(`typeCode`가 `IC`면 `buttonBar.setEnabled(false)`). 문서는 법규구분(`IT`) 노드에만 쌓이는 구조다.
- `search()`는 먼저 `expandAll()`하고 접지 않는다(F02·E01과 다름 — 원본 코드대로). 찾은 분류는 모두 선택하지만 단일 선택이라 마지막 것이 남는다.
- 행 key는 `rowKey`(`relateFundId-순번`) — 작업방법 "다른 점".
- `emp03_trans` 조인에 발령 기간 조건이 없다(원본 그대로 이식) — 발령이 여러 번인 사원의 문서는 같은 행이 여러 번 나올 수 있다. 아래 제안.

## 제안 (사용자 승인 전 반영 안 함)
- 문서 목록 SQL이 사원 발령 이력(`emp03_trans`)을 기간 조건 없이 조인해 발령 횟수만큼 같은 문서가 겹쳐 보일 수 있다(원본 동작). 실제 데이터에서 겹침이 보이는지는 일괄 시험 때 화면으로 확인한다.
- 처음 열었을 때 오른쪽 툴바가 모두 비활성이라 어디를 눌러야 하는지 안내가 없다(F02와 같은 UX보강 후보).
