## 공통 절차와 다른 점
- 원본 `ast33_fund_trans.selectById`의 펀드명은 `ast30_book_fund_fee` 회사 조건을 두고 `selectByDate`는 두지 않는다(원본 두 SQL이 다름) — 둘 다 그대로 옮겼다.
- 이관(출)에서 외화미수보수가 NULL이면 원본은 NullPointerException(`getForFee() != 0`) — TOBE는 0으로 보고 거래·분개 생성을 건너뛴다.
- 등록 편집창 E2(`date.Collapse`)와 E1(`date.Change`)은 같은 결과(그리드 비움)라 이관일자가 바뀔 때 한 번 처리한다.
- 수정 편집창 E1(이관구분 Collapse)은 MODI에서 콤보가 비활성이라 일어나지 않아 만들지 않는다.
- 12 화면우선원칙: 편집창은 EditModal 규격(머리·푸터 선, 라벨 오른쪽 정렬), 원본 폭 950/600 유지.
