## 공통 절차와 다른 점
- [엑셀업로드]의 `deleteByCompanyId`는 AS-IS가 파일 선택 전에 부르지만 TOBE는 업로드 요청 안에서 한다(이상한점 #143).
- 변경·연관문서 아이콘은 클릭한 행을 쓴다(AS-IS는 선택된 행) — 아이콘이 행 선택을 바꾸지 않는 공통 부품 특성.
- NEW 편집창의 [닫기]: AS-IS는 먼저 넣어 둔 빈 행을 뺀다. TOBE는 저장 때만 서버에 만들므로 그냥 닫는다.
