## 화면 구성
- 레이아웃: `Splitter` 왼쪽 1000(최대 1000) / 오른쪽. 각각 테두리 박스(여백은 원본 margins 20·0·22·20 / 20·20·22·0).
- 왼쪽 그리드 `SingleGrid`(행번호, 단일 선택): 이메일 220 · 비고 500 · 수정(아이콘 60). 오른쪽 `CellEditGrid`(행번호 + 체크박스 다중): 조직 160 · 직책 100 · 사번 80 · 성명 80.
- 등록·수정창: `LookupModal` 400, 메일주소/비밀번호(마스크)/비고(높이 120), 아래 가운데 [검증][닫기].
- 버튼 type: 조회 `search`, 등록 `register`, 저장 `save`, 삭제 `delete`, 검증 `view`(색인 후보), 닫기 `close`.
