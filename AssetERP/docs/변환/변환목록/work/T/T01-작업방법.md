## 공통 절차와 다른 점
- 원본은 settings()가 회사 설정을 비동기로 읽는 동안 retrieve()를 먼저 불러, 반기별(05) 회사의 첫 조회가 기간코드 "10"으로 나갈 수 있다 → TOBE는 설정을 읽은 뒤 조회한다(결정).
- 원본의 삭제 확인 창은 제목 "확인"·폭 250인데 `useGridCrud`의 확인 창(제목 "삭제")을 그대로 쓴다. 저장 성공 메시지("N건 저장되었습니다.")는 hook 공통.
- 성명 칸 돋보기는 "선택된 행"이 아니라 **클릭한 행**을 연다(원본 `getSelectedItem()` — GXT는 셀 클릭이 행을 선택하므로 같은 행).
- AS-IS `updateList`·`deleteList`의 `orderNum` 파라미터는 SQL이 쓰지 않아 옮기지 않았다. NPE가 나는 곳(DB 1차 평가자 null)은 null 안전하게.
