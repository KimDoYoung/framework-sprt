## SQL 이식
`selectStampCheck`는 조건·정렬(`apr16_appl_date DESC, apr16_stamp_doc_id DESC`) 그대로, `SELECT apr16_stamp_doc.*`·`t.*`는 DTO 열만 별칭으로 뽑고, `choose/when` → `if`. `updateConfirmDate`는 명시 UPDATE(회사 조건 추가). 원본은 클라이언트가 확인자·확인일자를 모델에 채워 보내지만, TOBE는 `check` 하나만 받아 서버가 로그인 사원·오늘로 채운다(결과는 같음, 클라이언트가 다른 사람 ID를 보낼 수 없게 됨).
