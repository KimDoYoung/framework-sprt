## 한계 / 넘긴 것
- 브라우저 시험은 일괄 때. 대결자 묶음 헤더의 파란 글씨는 부품 옵션이 없어 열 글자색으로만 표현.

## 원본 이상한 점
- `settings()`가 `LoginUser.getToday()` 객체에 `addDaysToDate(-7)`를 직접 적용한다. 같은 객체를 종료일에도 쓰면 둘 다 7일 전이 될 수 있다(실제 동작은 getToday가 새 객체를 주는지에 달림). TOBE는 의도대로 시작 = 오늘-7, 종료 = 오늘로 했다. **확인 필요**
- `retrieve`가 보내는 `empId`는 `selectByText` SQL이 쓰지 않는다.
- 원본은 새 행(altApprId는 insertRow에서 받음)과 DB 행 사이 기간 겹침을 검사하지만 `targetEmpId1.equals`가 null이면 오류가 난다(원결재자 미지정 행은 앞선 필수 검사에서 걸러짐).

## 제안 (03 원칙 5)
- 묶음 헤더(`gb.group`)에 헤더 글자색 옵션을 두면 대결자 파랑 헤더를 그대로 낼 수 있다.
