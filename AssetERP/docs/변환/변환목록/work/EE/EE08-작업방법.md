- 바깥 여백 20·배경 흰색, 가로 `Splitter`: 왼쪽(400, 최소 200·최대 1000) = 테두리 박스(위 툴바 50 `문서분류` · 입력 200 · [찾기] / 트리 / 아래 툴바 50 `부서별 조회권한 필터링` · 조직 조회창 칸 210 "전체"), 오른쪽 = 테두리 박스(툴바 50 `검색` · 입력 200 · [조회][등록][저장][삭제] · [사원별 권한현황] + 셀 편집 그리드 부서 300·성명 100·직위 100·사원구분 100·비고 500)

## 공통 절차와 다른 점
- 문서분류 트리는 한 번 눌러도 열리고 닫힌다(원본 `Tree.onClick → onDoubleClick`). 선택은 GXT처럼 여러 건이 가능하다(Ctrl 클릭, 찾기 결과) — 1건일 때만 오른쪽이 받는다.
- 사원별 권한현황 창의 왼쪽 그리드는 체크박스 다중이지만 쓰는 값은 행 클릭뿐이다(원본 그대로).
- 조직 칸의 x(선택안함)는 부품 `LookupInput`의 기본 모양이다 — 원본은 조회창 안의 [전체]로만 비운다(둘 다 같은 결과).
- 사원 조회창이 돌려주는 부서·직위·사원구분 글자를 그대로 새 행에 채운다(저장 뒤 다시 조회하면 서버가 같은 글자를 만든다).
