## 공통 절차와 다른 점
- 엑셀다운로드: AS-IS는 RD 리포트 서버(`Bbs15_Rd_CompanyRuleManager`)에 맡긴다 → TOBE는 서버가 xlsx를 직접 만든다. 열은 그리드 순서(구분·규정코드·규정명·제개정일·개정회차·첨부파일 갯수·공개·종료일·비고·작성자·변경자·작성(변경)일). RD 양식과 같은지는 확인 못 함
- 내보내기 서버 권한을 관리자 회사로 제한(원본에 없음) — 작업기록 "제안"
- 편집 창의 첨부파일은 저장 전에도 올릴 수 있어야 하므로(원본 DBUtil.setSeq) 새 ID를 `next-id`로 미리 받는다 (A29·E04와 같은 방식)
