### 제안 (사용자 승인 전에는 반영하지 않음)
- **E12 [메일발송]**: 원본 툴바에 안 붙은 도달 불가라 제외했다. 살리려면 `AlarmPopup`(알림 발송) 변환이 필요 — 사용자 결정.
- **"근거" 검색**: 칸 안내문("대분류/중분류/체크내용/근거")과 달리 원본 SQL은 근거(`ics10_criterion`)를 안 본다. 원본 그대로 두었다 — 근거도 찾게 하려면 SQL 변경이라 승인이 필요.
- **제출 뒤 답 수정**: 원본은 제출한 체크리스트도 확인 전까지 답을 바꿀 수 있다(K01 준수확인서는 막음). 원본 그대로 뒀다.
- **yunhee 제안**: `analysis ui`가 제외 사유(도달 불가)를 대조표에서 자동으로 `E12(생략)`로만 표시하는 것은 좋았다. `yunhee api --as <로그인ID>` 실패 시 남은 시도 횟수(3/5)가 서버 응답에만 있어, 계정 잠금 경고를 `--as` 사용 시 미리 알려 주면 좋겠다.
