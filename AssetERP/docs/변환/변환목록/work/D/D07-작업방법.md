## 화면 구성
- `Splitter` 가로: 왼쪽(580, 최대 800) = `SearchBar`(운용사 읽기 전용 칸 250 + 조회) + [ICAM Get][타사무 Get] + `SingleGrid`(펀드코드 70·펀드명 350·최신적용일 90, 체크박스 없음). 오른쪽 = `Icam03_Grid_Fund`: `SingleGrid`(행번호, 체크박스 단일, 33열) + `PagingToolBar`(100).
- 버튼 type: 조회 `search`, ICAM Get·타사무 Get = `download`(원본 문구가 `button-types`에 없어 `unknown` → "외부에서 가져오기" 뜻으로 고름, 제안).
- `fundId`는 18자리라 문자열로 내린다(05 §6).
