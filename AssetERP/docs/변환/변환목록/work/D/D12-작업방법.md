## 화면 구성
- 위: `SearchBar` = 사무수탁사명(`SearchBar.Input` 400, 빈칸 글자 "전체") + 조회 + 저장(n) + ICAM가져오기 + 사용여부(`Checkbox`, 켬). 아래: `CellEditGrid`(행번호, 체크박스 단일, 사무수탁사명 250 표시만·ICAM 80 편집·협회코드 80 편집·신한펀드 80 편집·사용여부 70 체크 표시만·비고 300 편집, 코드 3열은 가운데 정렬). 여백 20, 최대 폭 1000.
- 원본에 행 추가·삭제·초기화 버튼이 없다. 새 행은 ICAM가져오기로만 생긴다.
- 버튼 type: 조회 `search`, 저장 `save`, ICAM가져오기 `download`.
- `officeWorkId`는 `number`로 안전(05 §6 18자리 문자열 규칙 대상 아님; 샘플 66006).

## 공통 절차와 다른 점 (D11과 다른 점)
- 열 때 조회한다(D11은 안 함) → `useEffect`로 한 번 `retrieve()`.
- 이 DB의 `fnd06_office_work`에는 공통 회사(0) 행이 11건 있어 admin 회사에서 화면에 행이 보인다(D11은 0행).
- 서버 보강: 저장·가져오기는 관리자 회사만(원본은 화면이 공통 회사에서만 열려 서버 검사가 없다).
- `FndIcamImporter`에 `importOfficeWorks(Long companyId)` 추가(D13도 같은 인터페이스에 메서드를 더한다).
