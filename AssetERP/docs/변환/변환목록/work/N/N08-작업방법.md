## 공통 절차와 다른 점
- **등록(INSERT)에서 연결 버튼은 안내만 한다**("직책을 저장한 뒤 연결할 수 있습니다"). AS-IS는 새 ID를 미리 받아(`DBUtil.setSeq`) 직책을 저장하기 전에도 연결을 저장할 수 있어 직책 없는 연결 행이 남을 수 있다. TOBE는 ID를 서버가 저장 때 만들므로 저장 뒤에만 연결한다(03 원칙 4 예외 — 작업기록 "결정").
- 3개 연결창이 같은 "삭제 미룸" 흐름이라 훅 `useDeferredCrud`로 뽑았다(11 §4, 05 §5). N07의 `Tdm22_Lookup_RoleRelateCncl2`는 손대지 않았다.
- 보고CEO 칸의 [선택안함]은 AS-IS에 없다(`LookupInput`의 x로 비울 수 있으나 저장 때 필수 검사에 걸린다).
