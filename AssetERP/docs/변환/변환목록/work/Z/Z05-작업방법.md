## SQL 이식
전부 그대로(별칭·camelCase만). 주석 `AS-IS(IDMS-IC)`. 회사 조건(`*_company_id = 로그인 회사`)을 UPDATE·DELETE·SELECT에 더했다(05 §6, 보안 보강) — `selectBytargetCompanyName`(엑셀 업로드의 같은 이름 찾기)은 원본에 회사 조건이 없어 다른 회사의 활동처에 담당자를 붙일 수 있었다 → 회사 조건 추가(이상한점).
