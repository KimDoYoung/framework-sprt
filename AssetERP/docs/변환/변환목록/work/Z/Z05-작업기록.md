## 원본 이상한 점 (신규 → docs/원본-이상한점.md 반영)
- **#177** 엑셀 업로드 `selectBytargetCompanyName`에 회사 조건이 없다 → 다른 회사의 같은 이름 활동처에 담당자가 붙을 수 있다. TOBE는 회사 조건을 더했다.
- **#178** `selectBySearchTextTotal`은 담당자·즐겨찾기와 상관없는 활동처 수(검색어 대상도 활동처명+비고)라 즐겨찾기 추가 창의 페이지 수가 실제 행 수와 다르다(Y12 기존 구현이 이미 같은 방식). `selectFavoriteTotal`도 검색어 조건이 없다.
- **#179** 엑셀: 담당자 이름이 비어도 `managerName != null || !"".equals(managerName)`이 항상 참이라 빈 담당자도 등록된다. 이미 있는 활동처에 이름이 바로 맞은 행은 즐겨찾기를 안 넣고, 새로 만들거나 `기타` 쪽만 넣는다(그대로 옮김). 첫 칸이 비면 `기타`.
- **#180** `Mkt06_Favorite.deleteList`가 `deleteFavoriteId` 뒤에 활동처 모델 키(row_number)로 `deleteModel`을 또 부른다(아무것도 안 지움). 공유지정 [저장]은 변경이 없으면 창이 닫히지 않고 아무 일도 없다(`chk1==chk2` 검사가 안 맞음). 활동내역 저장은 연결펀드가 하나도 없으면 `updateByList`를 부르지 않아 예전에 저장한 연결펀드가 남는다(삭제 아이콘으로만 지워진다).
- 출력 창 이름이 `"%" + "Mkt01" + "%"`로 `sys99_print`에 `%Mkt01%` 글자 그대로 저장된다.
