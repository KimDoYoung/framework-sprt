## 공통 절차와 다른 점
- 12 준원칙의 "안쪽 padding 없음"과 SG 견본(안쪽 padding 10)이 달라 03 원칙 22에 따라 견본을 따른다(`page-style-check.py` SG 요구).
- 확인자 본인 검사(`confirmerId`가 로그인 사원이 아닌 경우)를 서버도 지금 저장된 확인자로 다시 검사한다. 원본은 창을 열 때 그리드 값만 본다(#187).
- 월 콤보는 월 코드만(`%` 전체 없음) — 원본 `ComboBoxField("MonthsCode")` 그대로. `lookupOrg`의 `%` 분기는 그대로 옮겼다.
