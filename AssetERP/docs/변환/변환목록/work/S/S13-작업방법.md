## 공통 절차와 다른 점
- **TOBE 추가**: ① 저장·삭제 때 상신 중·완료 행 검사를 서버에서도(화면 검사와 같은 문구), 날짜 순서·필수값 검사, 사원 소속 확인. ② `Emp00_Lookup_SelectSingle`에 `searchText` prop(AS-IS `open(…, searchText, …)`)을 더했다(공통 부품, 11·05 §5 갱신).
- **생략**: E18 삭제 뒤 "첫 행 선택"(체크박스 그리드라 첫 행이 삭제 대상으로 체크돼 버림). 헤더 글자색(연봉 구성 `456EA6`)은 `gb.*`에 열별 헤더색이 없어 적용하지 않음.
- 계약서 양식 태그 목록은 AS-IS가 Java `HashMap` 순서(일정하지 않음)라 선언 순서로 보인다. 셀을 한 번도 누르지 않았을 때의 기본 목록은 "연장근로시간(월)", 누른 뒤 목록은 "연장근로시간" — AS-IS 그대로 두 목록을 둔다.
- 엑셀 업로드 결과는 AS-IS가 응답 글자를 화면에 안 쓰고 다시 조회만 하지만, TOBE는 건수/오류 메시지를 보인다.
