- 원본 두 클래스(`Emp15_Lookup_Cert`·`Emp15_Lookup_StampDocCert`)는 코드가 거의 같아 TOBE는 폼을 `Emp15_CertEdit` 한 파일로 두고 두 클래스는 얇은 래퍼로 만들었다 — 이벤트·버튼 주석은 `Emp15_CertEdit`에 있다(`yunhee analysis ui`는 파일 이름으로 세어 두 클래스를 0으로 본다 → 결과확인에 손으로 센 값을 적음).
