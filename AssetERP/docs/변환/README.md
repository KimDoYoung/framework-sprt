# 변환

## 개요

- 변환이란 AS-IS 소스(GWT/GXT)의 화면을 Spring Boot / React 로 옮기는 작업이다.
- 규칙은 이 폴더의 `변환-가이드.md` 하나가 정한다(옛 03·05·06·12·08·05a는 `_보관/`, 2026-11-05).
- 핵심 명령: `yunhee analysis`, `yunhee port-sql`, `yunhee run`

## 읽는 순서

**세션 시작은 `변환-가이드.md` 전체부터.** 나머지는 `AssetERP/CLAUDE.md`의 "읽는 순서" 표를 따른다.

## 파일 및 폴더

- `변환-가이드.md` : 변환 규칙·절차·확인·yunhee 사용 (유일한 규칙 문서)
- `04`·`07`·`09`·`10`·`11`·`11a`·`13` : 레퍼런스. `05b` yunhee 버전 이력(막힐 때만)
- `_보관/` : 옛 03 절대원칙·05 작업방법·06 결과확인·08 회차인계·12 화면우선원칙·05a 부품 등록표 이력 (읽지 않는다. 옛 문서가 인용하는 번호는 이쪽 파일을 가리킨다)
- `서블릿-변환목록.md` : AS-IS 서블릿(`web.xml`)의 분기별 인벤토리와 TOBE 대체 여부 (2026-11-04~). 서블릿은 한 URL이 여러 기능이라 분기 하나를 ID 하나로 본다. JSP는 그 다음 단계.
- `변환목록/` : 화면별 변환 진행표 `01a`~`01z-변환목록.md` (상태 `대기`/완료). **통째로 읽지 않는다** — `grep -n '대기'`로 첫 `대기` 행만 찾고 그 ID 행만 본다.
- `work/{첫글자}/` : 과거 ID별 기록(2026-11-05에 새로 만들기를 중단). 읽지 않는다. 필요하면 해당 ID 파일만 연다.

## docs 루트의 변환 보조 문서

- `../page-style.md`, `../grid-style.md`, `../modal-style.md` (+ 같은 이름 폴더의 견본) : 화면 이름표
- `../SID-샘플만들기-목록.md`, `../yunhee-page-style-판별.md` : page-style 정립 작업
- `../원본-이상한점.md` : AS-IS 이상한 점, 사용자 판단 대기
- `../RD-대책.md`, `../DB_change.md`, `../React-수동으로 UI변경.md`
