## 공통 절차와 다른 점
- 승인 문자: 원본은 승인 때 신청자 휴대폰으로 문자를 보내고 실패하면 로그만 남긴다. TOBE는 `SmsSender`를 부르되 기본 구현(`DisabledSmsSender`)이 거절 → 경고 로그만(실제 문자 발송 금지 — 사용자 지시, C06과 같음).
- 사원찾기에서 회사가 "전체"일 때 돋보기: 원본은 `Long.parseLong("%")`이 실패한다 → "회사명을 먼저 선택해주세요" 안내(제안).
- `전체` 버튼(button-types에 없는 type)은 `select`로 그림 — 등록표에 추가 제안.
