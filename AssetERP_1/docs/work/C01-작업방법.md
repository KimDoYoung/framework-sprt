## SQL 이식
| SQL | 그대로 / 수정(사유) |
|:---|:---|
| selectByText | 조건·정렬 그대로(CTE emp00/org00, 재직구분 CASE, `(이름‖조직명‖사번) LIKE`, 조직 이력 max(mod_date), 겸직 NOT EXISTS, 발령일 문자열 비교). SELECT 목록은 그리드·탭이 쓰는 컬럼만(`emp01_password`·주민번호 복호화 등 안 씀). 이 SQL을 selectById(transId)·selectOneByPersonId와 같은 컬럼 조각으로 묶는다 |
| 신규 등록 | AS-IS 순서: personId 채번 → emp02_others(others_id=personId) → emp01_person INSERT(팝업 컬럼) → emp03_trans(채번, trans_cd '100', 발령일=입사일, 사원구분·조직·직위·직책, 계약만료일) → emp35_deduct(채번, insure true, basic 1, with_hold_rate 100) → 회사 0의 `AddDeductType` 코드마다 emp36_add_deduct(cnt 0).
