# A11 Sys06_Tab_MenuView — 작업기록

## 기록
- 2026-10-15 분석·백엔드·프론트 작성. 새 API 2개: `GET sys/menus/view`(sys06_menu.selectByCompanyId를 한 번에 읽어 전위 목록), `GET sys/menus/{menuId}/roles`(sys04_role.selectByMenuId). 사원 목록은 기존 `roles/{roleId}/user-roles` 재사용.
- 클래스 3개: Sys06_Tab_MenuView(트리), Sys04_Page_RoleView(권한그룹 그리드+분할), Sys05_Page_UserRoleView(사원 그리드). `screens.ts` 등록.
- 원본 그대로: selectByMenuId가 sys05_user_role을 LEFT JOIN해 사원 수만큼 같은 권한그룹이 나온다 → 프론트가 roleId 기준 첫 행만 쓴다(그리드 키 충돌 방지). 제안: 서버 SQL에서 중복 제거.
- 같은 회사·메뉴의 sys03_company_menu 행이 둘이면 INNER JOIN이 중복 행을 만든다 → 서비스 전위 목록이 menuId 한 번만 쓴다.
