## 화면 구성
- 레이아웃(BorderLayout): north 툴바 50(고객명 200 + 조회·저장·등록·삭제), west 고객 그리드 380(분할), center 권한 그리드 → `Splitter` 2단(05 §6 "화면 나누기")
- 고객 그리드 `SingleGrid`: `companyNm 200 고객명`, `locNm 150 Sub-Domain`, 행번호 보임
- 권한 그리드 `CellEditGrid`+`useGridCrud`(체크 다중): `companyNm 150 고객명`, `roleNm 200 권한명 text`, `seq 70 조회순서 text`, `defaultRole 70 기본권한 boolean(편집)`, `adminYn 70 관리자권한 boolean(편집)`, `note 500 권한설명 text`
- 버튼 `search`·`save`·`register`·`delete`

## 공통 절차와 다른 점
- 회사가 로그인 회사가 아니라 화면에서 고른 고객사 → API 경로에 `{companyId}`, `isSysAdmin()` 아니면 `ACCESS_DENIED`(05 §6 "관리 화면 권한").
- 권한명 빈 값은 A01과 같게 `INVALID_INPUT` "권한명을 입력하세요."(원본은 DB NOT NULL 오류).
- 삭제 선택 검사는 원본에 있으므로 원본 문구 "삭제대상을 선택하세요"를 화면에서 먼저 띄운다.
