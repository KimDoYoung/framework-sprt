## 공통 절차와 다른 점
- **순서 앞당김**: 04 순서(A02~A14, B10 다음)보다 먼저 한다. 1단계는 파일(B10)을 쓰지 않는다.
- **KFS 관리자만**: AS-IS는 메뉴가 admin 회사에만 있어서 막혔다. TOBE는 API가 열려 있으므로 `isSysAdmin()` 아니면 `ACCESS_DENIED`.
- **중복 검사 추가**: 서브도메인(테넌트 판정에 쓰임 — AS-IS는 막지 않음)과 사업자번호(AS-IS는 DB unique 오류 원문)를 미리 막는다 → `DUPLICATE_DATA`.
- **확인 방법**: 회사 등록은 초기화로 15개 테이블에 행을 남기므로 화면 확인에서 실제 등록하지 않는다. SQL은 `@MybatisTest`(롤백)로 asseterpdb에서 돌리고, 화면은 중복 사업자번호로 서버 거절까지 확인한다. 실제 등록(kalpa)은 사용자가 직접 한다.
