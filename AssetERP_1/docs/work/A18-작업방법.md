## 공통 절차와 다른 점
- 영업일은 DB 값 `workingYn`('true'/'false') 그대로 `gb.boolean(…, { editable: true })`(원본 `workingYnFlag` getter ↔ 05 §5 체크박스 컬럼).
- 서버 검사 두 개를 더했다(작업기록 결정): 생성 때 년도가 4자리 숫자가 아니면 막음(원본은 `to_date` 오류 문구가 그대로 뜸), 기초데이터생성에서 고객사를 안 골랐으면 막음(원본은 회사 없는 휴일 행이 생김).
