- 위 = 툴바(발생일 ~ · 회사명 · 구분 · 완료여부 · 검색어 · 미완료건만 보기 · 미확인건만 보기 · 조회) + `SingleGrid`(행번호·체크박스 단일, 9열). 아래 400 = `Sys90_Edit_BoardAdmin`.
- 버튼 type: 조회 `search`, 저장 `save`, 파일등록 `upload`, 파일관리 `view`, 닫기 `close`, 확인 `save`(원본 분석표대로).

## 공통 절차와 다른 점
- 파일 미리보기: 원본은 변환 서버(`admin.k-fs.co.kr`)의 화면을 iframe으로 열어 모든 문서를 보여 준다. 이 환경에는 그 서버가 없어 PDF·그림(png/jpg/gif/bmp/webp)은 브라우저가 직접 보여 주고 나머지는 원본의 "미리보기를 지원하지 않는 파일입니다. 다운로드하여 확인해주세요" 문구를 보인다(제안, 작업기록).
- `Sys10_Lookup_FileViewer.open(fileId)`의 확장자 조회(selectByFileId) 대신 행의 `fileExt`를 쓴다. `Sys10_Lookup_ListFileViewer`의 `fileRandomCopy`·viewerYn/fileType/viewerPath 열(DB에 없음)은 변환 서버용이라 옮기지 않았다.
