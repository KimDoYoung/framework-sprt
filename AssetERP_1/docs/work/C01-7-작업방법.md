## 화면 구성
- 세로: 툴바(높이 50) + 그리드. 툴바 = 제목 "연관파일"(굵게) + 조회·등록·삭제·저장
- 그리드 `CellEditGrid`(setChecked SINGLE → 체크박스 단일, 행번호): 등록일(date 100)·파일명(350)·용량(KB)(double 100)·상세설명(text 450, 편집)·업로드(iconCell upload 80)·다운로드(iconCell down 80)
- 한 연관파일에 파일이 여러 개면 원본 SQL(LEFT JOIN)대로 같은 relateFileId 행이 여러 줄 나온다 — 원본 그대로 둔다(현재 데이터 0건)

## 공통 절차와 다른 점
- 등록 = 행 추가 + 곧바로 저장(원본 insertRow 콜백이 update()를 부른다). `useGridCrud.addRows([...], true)` 뒤 다음 렌더에서 `saveRows`
- 삭제 = `useGridCrud.deleteChecked`의 `remove` 안에서 파일 판정(checkFileDelete)을 먼저 하고 emp18 행을 지운다(원본은 둘을 동시에 비동기로 부른다 — 결과 같음)
