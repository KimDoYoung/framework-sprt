## 제안 (사용자 승인 전에는 반영하지 않음)
- **파일 미리보기**: 원본의 변환 서버 미리보기를 대신할 방법(문서 변환 서버 연결 또는 서버 쪽 PDF 변환)을 정해야 xls·doc 등도 볼 수 있다. 지금은 PDF·그림만.
- **삭제**: 원본 서버 `delete`는 화면 어디서도 부르지 않는다(버튼 줄에서 뺌). 필요하면 이 ID의 후속으로 버튼·API를 추가.
- **조회 조건 7개 초기화(UX-02)**: 조건이 한 줄을 넘겨 넣지 않았다. 툴바를 두 줄로 두는 것을 사용자가 허용하면 넣을 수 있다.
- 원본 `updateRow()`는 처리방안의 `'`를 `''`로 바꿔 저장한다(동적 SQL 시절 잔재). 바인딩을 쓰는 TOBE는 바꾸지 않고 그대로 저장한다 — 원본 DB에는 `''` 두 개로 저장된 옛 행이 있을 수 있다.
