## SQL 이식 (새 매퍼 `SysRoleMenuMapper.xml`, 파라미터 `RoleMenuCopyParam`)
- 원본 파라미터: `companyId` = 목적지(반복 중인 회사), `inCompanyId` = 출발지, `roleName`(정확한 이름, `%` 안 붙임), `menuId`(조상 반복 중)
| SQL ID | 그대로 / 수정(사유) |
|:---|:---|
| sys04_role.selectByName (목적지, roleName) | 그대로(`LIKE #{roleName}`). 행 목록 대신 `count(*)` — 원본이 `size()`만 쓴다 |
| sys04_role.insertRole | 그대로(INSERT … SELECT 출발지 같은 이름 권한 → 목적지 회사). 컬럼 목록만 명시(A15 `copyRoles`와 같음, 순서 같음) |
| sys06_menu.getMenuId | 그대로(재귀 상향: 자기 + 조상 ID, 순서는 자기부터) |
| sys03_company_menu.selectByMenu / updateMenu / insertMenu | 그대로. update는 목적지 use_yn = 출발지 use_yn(출발지에 없으면 NULL), insert는 출발지 행을 SELECT(없으면 0행). 컬럼 목록 명시 |
| sys07_role_menu.selectByMenuId / updateRoleMenu / insertRoleMenu | 그대로(같은 방식, 권한 ID는 `sys04_role_nm LIKE roleName` 서브쿼리 — 출발지에 같은 이름 권한이 둘이면 원본처럼 오류). 컬럼 목록 명시 |

- north 툴바: `[권한그룹복사] [매뉴권한복사]  ※ 상단 : 출발지 회사 / 하단 : 목적지 회사`(파란 글자 #4472C4)

- 그리드: In 회사 = `SingleGrid` + 체크박스(SINGLE), Out 회사 = `MultiGrid`(MULTI, 행 클릭 선택), 권한 = `SingleGrid` + 체크박스(SINGLE), 메뉴 = 트리(`useTreeGrid`, 행번호 없음, 보기 전용)
