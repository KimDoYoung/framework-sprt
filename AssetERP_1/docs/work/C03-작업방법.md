## 공통 절차와 다른 점
- 원본 `retrieve()`의 하드코딩(고객사 '한국펀드서비스(주)' + 로그인 ID kfiamuser → 1, idmsuser → 28000)은 화면에 그대로 두었다(`loginUser.loginId`)

- `copyToClipboard`는 원본 클래스 밖이라 브라우저 Clipboard API(+ http용 execCommand)로 옮겼다
