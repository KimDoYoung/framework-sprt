### POST /emp/deducts — Emp35_Deduct.insert 로직
1. f_create_seq() → deductId
2. selectCurrentDeduct(companyId, personId, startDate) → existing (max start_date ≤ startDate)
3. Case 1 (existing null): insertDeduct(빈 값) + insertAddDeductTypes(deductId, personId, startDate, companyId)
4. Case 2 (existing, 같은 날짜 yyyy년MM월dd일): insertDeduct(existing 값 복사) + insertAddDeductTypes + deleteDeduct(existing.deductId) + deleteAddDeducts(existing.deductId)
5. Case 3 (existing, 다른 날짜): insertDeduct(existing 값 복사) + insertAddDeductTypes (과거 이력 유지)
- ⚠ 원본 result.setResult 없음 — 빈 값으로 삽입된 경우(Case 1) 화면에서 조회로 확인. TOBE는 OK 200으로 반환.

## 공통 절차와 다른 점
- Emp35 DeductDate + DeductInsert: 하나의 TSX 파일에 합침(레이아웃이 한 탭 안에서 좌우 분리이기 때문)

- Pay31_Popup_InsureApply(4대보험 신고정보): 급여 도메인 범위 밖 → 버튼 보이되 "미구현" 안내
