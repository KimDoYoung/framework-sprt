# 09. 업무 흐름 — 회사 등록 · 관리자 · 메뉴 · 권한

AS-IS(AssetERP)에서 "새 고객사를 열어 쓰게 하기까지" 실제로 어떤 순서로 무엇이 바뀌는지 정리한다. 화면을 변환할 때 **업무상 앞뒤 관계**를 놓치지 않기 위한 문서다.
근거:
- `~/oms-data/docs/`(OMS 만들 때 실제 로그와 소스로 분석한 문서). 회사등록-사용자등록-메뉴연결, company_add, company_menu, company-menu, company_user_role, menu-structure, login1
- A15 분석과 asseterpdb 대조(2026-10-07)

## 1. 전체 순서 (실제 운영 로그 kova, 2026-03-18 기준)

| # | 하는 사람 | 화면 (TOBE ID) | 바뀌는 것 |
|---:|:---|:---|:---|
| 1 | KFS 관리자(admin) | 고객별 시스템정보 관리 [등록] (A15) | `sys01_company` INSERT(사용여부 null) + **회사 초기화**(org01·org02·sys09 코드·dcr01 문서분류 … — A15-작업방법) |
| 2 | 〃 | 관리정보·기본정보 탭 (A15) | `sys01_company` UPDATE. 처음 열 때 로고 이미지 ID 채번. 기본정보의 법인등록번호는 `to_encrypts` |
| 3 | 〃 | 고객별 관리자 탭 (A15) | `sys02_user` INSERT, 비밀번호 `to_encrypts`, 보통 전체권한(`sys02_admin_yn`) true |
| 4 | 〃 | 관리정보 탭 사용여부 체크 (A15) | `sys01_use_yn` null → 'true'. **이것이 있어야 그 서브도메인으로 로그인할 수 있다** |
| 5 | 〃 | **회사별 메뉴맵핑** (A10 `Sys03_Tab_CompanyMenu`) | `sys03_company_menu` INSERT/UPDATE. 이 테이블에 행이 없으면 그 회사는 메뉴가 하나도 없다 |
| 6 | 회사 관리자 | 그 회사 서브도메인으로 로그인 | 회사 메뉴 전체가 보인다(전체권한이면) |
| 7 | 회사 관리자(또는 KFS) | 권한그룹 관리(A01) → 권한그룹별 메뉴 맵핑(A06) → 권한그룹별 사용자 맵핑(A03)·사용자별 권한그룹 맵핑(A04) | `sys04_role` / `sys07_role_menu` / `sys05_user_role` — 직원이 볼 메뉴 |

- 5단계 대신 쓸 수 있는 것: A15 [매뉴권한복사(초기)] — 다른 회사(템플릿)의 회사 메뉴·권한그룹·권한그룹별 메뉴를 한 번에 복사. 실제 kova 등록은 5단계(회사별 메뉴맵핑)로 했다.
- 메뉴를 회사에 붙이는 다른 길: 메뉴 관리(A09 `Sys06_Tab_Menu`)에서 메뉴 하나를 고르고 오른쪽 회사 목록에서 체크(`updateByMenuYn`).

## 2. 테넌트와 로그인

- **서브도메인 = 회사 코드 = `sys01_loc_nm`**. 모든 데이터 격리가 이 값 하나로 된다. 그래서 TOBE는 서브도메인 중복을 막았다(A15).
- `admin`(·admindev·admindr) 서브도메인만 로그인 화면에 회사 선택이 보인다(KFS 관리자가 다른 회사로 들어가기).
- 로그인 계정은 두 종류다.
  - 회사 관리자: `sys02_user`(회사 + `sys02_login_id`, 비밀번호 `to_decrypts` 비교)
  - 직원: `emp01_person`(회사 + 사번, 현재 발령 `emp03_trans`가 있어야 함)
- 로그인 후 회사 ID가 메뉴·권한·코드·직원·연차·특정메뉴 등 모든 조회의 기준이다.

## 3. 메뉴가 보이는 조건

```
회사 관리자(sys02, 전체권한 true)  : sys03_company_menu(use_yn='true')
회사 관리자(sys02, 전체권한 false) : 위 + sys82_admin_user_menu(그 관리자에게 체크된 메뉴)
직원(emp01)                        : sys03(use_yn='true') ∩ sys07_role_menu(use_yn='true') ∩
                                     ( sys05_user_role(본인) ∪ sys04_role.default_role='true' )
공통(3차 메뉴)                     : 특정메뉴(sys50_specific_menu)로 지정된 메뉴는 sys51_specific_menu_person에 있는 사람만
```
- 흔한 실수: 회사에 메뉴를 붙였는데 직원에게 안 보임 → `sys07_role_menu`가 없거나 역할이 없다. 기본권한(default_role)을 쓰면 사용자-역할 연결 없이 회사 전 직원에게 적용된다.
- 메뉴 트리 규칙(회사별 메뉴맵핑·메뉴 관리): 켜면 **부모도 모두 켠다**, 끄면 **자식도 모두 끈다**, 부모를 끌 때 켜진 형제가 있으면 부모는 둔다.

### TOBE 메뉴 API(B06, OMS에서 가져옴)와의 차이 — 2026-10-07 확인
| AS-IS 조건 | TOBE `SysMenuMapper` | 영향 |
|:---|:---|:---|
| 전체권한 false 관리자 → sys82 메뉴만 | 없음(회사 메뉴 전체) | A15 권한설정(Sys82)이 로그인 메뉴에 반영되지 않는다 |
| 특정메뉴(sys50/51) 제외 | 없음 | A15 특정매뉴 권한 탭(3단계)을 만들어도 메뉴에 반영되지 않는다 |
| 직원: 역할 메뉴 ∪ 기본권한 | 있음 | — |

→ 메뉴 API를 AS-IS `sys06_menu.selectByTailMenuCompanyId`(L417, `<choose adminYn>`)·`selectByHeaderMenuCompanyId`와 맞추는 B 작업이 필요하다(01에 추가 제안).

## 4. 화면·테이블 대응표

| 테이블 | 뜻 | 관리 화면 (TOBE ID) |
|:---|:---|:---|
| `sys01_company` | 회사 | A15 고객별 시스템정보 관리 |
| `sys02_user` | 회사 관리자 계정 | A15 고객별 관리자 탭 |
| `sys82_admin_user_menu` | 전체권한 아닌 관리자의 메뉴 | A15 권한설정(Sys82) |
| `sys06_menu` | 전사 공통 메뉴 정의(트리) | A09 메뉴 관리 |
| `sys03_company_menu` | 회사별 메뉴 사용 | A10 회사별 메뉴맵핑, A09 메뉴 관리(메뉴 기준), A15 매뉴권한복사 |
| `sys04_role` | 권한그룹(회사별, default_role·admin_yn) | A01 권한그룹 관리(고객사), A02 관리자용 |
| `sys07_role_menu` | 권한그룹별 메뉴 | A06 권한그룹별 메뉴 맵핑, A07 고객사별 메뉴권한 관리, A08 권한그룹별 메뉴권한 복사 |
| `sys05_user_role` | 사용자(직원)별 권한그룹 | A03 권한그룹별 사용자 맵핑, A04 사용자별 권한그룹 맵핑, A05 고객사별 사용자권한그룹 |
| `sys50/51` | 특정메뉴와 그 메뉴를 쓸 수 있는 사람 | A15 특정매뉴 권한 탭 |
| `emp01_person`·`emp03_trans` | 직원·발령 | sys 밖(`Emp00_Tab_TransInfo` 사원정보 관리) — 이 회차 범위 밖 |

## 5. 다음 작업에 반영할 것

1. **목표 경로의 "회사에 권한부여"는 A10 회사별 메뉴맵핑이 본래 길이다.** 매뉴권한복사는 템플릿 복사용 보조 수단. → 04 목표 경로 2단계를 A10으로 바꾼다.
2. **메뉴 API를 AS-IS 조건과 맞춘다**(위 3절 표). 관리자 권한설정·특정메뉴가 실제로 효과를 내려면 필요하다.
3. **직원에게 role·메뉴 주기(목표 4단계)**:
   - 순서는 A01(권한그룹, 기본권한 체크) → A06(권한그룹별 메뉴) → A03/A04(사용자 연결, 기본권한이면 생략)
   - **직원이 있어야 로그인해서 확인할 수 있다.** 새 회사(kalpa)에는 직원이 없다 → 사원 등록(sys 밖)을 할지, 기존 회사(kfstest) 직원으로 확인할지 사용자와 정한다.
4. 회사 등록 확인 항목에 "사용여부를 켜야 로그인됨", "회사 메뉴가 없으면 로그인해도 빈 화면"을 넣는다(06).
